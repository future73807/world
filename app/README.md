# 迷雾群岛 · 运行说明（G0 实机切片）

浏览器全屏 3D 开放世界浮岛。Three.js 实时渲染，全部 UI、模型、地形、材质均为本项目从零程序化生成，未使用恢复包或任何外部游戏资源。

## 启动

```bash
cd app
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # 生产构建 → app/dist
```

需要支持 WebGL2 的浏览器。首次进入约 1 秒生成浮岛与植被，随后进入全屏游戏。

## 操作

| 输入 | 行为 |
|---|---|
| WASD / 方向键 | 相对镜头移动（W 沿镜头前方），带起步加速、转向与停止反馈 |
| 鼠标单击画面 | 锁定指针，左右移动 360° 环视（不随上下移动俯仰）；松开不回正 |
| 滚轮 | 平滑调整跟随距离（3.4–13.5 BU） |
| 空格 | 跳跃（起身挤压 → 上升 → 顶点 → 下落 → 落地回弹） |
| Shift | 冲刺 |
| E | 走到离雾缘很近时（前方 9 BU 内），雾缘浮现世界内 E 标记，按键或点击弹出生成面板 |
| M | 全屏地图 |
| I | 帮助 |
| C | 设置（图像 / 声音 / 重置世界） |
| Alt | 显示鼠标指针（释放视角锁定） |
| Esc | 关闭当前面板 |

## 已实现

**美术方向（第三轮修订，按用户参考录屏逐帧核对）**

早期曾对用户提供的原神录屏做逐帧抽帧分析（参考帧已清理，结论保留如下）：

- **史莱姆**是原神的水史莱姆：近乎球形的蛋形穹体（不是水滴/锥形），半透明青色果冻，**发光的白色竖椭圆眼**带深色描边，没有嘴和腮红。
- **UI** 是原神 HUD：柔边圆形小地图（无白圈边框，橄榄色调地图）、右侧角色栏（名字+绿血条+头像+编号）、底部斜切端头血条（白色数值内嵌）、右下圆形技能钮（键位标签在下方）、右上白色细线图标。
- **场景**：明亮蓝天空、暖阳、饱和草绿、圆润树冠与鹅卵石岩石。

据此重写了史莱姆建模与 HUD 布局。历史说明见文末限制一节。

**世界与美术**

- 确定性高度场：地形、水面、小地图、全屏地图、碰撞和植被散布共用同一 `IslandField`，同种子必然同岛。
- 平滑连续地形：10×10 区块、每块 28×28 细分（约 0.36 BU 采样），共享顶点 + 解析法线，块间无光照接缝；崖壁保留分层色带；三层微噪声让草坡有真实起伏。
- 树冠为"多团块叠加"（`foliageClump`：双尺度椭球叠加 + 高度/法线双渐变），三族树各 3 个结构变体；岩石为圆润鹅卵石；草簇宽叶 9–13 片，约 4200 丛。
- **水滴史莱姆**：蛋形穹体轮廓（参照水史莱姆实测控制点），26 环 × 26 边索引拓扑；半透明果冻材质（菲涅尔边缘增透 + 湿润高光 + 高光斑点）；**发光白色竖椭圆眼**（RGB>1 穿透 ACES 色调映射）带深色描边光环；无嘴无腮红；眨眼/呼吸/挤压拉伸保留。
- 光照：高调日光（暖阳 3.15 + 蓝天补光 + 冷侧补 + 暖轮廓），ACES；天空为亮蓝分层渐变穹顶。
- 远景：11 座独立漂浮小岛与多组云团。

**玩法与界面（第五轮：按反馈收敛 HUD、全屏地图、书本帮助）**

四周被浓雾包围的浮岛；所有界面只保留一套白色语言，页面背后是高斯模糊的世界。

- **小地图**：左上玻璃圆盘，边缘用长渐变完全化开（无任何可见边线）。圆盘外是白蓝云层，走过的地方从云里透出；顶部只有 `N`。已去掉眼睛按钮与区域文字标签。
- **玩家箭头**：圆角蓝色水滴（青→蓝渐变 + 白描边 + 白晕），随镜头朝向旋转。
- **右上三枚白色纹样图标**：罗盘星（地图 M）、问号（帮助 I）、齿轮（设置 C）。三枚共用同一套环形底纹与中心圆点（`Ring`/`Hub`），同尺寸同基线完全对齐，键帽字幕无框白字。
- **世界内“开拓迷雾”提示**：走到离雾缘很近时（朝向前方 9 BU 内采到岛缘入水线）才投影在雾边，白色圆角键帽 E + “开拓迷雾”四字胶囊，纯白样式。指针锁定时点击画布同样能命中提示打开对话框。
- **全屏地图**：整页只有地图和一枚关闭按钮，没有任何缩放条、指北针、比例尺或底栏。玩家箭头固定在屏幕正中，拖动时移动的是世界，不会把自己拖丢。地形按需分块烘焙，可无限平移——地图没有边界。未探索区域覆盖云层迷雾。
- **全屏设置**：只有「图像」和「声音」两栏；每行一枚白色胶囊控件，铺满屏幕。图像栏底部有「世界 · 重置世界」，二次确认后换新种子重生成整座岛，迷雾与地图一起清空。
- **帮助**：做成一本真正的书。打开时从书脊展开（`bookOpen` + 左右页翻页动画），占窗口 80%，背后世界压暗虚化。正文 16px、行高 2，像看说明书。
- **加载页**：标题、副标题、提示语整体放大两倍，进度条改为柔光扫过的青蓝轨道。
- **关闭按钮**：所有页面统一一枚圆形按钮（悬停旋转 90° 并微放大）。
- **地形三种区域**：中央草甸、向阳侧的金色灌木坡、高处偏冷的苔原，由低频噪声划分；整体起伏放缓（peak 16 / roughness 0.36），地形网格 flatShading 低面化，坡度不再陡峭。
- **角色朝向**：转动视角不再带动史莱姆旋转——只有实际移动时才转身，静止时保持朝向。
- **实体碰撞**：树干与岩石注册为圆柱碰撞体，移动时圆形推出并沿障碍滑行，不再穿模。
- **相机**：默认仰角 0.24 → 0.36、距离 7.4 → 8.4，不再贴地爬行；设置改为 **C** 键打开（S 不再与后退冲突）。
- **草地**：宽叶带中脊折痕（V 形截面），一丛 13–16 片，向外散开；不再是细线状杂毛。
- **史莱姆重建模**：按参考图改为平底圆顶（宽肩 + 圆冠，不再蛋形），头顶两只软胶角，蓝圈 + 暖白核心的大椭圆眼贴合曲面（修正 lookAt 反向导致眼睛沉入壳内的深度排序问题），腹部浅色渐变；高光与星点收敛，太阳盘片与天空为卡通化色带。

**第六轮（视角锁定、太阳重绘、提示距离、磨砂小地图、图标统一）**

- **相机只横转**：视角锁定后鼠标上下移动不再俯仰（`handleLook` 忽略 dy，仰角恒 0.30），左右仍是完整 360°。太阳盘仰角随之压到 5.1°，保证固定视锥内完整可见。
- **太阳重绘**：绘本风三层盘——柔光环 + 内辉光 + 象牙心金边实心盘（半径 44/30/20）。排查并修掉困扰两轮的"放射尖刺"：三层共面圆盘开着 depthWrite，CircleGeometry 三角扇沿径向边深度打架（z-fighting）画出星芒；`depthWrite: false` 后干净（depthTest 仍开，地形照常遮挡）。单盘隔离与三层关深度写入两组对照实验均已截图验证。
- **E 提示只近距离显示**：探测从 30 BU 收紧到 9 BU（岛缘入水线实测在 44 BU 半径处）：14 BU 外不显示、7/4/1.2 BU 内显示，回出生点不显示。
- **小地图磨砂边缘**：`backdrop-filter` 磨砂环（`.orb-haze`）叠在圆盘外圈，配合原有的长渐变遮罩，边缘完全化开。
- **三枚图标统一**：M/I/C 同尺寸同基线，共享环形底纹与中心圆点，视觉重量一致。

**第七轮（愿望真的生成接壤新岛、弹窗放大、加载散雾、草地重做）**

- **新区域接壤生成**：此前 `generateRegion` 把新岛放在离原点 62–96 BU 的海面——超出雾远平面（62 BU）、被迷雾墙挡住、探索迷雾也不揭示，玩家完全看不到。现在沿射线实地采样现有海岸线，把新岛圆顶**直接并入当前岸线**（圆心 = 海岸 + 0.5·半径），两层地形 `max()` 融合出一条可步行的陆桥（实测桥面最低 1.3–1.9 BU）。生成后迷雾墙整体外推包裹所有已知陆地，并在迷雾遮罩上即时揭示新岛——小地图、全屏地图、3D 世界三处立刻可见。
- **愿望弹窗**：整体放大 1.5×（输入框 86px 高、24px 字号）；提示条从顶部搬到副标题正下方（圆角药丸样式）；「取消」与「确认提交」改为并排一行（取消左、提交右）。
- **加载完成迷雾散开**：加载页不再是生硬消失——白雾层膨胀漂散（`mistDisperse`）的同时整页溶解（`bootMistReveal`），世界像从雾里显出来，1.45s 后卸载。
- **草地重做**：从"宽叶散开的喷泉"改成**矮密软和的丛状**——每丛 20–24 片短叶、均匀扇形排布、轻微外倾、尖梢小幅弯曲；散布密度 4200→5600 丛（间距 0.42→0.36），远景简化版 5→7 片，近景细节半径 19→30 BU。地面连成草坪，不再"一点一点"。

**第八轮（图标、天空贴图化、真迷雾、地形与史莱姆精修、穿模修复）**

- **地图图标**：罗盘星换成**折叠航海图**（白色描边 + 折线 + 定位点），与其余两枚共用同一环形底纹。
- **天空不再用模型**：穹顶 shader 网格整体移除，改为**画布透明 + stage 层 CSS 卡通渐变**（深蓝顶带 → 浅蓝 → 雾白，整个色带压缩在画面上沿 1/5 内）；太阳从圆盘网格改成**精灵特效**（renderOrder 高于雾墙，从雾里透出，地形仍可遮挡）。`scene.background` 贴图方案被背景渲染管线二次编码洗成灰白，已弃用。
- **浓雾真正渲染**：雾墙重做——近不透明核心（0.985）+ 三层渐弱外层，墙顶压在海平线上方 2–4°，完全遮挡墙外世界且不吞天空；**出生不再全岛揭示**（原 40/47 BU 半径把整个岛都揭了），只揭示出生地，其余全在云雾下，探索度从真实行走累计；愿望生成的陆地材质 `fog:false`——新岛以完整色彩从浓雾中显现，岛内雾感不变。
- **地形去台阶**：微噪声频率 0.11→0.05、幅度 0.22→0.12——保留起伏与高峰，但坡度连续渐变，不再"走几步卡脚"。
- **史莱姆比例**：穹体 0.95→1.05 更接近参考的近球形，冠部更饱满（0.86 处 0.88、顶 0.46），眼睛放大（蓝圈 0.155→0.185、发光核 0.118→0.148）并上移，角更短更软（0.44→0.32、外倾 0.42→0.3）。
- **穿模修复**：散布（草/花/菌）现在避开**所有**已注册碰撞体（原来只避开出生点——草叶插进树干和岩石就是"穿模"的主要来源）。
- **地图页回归"只有一枚关闭按钮"**：区域名卡片与"清除路径点"按钮移除（路径点改为**再次点击原地清除**）；修复关闭按钮点不动的 bug——按钮原在拖拽层内部，`setPointerCapture` 会把后续指针事件全部截给拖拽层，click 永远到不了按钮（现已移出拖拽层且拖拽层跳过 button 起点）；关闭按钮重绘为磨砂玻璃圆钮（渐变白 + 内高光 + 悬停旋转放大），✕ 加粗。

**第九、十轮（图标包化、真开关设置页、书页帮助、云雾粒子、体力奔跑）**

- **HUD 图标包化**：三枚图标去掉环形边框（地图=折叠航海图、帮助=问号、设置=描线齿轮），键帽字幕改为无底白字；关闭按钮统一为**手绘叉**（两笔微弧、圆头），悬停显示阴影，无圆形底。
- **设置页**：单页不分类（去掉左侧分类栏），白半透明+高斯模糊；**真开关**（滑动旋钮式 Switch，不再是"已开启/已关闭"文字）；分辨率改 50%/75%/100% 三选；渲染精度 0.1 步进（0.5–2.0）；视野距离 50–150（默认 60）；选项文字放大（21px 标题/14px 说明）；重置世界改为按钮+**居中确认弹窗**。
- **帮助书页化**：左右两页真书摊开，点页边/箭头翻页（两份对页：操作|世界、手册|封底），「旅途」章节删除，排版放大。
- **世界迷雾粒子化**：前排 = 72–200 朵**带明暗的积云精灵**（顶亮底影贴图，缓慢环游），后排 = 三层淡化的"空气墙"圆柱；走过雾界直接穿行（本就是纯视觉层）。
- **加载完成 = 云朵散开**：三层云 bank 向不同方向吹散（mistCloudA/B），配合整页溶解。
- **右键奔跑 + 体力**：右键（或 Shift）奔跑，体力 5.2s 耗尽、间歇 0.9s 后 4s 回满；底部居中出现细体力条（未消耗时隐藏）。
- **音乐重做**：合成低鸣换成**八音盒式 C 五声音阶拨弦小调**（正弦体+八度泛音、指数衰减、稀疏留白、两小节和弦垫），轻快悦耳。
- **地图手感**：烘焙延迟化（拖拽期间不烘焙，松手 50ms 后补烤 1536px 瓦片）——拖动不再卡死；迷雾改用画布自带的 worldSpan 对齐（修"迷雾与地形分层"）；未探索云层加浓（0.88 底+云斑），不透出地形。
- **史莱姆**：穹体改**上小下大半圆**（belly 1.0 → crown 0.34）；角改**果冻水滴**（深青半透明球体沉入冠部）；跳跃落地挤压 ×1.6（弹簧 205/14 回弹更弹）；移动前倾 0.32+转向侧倾 0.42。

**第十一轮（贴合与翻页细化）**

- **体力条**移到史莱姆头顶（引擎每帧投影锚点，HUD 以帧率跟随），只在消耗后出现。
- **史莱姆角并入壳体几何**（Crown droplets 直接长在 bodyGeo 上，挤压/涟漪/倾斜全部同步形变，永不"贴上去"或穿模）；穹体改真半圆（belly 1.0 → crown 0.14）+ **顶部深青、腹部浅色**的纵向渐变。
- **坡度贴合**：每帧采样脚下高度梯度，身体向坡面倾斜，腹部始终坐在斜坡上。
- **树不穿模**：栽深 0.06→0.22、坡度上限 0.36–0.44；区域植被 minH 1.5 不再长在水线上；陆桥重叠加深（coast+0.42·radius），鞍部高于潮线可步行。
- **天空建模云移除**（buildClouds 不再加载）；**雾界粒子改纯白**（贴图白顶+极淡冷底，圆柱层减淡到 0.42/0.3/0.18），不再有"黑云压境"。
- **冲刺提速** 5.4→7.0；**遮挡虚化**：树/岩石家族落在镜头与史莱姆连线时整族淡至 0.16。
- **UI 细节**：三图标改**实心半透明**（填充 + 88% 不透明度）；重置按钮只写「重置」、白色胶囊统一风格；环境音乐**默认开启**，加载完成后自动解锁播放。
- **帮助书**：真 3D 翻页（sheet rotateY 过书脊，中途可见纸页透视）、写实纸张（fore-edge 帛书线、书脊谷影、封面板）；A/D 翻页，页角只剩白色箭头图标（无文字）；内容分页排布无滚动条。
- **加载散雾逐步化**：遮罩分 35/65/85% 三段渐隐，两层云团错峰离场。

## 与设计稿的关系

`design/` 原型设计包已按用户要求删除；实现沿用了其视觉 token（墨青渐层、暖象牙白、雾金、4/8px 间距、120–240ms 动效）与信息层级，但**不是对设计稿的像素复刻**：设计稿背景为 SVG 示意，本实现是真实 3D 世界。三维画风、模型与地形以本实现为准。

## 实测数字（Chrome headless + SwiftShader 软渲染，1920×1080，静止待机）

| 指标 | 实测 | 契约目标 |
|---|---|---|
| 帧率 | 165 fps（软渲染下，真实 GPU 只会更高） | 1080p ≥45fps ✅ |
| Draw call | 108 | ≤600 ✅ |
| 主场景提交三角面 | 约 662k | 出生岛默认 ≤250k ❌ |

**关于面数仍超预算的说明（如实记录）**：这一轮为了把地形从"低模折面"改成平滑连续表面，地形本体从 23k 提高到约 156k（28×28 细分），同时草加到 4200 丛。植被 LOD 已实现，把提交量从 123 万压到 66 万，但仍高于 250k。

## 踩坑清单（持续更新）

- **共面透明圆盘 + depthWrite:true = 星芒伪影**：太阳三层盘曾因三角扇深度打架画出放射尖刺；透明盘一律 `depthWrite:false`（depthTest 照常）。
- **`scene.background` 贴图会被二次编码洗成灰白**：卡通天空最终用「透明画布 + 页面层 CSS 渐变」实现，色调零损失。
- **`setPointerCapture` 拖拽层内的按钮收不到 click**：控件必须放拖拽层外，或 pointerdown 里对 `closest('button')` 直接跳过。
- **Sprite 想在世界里发光必须 `fog:false`**，否则会被场景雾按距离洗掉（测试时红色精灵变粉就是它）。
- **验证相机朝向别手摆**：`g.update()` 每帧用第三人称控制器覆盖 camera.position/lookAt；要用 `g.cam.frame(yaw, pitch, dist)`。
- **`ridgedFbm` 生成地形会出现月球坑**：山体噪声已换平滑 `fbm`。
- **雾粒子的高度带要对着相机眼高调**：云朵 y 低于山脊就会被丘陵挡住，看起来“没渲染”。
- **App 的 fogSpan 状态可能滞后一拍**：地图上迷雾直接读遮罩画布自带的 worldSpan，否则云层与地形“分层”。
- **IAB 面板被遮挡时 rAF 节流**：游戏循环看似死亡（visibilityState 仍 visible、定时器正常）；另外 `waitForLoadState` 必须传对象 `{state:'domcontentloaded'}`，传字符串会被展开成 16 个 key 报错。
- **地图烘焙要延迟**：拖拽期间反复重排定时器，松手 50ms 后再补烤瓦片，否则拖动卡死。

## 当前限制（如实记录）

- **面数仍超预算**：662k vs 250k。需要地形分级细分与草地贴片实例化，尚未实现。
- LOD 按**离岛心距离**静态分级，不是按相机距离动态切换；玩家走到远处时，脚下的树仍是简化版。
- 尚无音频；设置里的音量项保留但未接入。
- 迷雾聚力目前只推进 HUD 状态与本地计数，不触发后台扩环作业（零件 30–32 未实现）。
- 世界固定为 100 BU 出生岛，尚无环拓荒、AI 生成、天气与昼夜循环。
- 树木/岩石为程序化合并几何 + InstancedMesh，尚无 GLB 管线（零件 14/15 未实现）。
- 触屏布局已实现，但仅在桌面浏览器模拟手势下验证，未在真机复测。
