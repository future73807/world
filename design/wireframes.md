# 迷雾群岛 · UI 线框与信息层级（从零设计）

> 本文件只做结构评审。高保真效果图见 `design/*.html` 与 `design/screenshots/*.png`。
> 所有布局保证：角色与前方道路安全区不被遮挡，默认 ≥80% 画面为世界。

## 1. 默认游玩 HUD

### 桌面（1920×1080，安全边距 28/24）

```
┌──────────────────────────────────────────────────────────────────┐
│ ◯小地图 168px            世界可见区（无面板）        ◯地图 ◯目标 ◯暂停 │
│  区域名 · 时刻/天气                                       （键位提示）│
│ ▸ 主目标一行                                                     │
│   · 子项  · 子项（至多2条）                                       │
│                                                                  │
│                    【前方道路安全区】                              │
│                     （中央 60% 无任何常驻元素）                     │
│                                                                  │
│                        ◇ 情境互动提示                              │
│                        [E] 触摸迷雾 · 蓄力环                       │
│                                                                  │
│ 史莱姆状态（水滴/体力，仅真实信息）                                │
└──────────────────────────────────────────────────────────────────┘
```

- HUD 容器 `pointer-events:none`，仅真实控件接收事件。
- 不显示虚拟摇杆；无三栏、无常驻日志、无血条背包等虚构属性。

### 触屏（844×390 横屏，避开系统手势区）

```
┌────────────────────────────────────────────────────┐
│ ◯小地图120px                              ◯地图 ◯暂停 │
│ ▸ 主目标一行                                         │
│                                                    │
│   左下虚拟摇杆区        【前路安全区】    右侧滑动环视区 │
│   （拇指自然位）                        ⤒跳跃 ⤳冲刺 Ⓔ互动│
└────────────────────────────────────────────────────┘
```

- 底部预留 20px 手势安全区；右侧环视区不与按钮重叠。
- 情境提示改显示触屏图标，不显示 `[E]` 键帽。

## 2. 全屏地图

```
┌──────────────────────────────────────────────────────────────────┐
│  世界地图                                    图例/筛选 ▾      ✕    │
│ ┌──────────────────────────────────────────────────────────────┐ │
│ │   同源世界俯视图：已解锁清晰 / 未解锁同色雾                     │ │
│ │   ◇地标   ⚑路径点（选中→轻详情）        ▲玩家朝向              │ │

```

- 世界压暗但保留；Esc/M/✕ 返回原状态；不自动传送玩家。
- 图例与筛选在按需底部抽屉，触屏可单手关闭。

## 5. 情境互动反馈

| 状态 | 表现 |
|---|---|
| 接近可互动对象 | 对象锚点出现细线光环 + 输入图标 + 动作词 |
| 按住蓄力 | 环形进度 240ms 起步，沿对象锚点收拢 |
| 取消 | 环反向消散，文字提示「已取消」并淡出 |
| 成功 | 雾面退散 + 小型金色粒子 + 目标更新提示 |
| 失败/不可达 | 提示变为低饱和红并说明原因，不阻塞移动 |

## 6. 开发者工具入口（与玩家 HUD 隔离）

- 默认完全不出现。仅通过 `` ` `` 或设置内显式开关进入独立 `developer` 状态。
- 独立日志 / CLI / 性能面板，使用另一套密度更高的排版，不与玩家 HUD 同屏。
