## 素材与字体来源

- **图标**：全部本包原创 SVG，无外部游戏图标、无图标库默认皮肤。
- **背景与插画**：本包原创 SVG 多边形，仅用于评审 HUD 与世界的关系。
- **字体**：设计稿使用 Windows 系统随附的 SimSun/NSimSun（标题宋体）与 Microsoft YaHei（正文），仅用于本机设计评审，**未复制任何游戏字体**。
  进入实现与发布阶段时，标题/正文替换为可分发的思源宋体 / 思源黑体（SIL OFL），并在 `app/` 内附带 license 文本；在此之前不打包系统字体文件。
- **配色**：由世界色板（苔青、雾青、浅滩沙金）推导，未采样其他游戏色值。

## 设计自查

| 检查项 | 结果 |
|---|---|
| 默认 HUD 无三栏、无常驻日志、无后台表单 | 通过 |
| 中央前路安全区无任何常驻元素，世界占画面主体 | 通过 |

| 触屏操作区 44px 点击区、底部手势安全区、无键帽提示 | 通过 |
| 地图路径点/回到玩家/缩放/轻详情/关闭恢复 | 通过 |
| 设置含操作/镜头/画面/声音/舒适性，危险操作独立 | 通过 |
