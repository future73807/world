# 宇宙模拟软件对照表 · 可选功能取舍

> 参照对象：SpaceEngine、Universe Sandbox。
>
> 本表只帮助决定可选宇宙章节“要不要做某项能力、为什么简化”。它不是 UI 参考、美术参考、实时架构或完成度声明。核心浮岛游戏未通过 G0/G3/G4 前，不启动本章。

---

## 1. 参照对象提供的是设计问题

| 参照对象 | 值得研究的问题 | 不能直接搬用的部分 |
|---|---|---|
| SpaceEngine | 从地表到太空的连续观察、广阔尺度、天体与大气表现 | 写实材质、真实星表、海量星系、观察器式 UI、截图与资产 |
| Universe Sandbox | 改参数后世界如何响应、时间控制、轨道与气候因果 | N 体混沌、破坏性碰撞/超新星、参数面板主导的产品结构 |

这些参照不决定迷雾群岛的颜色、模型、图标、字体、镜头参数或面板布局。所有天体仍采用原创低模/示意表现；所有编辑 UI 都重新设计。

---

## 2. 本项目的选择

| 设计问题 | 本项目选择 | 取舍理由 |
|---|---|---|
| 世界范围 | 一个虚构小星系，1～7 颗行星；宇宙是可选观察层 | 保持玩家与自己的浮岛之间的联系 |
| 地表与太空关系 | 同一座岛经球面投影形成观察副本，地表存档仍唯一 | 不在球上另造一套世界，不重置已解锁地表 |
| 尺度 | 明确标注“示意”的压缩轨道与天体尺寸 | 真实比例会让行星不可读；不能以假比例冒充科普 |
| 轨道 | 开普勒解析解 + 受限的弱扰动 | 可预测、可跳时间，避免混沌毁掉玩家世界 |
| 时间 | 可加速、减速、倒流与跳到指定时刻 | 解析表达式可稳定求值，不积累积分误差 |
| 地表因果 | 若做 49，可用少量参数影响跳跃、雪线、昼夜和潮汐 | 只保留玩家能实际感知的因果，不堆物理名词 |
| 大气与天体 | 有限色板、低模球面、受光侧辉光、简化云壳 | 与地表原创低模保持同一视觉语言 |
| 编辑 | 非驻留的暂停/设置界面，草稿→预览→显式应用 | 默认 HUD 不出现参数表单，应用成本可理解 |
| 毁灭性事件 | 不做超新星、星系碰撞或删除家园的玩法 | 玩家世界不能被无关模拟永久摧毁 |

---

## 3. 不做与暂不承诺

- 不做星系级真实尺度、真实星表和数十亿天体。
- 不追求高精度 N 体、相对论、引力透镜物理正确性或航天器任务系统。
- 不用“视觉等价”“成本降低 100 倍”等没有测量的宣传数字。
- 不在文档中把尚未开发的宇宙能力写成“已完成”。完成状态只能引用浏览器实机验收。
- 不做实时碰撞毁灭、超新星、多宇宙和平行存档等破坏核心体验的功能。
- 不把 Blender 作为星图、轨道动画或玩家视角的实时运行时。

---

## 4. 交互和视觉边界

1. 地表默认仍只有轻量小地图、目标、状态和情境提示。
2. 星图只在展开地图或 cosmos 观察状态出现，不与地表小地图挤在同一个常驻侧栏。
3. 轨道、星球列表和物理编辑器采用新的可关闭界面；不能用旧三栏把 3D 视图夹在中间。
4. 点击星图直接改变 Three.js 观察状态，不向 Blender 发玩家控制指令。
5. 所有天体、图标、云、轨道线和动效都从新设计生成，不下载或临摹参照软件素材。
6. 过渡期间不能偷偷重置玩家、地表 ring、seed、天气或时钟。

---

## 5. 验收方式

本章不以“对标了多少功能”计分。若选择实现，只验收：

- 地表→星球→宇宙→返回在浏览器中连续完成。
- 同一时间和轨道输入下，星图与 3D 位置一致。
- 参数编辑有预览、成本提示、校验、撤销和关闭返回；输入不穿透到地表角色。
- 尺度压缩明确标注，未测的物理效果不写“已实现”。
- 天体视觉与原创低模世界一致，没有变成写实资源合集或后台管理软件。
- 核心地表验收保持通过；可选功能未做时如实标“未做”。
