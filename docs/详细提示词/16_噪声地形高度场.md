# 16 · 噪声地形高度场

> **一句话**：用两层噪声叠出"有主峰、有缓坡、有小起伏"的高度场，并让它按世界坐标求值——这样流式装出来的块天然无缝。

---

## 前置

零件 15（区块框架与平坦地面已跑通）、零件 12（派生种子）。

---

## 提示词正文

你是**地质师**。目标是一个纯函数：给世界坐标 (x, y)，返回高度 z。其它一切（海岸、沙滩、着色、撒树）都建立在这个函数上。

### 步骤 1 · 高度函数的三层结构

高度函数的语义是：**基础起伏 + 主峰体 + 微细节**，三项相加。

**基础起伏**
- 低频噪声。参数：`freq_base`（默认 0.012）、`amp`（默认 4.5）。
- 作用：整体地势的缓慢起伏，决定"这是一片平原还是丘陵地带"。

**主峰体**
- 以岛屿中心为顶点的一个径向衰减包络，叠加一点角度扰动，让山体不对称。
- 参数：`peak_height`（来自 spec.terrain，8~26）、`peak_radius`（默认 26 BU）、`peak_asym`（0~0.6）。
- 不要做成完美圆形——圆形的山一眼假。

**微细节**
- 三层中高频噪声，振幅递减（例如 1.2 / 0.45 / 0.15），频率递增（0.05 / 0.11 / 0.23）。
- 用"绝对值和"或"尖峰化"让山脊有棱角，符合低模气质。

### 步骤 2 · roughness 的作用

spec 里的 `roughness`（0~1）同时控制：

- 微细节三层的振幅乘子（0.4 + 1.6*r）
- 基础起伏的振幅乘子（0.6 + 0.8*r）
- 山脊锐度：r 越大越尖锐（对噪声取绝对值再取幂）

**一个参数改三处**，这样"粗糙"是一个可感知的性格，而不是一个孤立数字。

### 步骤 3 · 峰值对称与多峰

允许（不是必须）在 `peak_radius` 之外再造 1~2 个"次峰"：

- 位置由 `derive(seed, "subpeak")` 决定，落在岛内、离主峰至少 18 BU。
- 高度是主峰的 0.35~0.6。
- 次峰要能"读出来"是天际线上的一处隆起，不是噪点。

### 步骤 4 · 接入区块

把零件 15 的平坦地面换成真实高度：

- 每块 17×17 顶点，顶点世界坐标 = 块中心 + 本地坐标。
- 直接调高度函数，**不许采样别的块**。
- 接缝一致性靠"同坐标同函数"天然保证。
- 生成后 `shade_flat`（平面着色）留给零件 18，这里只保证几何正确。

### 步骤 5 · 全局最小值/最大值

生成后统计整岛高度范围：

- 最低点应 ≥ -8（水下也在此范围）。
- 最高点应 ≈ `peak_height`（误差 ±0.5）。
- 若误差过大 → 是径向包络没归一化，修好再继续。

把实际 min/max 与 peak_height 写进汇报。

### 步骤 6 · 五处采样验收

在 (0,0)、(±40, 0)、(0, ±40) 五个点打印高度，确认：

- 中心最高
- 四周递减
- 无 NaN、无突兀跳变

### 步骤 7 · 截图

两个机位：正俯视（看岛形）、贴地 15° 仰角（看山脊轮廓）。存 `runtime/shots/step_16_*.png`。

## 参数表

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `freq_base` | 0.012 | 0.004~0.03 | 低频 |
| `amp_base` | 4.5 | 2~8 | |
| `peak_radius` | 26 | 14~40 | 主峰影响半径 |
| `peak_asym` | 0.35 | 0~0.7 | 山体不对称 |
| `detail_amps` | 1.2 / 0.45 / 0.15 | | 微细节三层 |
| `detail_freqs` | 0.05 / 0.11 / 0.23 | | |
| `subpeaks` | 1 | 0~2 | 次峰数 |
| `ridge_power` | 1.6 | 1~3 | 山脊锐度基线 |

---

## 验收标准

1. 整岛高度 min/max 落在 [-8, peak_height+0.5]。
2. 中心明显高，四周缓降，天际线有 1~3 处隆起。
3. 五处采样数值合理、无 NaN。
4. 相邻块接缝无裂缝（贴地截图确认）。
5. 两张截图已存。
6. `roughness` 从 0 调到 1，地貌风格明显变化（各截一张对比图加分）。

---

## 回退方案

- **山看起来像一个圆包**：加大 `peak_asym`，并在包络里叠加低频噪声（乘以 0.8~1.2）。
- **噪点太多像砂纸**：降第三层细节振幅到 0.08 以下，或把最高频层的顶点密度降一档。
- **性能掉**：先用 9×9 顶点验证形态，满意后再升 17×17。
