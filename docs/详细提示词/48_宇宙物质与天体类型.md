### 步骤 1 · 天体类型清单（十种）

| 类型 | 关键参数 | 视觉要点 | 能否降落 |
|---|---|---|---|
| `star` 恒星 | `mass`、`radius`、`palette.core/corona`、`luminosity`、`temperature_k` | 自发光球 + 光晕 + 日冕 | 否（提示"太热了"） |
| `planet` 行星 | 见 43 | 球面地形 + 大气 + 云 | **能**（地表玩法） |
| `moon` 卫星 | `a`、`period`、`radius`、`palette` | 小、有环形山（薄环感） | 能（简化地表：只环 0） |
| `asteroid_belt` 小行星带 | `count`、`a_inner`、`a_outer`、`thickness`、`size_range` | 一圈细碎点（实例化，300~1200 个） | 否 |
| `comet` 彗星 | `a`、`e`（大偏心率 0.6~0.9）、`period`、`tail_length` | 亮核 + 一条拖尾（**朝向背离恒星**） | 否 |
| `nebula` 星云 | `radius`、`palette` 2~3 色、`density` | 半透明体积感色团（低模：多层噪声面片） | 否（可"穿过"） |
| `ring` 行星环 | `inner_r`、`outer_r`、`tilt`、`palette`、`opacity` | 扁平环形带 + 细密条带 | 否 |
| `binary_star` 双星 | 两个 `star` 互绕（`a`、`period`、`mass` 各自） | 两个发光点互绕，阴影会**双重** | 否 |
| `black_hole` 黑洞 | `mass`、`disk_r`、`disk_tilt` | 黑球 + 吸积盘（亮橙环）+ 引力透镜扭曲背景（用一层屏幕扭曲 shader） | 否（提示"会被撕碎"） |
| `ruin` 废弃构造 | `kind`（`ring_world`/`dyson_shard`/`wreck`）、`scale` | 巨大几何残骸，缓慢旋转 | 能（无地表玩法，只有遗迹） |

**不做**：中子星、脉冲星、星系本身（那是另一个尺度）、暗物质可视化。

### 步骤 2 · 小行星带（性价比最高的一个）

- 300~1200 个小多面体（每个 3~6 面），**必须实例化**（一个网格数据块）。
- 分布：环带内随机 `a`、随机角度、`thickness` 内上下抖动（`z` 方向 ±0.4 RU）。
- 整带绕恒星**缓慢公转**（同一 `period`，内圈略快——用差速：`period ∝ a^1.5`）。
- 每个小行星**自转**（随机轴、随机速度）。
- 不投影（省）；接收恒星光照（近侧亮）。
- 视觉检查：从内圈看过去应该像"一条由碎屑组成的河"，不是均匀撒的星点。

### 步骤 3 · 彗星

- 核：一个 0.05~0.15 RU 的亮核（自发光）。
- 尾：一条**从亮核沿背离恒星向量延伸**的锥形薄带（长 2~6 RU），越远越淡、越宽；不能改成简单沿速度反方向。
- **拖尾永远背离恒星**（不是背离运动方向——真实彗星尾是太阳风吹出来的）。这一点做对，懂的人会认出来。
- 大偏心率轨道（0.6~0.9），所以会"远远地来、擦着恒星过去、再远远地走"。
- 最多 1~2 颗。

### 步骤 4 · 星云

- 3~6 层同心/错位的半透明噪声面片（不是体积雾，是面片）。
- 两到三色叠加（例如粉 + 青 + 深蓝），透明度 0.05~0.18，极大（半径 8~25 RU）。
- **缓慢旋转且内部漂移**（不同层不同速度）→ 产生"云在流"的错觉。
- 放在星系外围，不挡视线中心；若挡住恒星，把层透明度再降一半。
- 星云内的行星可以带一点点该色相的偏色（可选）。

### 步骤 5 · 行星环

- 一个扁平环（内外半径比 `0.55~0.85`），`tilt` 与行星自转轴一致（这样"赤道环"看起来合理）。
- 不是均匀色带：细密条带（8~20 条厚薄不同的同心带）+ 一条明显的"卡西尼缝"（一道半透明缺口）。
- 环**不投影**，但在行星表面投下一道淡影（可选，很加分）。
- 环的朝向必须与行星自转轴对齐，否则一眼假。

### 步骤 6 · 黑洞与引力透镜（视觉）

- 核心：纯黑球（完全不反射）+ 一圈极亮的吸积盘（薄、亮橙白、快速旋转）。
- **引力透镜**：在黑洞周围做一层屏幕扭曲（后处理或一个扭曲球壳），把背景星空向中心"吸"进去。
- 若引擎不支持后处理扭曲：退化为"一个黑球 + 一圈被拉长的星空条纹"（预烘一张贴图）。
- 黑洞周围不放置可降落行星（提示"轨道不稳定"）。

### 步骤 7 · 双星

- 两颗恒星互绕（质心在两者之间，质量大的绕小圈）。
- **阴影会双重**（两个光源）——这是最直观的"双星"证据，务必保留（若性能吃紧，至少让主星强、副星弱）。
- 行星可以绕双星（"环形轨道"或"8 字形"——只做环形，8 字不稳定且难看清）。

### 步骤 8 · 与编辑器（47）的对接

每种天体在 47 的非驻留工作台里都要有对应的字段组；一次只编辑一组，不堆叠编辑卡或形成常驻面板：

| 类型 | 可改字段 |
|---|---|
| `asteroid_belt` | `count`、`a_inner`、`a_outer`、`thickness`、`size_range`、`palette` |
| `comet` | `a`、`e`、`period`、`tail_length`、`palette` |
| `nebula` | `radius`、2~3 色、`density` |
| `ring` | `inner_r`、`outer_r`、`tilt`、`opacity`、条带数 |
| `black_hole` | `mass`（只影响吸积盘大小与透镜强度）、`disk_r`、`disk_tilt` |
| `binary_star` | 两星的 `mass`、`radius`、`a`、`period` |

**编辑一条规则**：物质（非行星）的编辑**永远不需要重建地形**，只更新参数，通常无需重建地形。实际响应时间在浏览器中测量并在 UI 提示，不能预先承诺固定毫秒数。

| 天体 | 预算 |

### 步骤 10 · 验收

1. 十种天体各自可见（截图）。
2. 小行星带像"河流"而非星点。
3. 彗星尾背离恒星（关键细节）。
4. 星云在流、不挡恒星。
5. 行星环与自转轴对齐。
6. 黑洞有吸积盘与（若可行）透镜。
7. 双星有双重阴影。
8. 每种天体在编辑器里有对应卡片，改动是毫秒级。
9. 性能数字记录。

## 回退方案

- **小行星带掉帧**：降到 300，并只在相机距离 < 40 RU 时渲染。
- **星云糊成一片**：层数降到 3，透明度提高单层但减少重叠。
- **黑洞透镜做不出**：用贴图方案（预烘一张"扭曲的星空环"），视觉上仍然成立。
- **双星阴影性能翻倍**：只保留主光投阴影，副光不投影。
- **彗星尾像光剑**：尾必须有宽度渐变（末端宽、根部窄）与透明度衰减。
