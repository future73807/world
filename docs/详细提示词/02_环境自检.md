## 提示词正文
> **共同硬约束（独立执行本零件也必须遵守）**
> - 主游玩端是浏览器全屏 Three.js/WebGL；Blender 只负责从零生成、导出和离线检查，禁止把“打开 Blender”作为玩家步骤。
> - 恢复包中的任何文件均不得读取、参考或导入；所有 UI、模型、材质和动画从空白重新设计，禁止迁移、换皮或使用外部游戏/现成模型包资源。
> - 目标是**精致风格化低模**：大/中/小结构、合理拓扑与平面/分组平滑/加权法线、原创程序化材质和近景细节。低面数不等于简陋，禁止方块、体素、像素纹理和粗糙 primitives 通过。
> - 新模型先交剪影、灰模、材质完成图及近/中/远实机证据；美术不合格不能用低面数、帧率或“非 MC”豁免。
> - 新 UI 先交桌面/触屏线框和高保真 HUD/地图/暂停/创建/互动设计稿，使用原创图标、合法字体和统一 token；只参考开放世界游戏的信息层级，不复制具体素材。
> - 默认第三人称跟随。角色具有起步、移动、停止、转向、跳跃预备、上升、顶点、下落和落地；桌面 WASD/指针锁定/空格/Shift/E/M/J/Esc，触屏才显示虚拟控件；松鼠标不强制回正。
> - 禁止三栏/左右常驻面板/常驻日志。CLI 与性能工具默认隐藏，创建、设置、编辑只在高保真非驻留界面。
> - 本零件与上述约束冲突时，上述约束优先；若正文仍存在旧指令，停手报告，不擅自回退产品方向。

你是**体检医生**。这一轮不造世界，只出体检报告。全部检查用只读方式，不改任何东西。

### 步骤 1 · Blender MCP 连通

调 `get_scene_info`（若失败，你的 MCP 版本可能没有这个工具，改用 `get_addon_status`）。记录：

- 是否返回正常
- 场景当前对象数
- Blender 版本字符串（若工具没给，调 `execute_blender_code` 读 Blender 的版本字符串）

### 步骤 2 · 截图能力

调 `look`（或 `get_viewport_screenshot`）。成功则记下图片尺寸与保存位置；失败记下错误原文。这是后面每个零件验收的基础，不通过就先修它。

### 步骤 3 · Blender CLI 本体

在终端跑 `blender --version`。再用后台模式（`-b`）配一个只读的版本探测表达式跑一次，确认三件事：能启动、能打印到 stdout、能正常退出。**注意**：探测表达式只读版本号，不带任何会写文件的参数。

### 步骤 4 · 运行时依赖

依次确认并记录版本：`node --version`、`npm --version`、`python --version`。若 `python` 指向 Windows 商店占位符（运行后弹商店），改用 `py --version`，并在报告里注明最终用哪个命令。

### 步骤 5 · 图形与硬件粗测

读一下 GPU 型号（Windows 可用 `wmic path win32_VideoController get name`），记下。它只影响性能预算，不影响开工。

### 步骤 6 · 生成报告

写 `runtime/env_report.md`，结构如下：

**标题**：迷雾群岛 · 环境自检 · 日期
**一张五行表**：检查项 / 结果（✅ 或 ❌）/ 值或错误摘要
**一段"结论"**：能否开工；若不能，缺什么、最短修复路径三条以内
**一段"建议的引擎设置"**：渲染引擎用 Eevee 还是 Cycles、分辨率、采样数（按 GPU 给出保守值）

## 参数表

| 参数 | 默认 | 说明 |
|---|---|---|
| `MIN_BLENDER` | 3.6 | 低于此版本中止并报告 |
| `RECOMMENDED_BLENDER` | 4.2 | 低于此版本：体积雾/几何节点可能缺特性，标注但可继续 |
| `MIN_NODE` | 20 | 低于此版本中止网页部分 |
| `PROBE_TIMEOUT_S` | 30 | 任何单条命令超时按 ❌ 记 |

---

## 验收标准

1. `runtime/env_report.md` 存在，含五行表 + 结论 + 引擎建议。
2. 五项检查每一项都有确定结论（不许"未测"）。
3. 没有改动场景、没有创建 .blend。
4. 若某项 ❌，报告里给出不超过三条修复路径。

---

## 回退方案

- **MCP 工具名不对**：先调一次 `execute_blender_code` 打印 Blender 版本字符串。能通就说明连接正常，只是工具名差异，记下来，后面统一用能通的那个。
- **Blender 不在 PATH**：不要自己去装。报告里写"未安装/未在 PATH"，把安装页链接和"装完后重跑零件 02"一起给出，停手等用户。
- **Node 缺失**：网页阶段整体跳过，先行做阶段 3（世界与史莱姆），把 `app/` 留给用户装好 Node 后再补。
