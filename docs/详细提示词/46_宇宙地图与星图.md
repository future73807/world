# 46 · 宇宙地图与星图 UI

> **一句话**：网页里给你两张图——地上的地图，和天上的星图；点一颗星就能回那去。

---

## 前置

零件 33（地表地图）、43（宇宙设定卡）、45（视角状态机）。

---

## 提示词正文

你是**星图绘制员**。地表地图（33）已经有了，这一零件补上"宇宙级"的那一半，并让两者能互相跳转。

### 步骤 1 · 三种缩略视图（不是三套实现）

网页右栏的地图容器，根据 `world_state.json` 的 `view` 字段切换内容：

| `view` | 显示 | 来源 |
|---|---|---|
| `surface` | 地表 2D 地图（零件 33，已有） | `runtime/map_tiles.json` |
| `planet` | 球面缩略（把一个球用小尺寸渲染） | 直接取 Blender 截图 / 或 CSS 3D 球 + 贴图 |
| `cosmos` | 星图（俯视轨道图） | `specs/universe_spec.json` + 实时位置 |

**关键**：三者**同尺寸、同位置**，切换时交叉淡入（不是重新布局）。这样"从地面看到星图"是一个连续的动作，不是跳页面。

### 步骤 1B · 单星球形态的星图

`planets` 长度 = 1 时，星图退化为一张"名片"：

- 不画轨道，只画一颗球（居中）+ 恒星（可选，画在一角）。
- 底部一行：`{宇宙名} · 只有一颗`。
- 依然可点它 → 切 `planet` → 再切 `surface`。
- **别把它做成"空荡荡的轨道图"**——那会显得像加载失败。

### 步骤 2 · 星图怎么画

用 Canvas 2D，俯视整个轨道系统：

- 中心 = 恒星（一个带光晕的圆）。
- 每颗行星 = 一条椭圆轨道 + 一个圆点。轨道按 `inclination` 做**透视缩短**（乘 `cos(inclination)`），这样看起来是斜视图而非纯平面图。
- 轨道线颜色 = 该行星 `palette.accent` 的 25% 透明版。
- 行星圆点半径 = 该星球的 `render_d` 映射到 2~6px。
- 行星**实时公转**（读 42 的解析位置，按 `t` 计算）——地图上的点动起来，与 3D 里一致。
- 选中行星：外圈一光环；悬停：显示名字。

**不要**画成"太阳系示意图"：不要标注半径数字、不要假比例尺。它是一张"星图"，不是天文教材。

### 步骤 3 · 星图上的四件事

1. **当前所在星球**：一个更亮的描边 + 一个小三角标记（像"你在这里"）。
1b. **你的世界**（`origin=grown`）：额外一层浅金色细描边 + 悬停卡标注「你的世界」。与"当前所在"是两个独立标记（你可能在邻居星上看风景）。
2. **点击行星**：发指令给 Blender → `cosmos → planet` 过渡（零件 45），并选中该星球。
3. **双击行星**：直接进 `surface`（如果那颗星球已生成过地表世界；否则提示"这颗还没去过"）。
4. **拖拽可旋转星图**（改变观察角，不做 3D，只是把椭圆的朝向转一下）——增强"宇宙是立体的"感受。

### 步骤 4 · 与地表地图的互相跳转

这是"多星球"体验的关键：两张图之间要有一条**连续的路径**。

- 地表地图右上角加一个小圆钮「↑ 星球」（点它 = 切到 `planet` 视角）。
- 星图上选中某颗星，面板底部出现「↓ 下去看看」（点它 = 切到那颗星的地表）。
- 切过去之后，地表地图自动定位到史莱姆所在位置（不是默认原点）。

**过渡文案**（提升质感）：

- 上去：`离开地面…`
- 下来：`正在降落…`
- 完成：`到了 · {星球名}`

### 步骤 5 · 星图信息卡

悬停或选中行星时，右下角出现一张薄卡片：

- 星球名 + 一句 `note`
- 三个小信息：biome、天气、生物生机（用小图标或色块）
- 一行"距恒星：`{a}` AU（示意）"—— **明确标注"示意"**，因为 42 已经说明尺度是压缩的。
- 一个「编辑这颗」按钮（跳零件 43 的编辑区）。

### 步骤 6 · 行星地表缩略（`planet` 视角的右栏）

不重新渲染，直接两选一：

**A. 截图法**（省事）：Blender 侧每次进入 `planet` 模式时截一张 320×320 的球体图，存 `runtime/shots/planet_{id}_thumb.png`，网页直接显示。

**B. CSS 3D 法**（更活）：一个 `border-radius: 50%` 的 div，背景用径向渐变（受光侧亮）+ 一个 `conic-gradient` 的云带 + `box-shadow` 外发光（大气）。用 CSS 动画让它缓慢自转。

推荐 **A**（真实），B 作为加载中的占位。两者要有相同的尺寸与圆角，避免闪烁。

### 步骤 7 · 性能与节流

- 星图 Canvas 20fps 足够（与 33 一致）。
- 只在 `view !== surface` 时绘制星图；地表模式下完全停掉（省 CPU）。
- 行星位置每秒从 Blender 读一次，中间用本地时间推算（解析式，可插值）。

### 步骤 8 · 验收

1. 三种缩略视图在同一容器内交叉淡入切换。
2. 星图上的行星在公转，位置与 3D 一致（对比截图）。
3. 点击行星 → 3D 里真的飞过去。
4. 「↑ 星球」/「↓ 下去看看」两条路径都通。
5. 信息卡的"示意"标注清晰，不误导。
6. `planet` 视角右栏有球体缩略（真实或占位）。
7. 星图 20fps，无卡顿。
8. 六张截图（地表图、星图、悬停卡、切换中、星球缩略、移动端窄屏）。

## 回退方案

- **星图与 3D 不同步**：说明两边各算了一次时间；改为"网页只用 `clock` + 解析式推算"，不自己起 `t`。
- **椭圆画得太扁**：`inclination` 取 3~12° 即可，不要 45°（会变成一条线）。
- **切换时地图闪烁**：三视图尺寸不一致；统一容器尺寸与 `border-radius`。
- **CSS 球太假**：把 `thumb_mode` 切回 `shot`。
- **小屏挤**：`starmap_px` 降到 260，信息卡改为底部抽屉。
