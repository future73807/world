## 提示词正文
> **共同硬约束（独立执行本零件也必须遵守）**
> - 主游玩端是浏览器全屏 Three.js/WebGL；Blender 只负责从零生成、导出和离线检查，禁止把“打开 Blender”作为玩家步骤。
> - 恢复包中的任何文件均不得读取、参考或导入；所有 UI、模型、材质和动画从空白重新设计，禁止迁移、换皮或使用外部游戏/现成模型包资源。
> - 目标是**精致风格化低模**：大/中/小结构、合理拓扑与平面/分组平滑/加权法线、原创程序化材质和近景细节。低面数不等于简陋，禁止方块、体素、像素纹理和粗糙 primitives 通过。
> - 新模型先交剪影、灰模、材质完成图及近/中/远实机证据；美术不合格不能用低面数、帧率或“非 MC”豁免。
> - 新 UI 先交桌面/触屏线框和高保真 HUD/地图/暂停/创建/互动设计稿，使用原创图标、合法字体和统一 token；只参考开放世界游戏的信息层级，不复制具体素材。
> - 默认第三人称跟随。角色具有起步、移动、停止、转向、跳跃预备、上升、顶点、下落和落地；桌面 WASD/指针锁定/空格/Shift/E/M/J/Esc，触屏才显示虚拟控件；松鼠标不强制回正。
> - 禁止三栏/左右常驻面板/常驻日志。CLI 与性能工具默认隐藏，创建、设置、编辑只在高保真非驻留界面。
> - 本零件与上述约束冲突时，上述约束优先；若正文仍存在旧指令，停手报告，不擅自回退产品方向。

你是**值班工程师**。顺序固定：复现 → 保存证据 → 定位层 → 最小修复 → 同路径验证 → 记录。无法确认的原因写“未确认”，不能编一个原因收尾。

### 第一层：定位

| 现象 | 优先检查 |
|---|---|
| 浏览器白屏/不是全屏游戏 | 控制台、WebGL 初始化、03 状态机与路由 |
| 画面像旧三栏或旧模型 | 资源来源、恢复包是否被误用作输入；立即停下重新设计 |
| 角色不动/输入穿透 | InputController、焦点、暂停/设置与触屏模式 |
| GLB 加载失败/轴向错 | manifest、URL、hash、唯一坐标适配层 |
| 玩家穿地/相机穿墙 | 同源碰撞、局部原点、L0 与流式切换 |
| 区块裂缝/扩环改旧块 | 纯函数采样、LOD 接缝、不可变版本和 hash |
| 小地图不一致/有棋盘缝 | map_url、同源 color/kind、DPR 与连续路径 |
| 后台失败/状态卡住 | job 日志、fsm、候选完整性与版本指针 |
| 帧率下降 | 浏览器 renderer.info、帧时间、实例和流式压力路线 |

## 症状表

### 1. 首屏变成管理面板或旧 UI

**处理**：立即判方向失败。核对是否从恢复包复制了 DOM/CSS/截图；删除该实现输入来源，回到 03 的新桌面/触屏线框。不要靠缩小侧栏或改圆角补救。

**验证**：默认画面为全屏实时 3D + 轻 HUD，无固定左右栏和日志。

### 2. 地形、树木或角色像方块/外部游戏

**处理**：停止精修，追查几何来源。恢复包、现成模型包和外部游戏资源不得使用；回到 16/22/24 的新剪影、灰模和顶点生成。

**验证**：灰模轮廓为连续三角地形、折伞/叠羽/灯菌树、切面水滴团子；不是换材质后的旧模型。

### 3. 网页打开但角色不动

**可能层**：输入层或运动层，不是 Blender 没开。

**处理**：检查画布焦点、按键状态、暂停/文本输入隔离、dt 循环与同源地面数据。失焦时清空持续输入。

**验证**：关闭 Blender 后仍能走、跳、冲刺、环视；设置打开时输入不穿透。

### 4. 触屏与鼠标反复切换或双跳

**处理**：按最近有效输入去抖，忽略兼容鼠标事件，切换时清空旧持续状态；动作统一映射到同一控制器。

**验证**：交替真实触摸/键鼠，无双移动、双跳或控件闪烁。

### 5. 角色倒立、横躺、大小异常或脚底偏移

**处理**：检查标准 glTF Y-up→游戏 Z-up 的唯一适配层，以及共享 GLB 是否错误烘焙出生点。禁止逐个资产补旋转。

**验证**：契约 `(1,2,3)→(1,3,-2)→(1,2,3)` 样例与 10 BU 尺度测试通过。

### 6. 史莱姆陷地、浮空或跳跃后不回地面

**处理**：检查运动根与视觉根是否混用、碰撞是否与近场 L0 同源、落地事件是否恢复吸附。不要用增加透明地面补丁。

**验证**：坡地、沙滩、块缝、跳跃和扩环切换均无浮空/穿地。

### 7. 相机贴脸、穿地或在树林抽动

**处理**：按 34 检查目标点、球体/多点扫掠、近裁余量与收近快恢复慢。不要把相机抬高成整岛俯瞰规避。

**验证**：贴山、进林、进洞、跳跃、触屏缩放与设置返回均稳定。

### 8. 区块裂缝或 LOD 跳高

**处理**：确认高度纯函数、全局三角化索引、float32 量化与 LOD 交接边一致；不同档不能各用一个简化公式。

**验证**：共享边/横切线采样一致，行走和 LOD 切换无异常台阶。

### 9. 返回后地形/树木变化

**处理**：检查系统随机、加载顺序和缓存 id；同坐标+seed 必须生成同资源与实例。

**验证**：往返前后区块 hash、树种、位置、旋转与尺度完全一致。

### 10. GLB/manifest 加载失败或新旧地图混用

**处理**：检查候选是否完整、manifest URL/hash 是否存在、当前版本指针是否过早切换。失败继续旧版本。

**验证**：GLB、地图、碰撞、spec、ring 同属一个 asset_version；缺文件不会发布。

### 11. 小地图有棋盘格或与脚下不同

**处理**：移除网格缝和逐块随机色；使用 manifest `map_url` 的同源 `kind/color`、共享边路径与 DPR 对齐。

**验证**：无 1px 缝，水/沙/草三个点、玩家 yaw、雾边和 GLB 一致。

### 12. 蓄力满但无法拓荒

**处理**：检查是否已有作业、满环、重复 request_id 或方向已解锁；普通 HUD 必须给出轻量拒绝原因，完整细节在开发日志。

**验证**：重复点击、满环和进行中共三种拒绝不会生成第二作业。

### 13. 扩环后旧地形改变或玩家被重置

**处理**：停止发布，从备份恢复旧状态/版本指针。检查是否重建了整岛、覆盖旧 URL 或用服务端旧快照覆盖实时玩家。

**验证**：旧块 hash 100% 不变；玩家位置、输入、动画和相机 yaw/pitch/dist/弹簧状态连续。

### 14. 新环像贴上去的补丁

**处理**：检查新环一侧过渡带、色板和地标差异；不得为了接缝修改旧块，也不得用复制旧块矩阵充数。

**验证**：从新环走回旧环，视觉/碰撞连续，新环原创轮廓与同族色板成立。

### 15. AI/网络失败导致不能玩

**处理**：进入确定性本地预设，不在线反复重试；记录实际兜底级别。Key 只在非驻留设置中配置。

**验证**：断网/无 Key 也能进入完整游戏，不停在提供商页面。

### 16. 日志、CLI 或编辑器抢占游戏

**处理**：检查 03 的界面状态机和事件隔离。开发工具默认隐藏，创建/设置/编辑只在可关闭界面。

**验证**：默认 HUD 无面板；关闭覆盖界面回到原玩家/相机，输入不穿透。

### 17. 透明史莱姆排序错误或像玻璃/塑料

**处理**：减少相互穿插透明层，统一材质适配与深度策略，保持身体平面切面；不要导入旧球体模型替换。

**验证**：360°环绕时眼、嘴、核稳定，灰模和彩色低模轮廓都成立。

### 18. 帧率低于契约

**处理**：看 35 的浏览器中位/p95、draw call、实际三角面、geometry 与长帧。按草花、小件、远景密度、更新频率、LOD 距离降级。

**验证**：同硬件同路线复测；不把树改方块、不用 Blender 帧率、不关闭核心效果凑通过。

### 19. 进程或状态损坏

**处理**：只终止已验证属于本项目的作业进程；`world_state.json` 从最近有效备份恢复，并修复临时文件+原子替换与互斥。

**验证**：无本项目残留进程，连续写入/崩溃恢复后 JSON 可解析，版本一致。

## 记录新问题

新增条目必须含：**症状 / 实机证据 / 已确认或未确认原因 / 最小处理 / 同路径验证 / 影响面**。

不得把“从恢复包导入旧文件”“用 Blender 截图代替”“隐藏失败项”写成回退方案。

---

## 验收标准

1. 核心链路常见问题都有可执行验证方式。
2. 每次修复保留前后证据，旧版本可恢复，不删除失败记录。
3. 同一故障连续出现 3 次未解决时停手，向用户报告已试方案与待决问题。
4. 排障结论区分浏览器实测、离线资产检查和服务端日志，不相互冒充。

---

## 回退方案

- **问题无法定位**：冻结发布，保留最后可玩版本，缩小到单个 GLB/输入动作/状态转移再测。
- **疑似工具版本差异**：记录 Blender、Node、浏览器、Three.js 与操作系统版本，一次只变一个变量。
- **怀疑需要参考历史版本**：不得读取恢复包。回到本次新设计稿、契约和验收记录排查；任何旧 UI、模型、参数或脚本都不能作为修复输入。
