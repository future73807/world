# 20B · 天气系统

> **一句话**：雨会落、雪会积、雾会漫、风暴会打闪——天气不是背景板，它改水面、改颜色、也改史莱姆手感。

---

## 前置

零件 20（天空与雾）、20A（昼夜循环，天气要跟着时段变）。

你是**浏览器实时天气工程师**。目标：五种天气，可切换、可渐变、有物理反馈。天气状态、粒子循环、雪覆盖、闪电、植被摆动和角色反应全部在 Three.js 内运行；Blender 只提供新设计的效果网格与离线对照，不通过帧轴或脚本实时驱动天气。

### 步骤 0 · 状态与资源来源

- 浏览器维护当前天气、目标天气、强度、切换进度、`snow_cover` 与最近一次确定性闪电事件；天气与 20A 时钟正交。
- 服务端只低频持久化快照，不逐帧覆盖浏览器；扩环、设置开关和资源版本切换不得重置天气。
- 雨、雪、云、闪电网格与图标从新几何/新路径制作，不导入恢复包或外部游戏粒子、贴图。
- 普通 HUD 只在小地图下显示一个天气状态；人工切换和诊断开关放在非驻留设置/开发工具。

### 步骤 1 · 五种天气与视觉实现

**`clear` 晴**
- 无额外特效。云按 spec 数量。
- 唯一变化：空气透视更清（雾密度 ×0.8）。

**`rain` 雨**
- 实现：**不要**用流体/模拟。用 2~3 层"下落的细长面片带"（每层 40~80 个条状面，围着相机循环），配轻微斜角（风）。近层大而清晰、远层细而淡。
- 落地涟漪：只在史莱姆与相机附近地面上画 3~6 个短暂圆环（每 0.4 秒一次，非常省）。
- 水面：细密涟漪（波形噪声振幅 ×1.4，频率 ×1.8），水面颜色加深 12%。
- 天穹：压暗 15%，云厚，太阳柔化。
- 雾：湿度高，近地雾薄薄一层。

**`snow` 雪**
- 实现：粒子更慢、更大、有横向摆动（像纸屑），落速 0.6~1.2 BU/s。
- 地面：逐渐"变白"——用**材质混合权重**（一个全局参数 `snow_cover` 0→1，控制地表向雪色混合，无贴图），2~4 分钟世界时间铺满；停雪后 6 分钟慢慢化掉。
- 水面：结一层薄冰感（粗糙度 +0.15，波纹几乎停）。
- 声音缺省：安静（视觉上表现为雾更清、远景更亮）。

**`storm` 风暴**
- 雨的一切 + 更强：
  - 雨角 25~35°，速度更快，屏幕边缘出现"雨帘"感。
  - 云压得很低、颜色近灰紫。
  - 水面浪高 ×2（**这是最有说服力的一条**），岸边浪花线变宽。
  - 树与草的摆动幅度 ×3（顶点动画或整体轻微倾斜）。
- 闪电（`Weather_Bolt`）：
  - 每 8~20 秒一次，随机位置（岛内，离相机 30~90 BU）。
  - 一道折线自发光，持续 2~3 帧，随后 0.3 秒渐隐。
  - 同时：一次**极短的环境光闪烁**（0.06 秒，亮度 ×4），然后是 1~3 秒后的雷声（若开声音）。
  - **不要**每次都闪——间隔要有随机性，且风暴前 10 秒不闪。

**`mist` 起雾**
- 远景雾密度 ×2.2，能见度降到约 40 BU。
- 太阳变成一个模糊的光斑。
- 声音感：世界"闷"（视觉上用降低对比度实现）。

### 步骤 2 · 天气状态机

- spec 的 `weather.kind` 是**起始**天气，不是永久的。
- `weather.frequency`（0~1）决定多久变一次：0=不变；0.5≈每 8~15 分钟世界时间换一次；1≈每 3~5 分钟。
- 切换必须**渐变**（交叉淡入 8~20 秒世界时间），不允许"啪"地换。
- 天气与昼夜**正交**：夜里下雨就下雨，不要自动改成晴天。
- 但有一条例外：`snow` 只在温度低时出现（用 20A 的时段 + spec 气候判定），沙漠 biome 的雨改成"沙尘"（视觉上是偏黄的粒子 + 更低的能见度）。

### 步骤 3 · 对世界的影响（这是"有生命"的关键）

| 受到影响 | 怎么变 |
|---|---|
| 水面 | 浪高/涟漪/颜色/结冰（见上） |
| 地表 | 湿度变深（`weather.wetness`）；雪覆盖 `snow_cover` |
| 植被 | 风暴时摆动，雨时叶片略低垂（整体缩放 Z ×0.97） |
| 雾 | 各天气的雾密度不同 |
| 光照 | 太阳强度与色温随天气下降 |
| **史莱姆** | 见步骤 4 |

### 步骤 4 · 史莱姆的天气反应（加分但很值）

| 天气 | 反应 |
|---|---|
| 雨 | 身体更透亮（次表面权重 +0.1），偶尔抖一下（像甩水） |
| 雪 | 头顶积一小片白（按新角色顶环形状生成 1 层低模多角薄片，随停留时间增加覆盖角，不导入旧球体） |
| 风暴 | 更紧地贴地（高度略降），眼睛看向闪电方向 0.8 秒 |
| 雾 | 视线变短，AI 的 `wander` 半径缩到一半 |
| 晴 | 偶尔原地开心跳（`bouncy` 性格更频繁） |

### 步骤 5 · 与昼夜的联动

- 夜雨：更暗、水面反射更强（有月光时的"雨夜"很好看）。
- 黎明起雾：默认让 `mist` 在 05:00~07:30 的概率 ×3（这是"清晨薄雾"的来源）。
- 正午沙漠：`clear` 概率更高，且太阳更强。

### 步骤 6 · 性能

- 雨/雪是**面片 + 循环位移**，不是粒子系统（粒子在很多机器上不稳定）。
- 每层雨 40~80 个面片，总 ≤ 240 面。
- 闪电是单个对象复用（不是每次新建）。
- 目标：天气开启时帧时间增加 < 3ms。
- 汇报"各天气下的帧时间"。

### 步骤 7 · 验收

1. 五种天气各截一张（同一机位、同一时刻，只有天气不同）。
2. 雨有落地涟漪、雪会逐渐铺白（截"开始/铺满"两张）。
3. 风暴：水面明显更浪、闪电会出现且有光照闪烁。
4. 天气渐变切换（不是瞬切，录 10 秒）。
5. 史莱姆在雨中更透、雪中头顶有雪（两张特写）。
6. 各天气帧时间记录。
7. 天气与昼夜正交（夜里下雨截图一张）。

## 验收标准

1. 五天气截图可辨。
2. 雪的累积与融化可见。
3. 风暴水面显著更浪 + 闪电 + 光照闪烁。
4. 切换是渐变。
5. 史莱姆天气反应可见。
6. 夜里下雨正常（不与昼夜打架）。
7. 帧时间达标。

## 回退方案

- **雨看起来像竖线**：给每个面片加 8% 横向抖动 + 随机长度，三层不同透明度。
- **雪太像雨**：雪必须是"慢 + 大 + 摇摆"，把速度降到雨的 25%，横向摆动 +0.3 BU。
- **闪电太吵**：间隔下限提到 12 秒，且只在 `storm` 强度 > 0.6 时出现。
- **性能掉**：先把雨层数降到 2，再关落地涟漪。
- **雪覆盖导致地形材质需要重建**：绝对不能重建网格——只用一个全局混合参数在材质里混色；这是硬约束。
