# 40 · Google Earth 式轨道相机

> **一句话**：像在 Google Earth 里看地球那样——可以绕着球转、可以俯冲进去、滚轮是"高度"而不是"缩放"。

---

## 前置

零件 39（星球本体已生成）。

---

## 提示词正文

你是**轨道摄影师**。这个相机和零件的 34 是两套东西，**不要混用**：

| | 34 第三人称 | 40 轨道相机 |
|---|---|---|
| 模式 | `surface` | `planet` |
| 目标 | 史莱姆 | 球心 |
| 距离 | 4~14 BU | `R × 0.15 ~ R × 4` |
| 输入 | WASD 移动角色 | 纯鼠标（拖拽旋转、滚轮高度） |

### 步骤 1 · 球坐标相机

相机位置用球坐标描述，绕球心：

- `distance`（距球心距离，从 `R × 1.05` 到 `R × 4`）
- `yaw`（经度方向，无限旋转）
- `pitch`（纬度方向，限制在 -85° ~ +85°，避免翻到球心正上方产生万向锁）

`pos = center + distance × dir(yaw, pitch)`；相机永远看向球心（`look_at(center)`）。

**手感要点**：

- 拖拽 = 改 yaw/pitch，灵敏度与 `distance / R` 成正比（离得远转得快、离得近转得慢——这是 Google Earth 的手感）。
- 滚轮 = 改 `distance`，**对数**：`distance *= exp(-wheel × 0.12)`。线性滚轮在近距离会失控。
- 平滑：所有输入都经过 0.1 秒的临界阻尼（不是线性插值），且不累积。

### 步骤 2 · 自动旋转（"太空感"）

- 空闲 3 秒后，`yaw` 以 `0.01 rad/s` 缓慢自转。
- 一旦有输入，立刻停止并保持"跟手"。
- 这个细节让静止画面"活着"，是太空视角最重要的一条。

### 步骤 3 · 高度与地平线

- `distance` 与"能看到多少球面"的对应关系要可预期：`distance = R × 1.5` 时应该看到约 60% 的球面。
- 给一个"高度读数"（HUD 小字）：`海拔 3,200 km`（用 `distance - R` 换算，纯装饰，用假单位也行——但要一致）。
- 地平线雾：球边缘外 1.05R 处一层极淡的雾（零件 44 的大气壳负责，这里只留接口）。

### 步骤 4 · 地面模式 ↔ 星球模式的空间一致

这是**最容易让人困惑的一点**，必须处理好：

- 用户在 `surface` 模式站在岛心（平面原点），切到 `planet` 时，相机应该自动定位到"岛心对应的球面点"正上方。
- 反之，在 `planet` 模式双击某处地面 → 切回 `surface`，**并且史莱姆被传送到那个点**（如果那个点已解锁；否则提示"那边还没解锁"）。
- 换算：球面点 → `(lat,lon)` → 平面 `(x,y)`（零件 39 的投影反函数）。**必须用同一个投影**，否则会偏差几十 BU。

### 步骤 5 · 输入互斥

- `planet` 模式下，`WASD` 不移动史莱姆（否则玩家会困惑"为什么史莱姆在乱走"）。
- 但允许 `WASD` 作为"平移视角"的替代（微调 yaw/pitch），这样习惯键盘的玩家也能用。
- 空格 = 切回 `surface`（如果双击地面已经能切，这里是快捷方式）。

### 步骤 6 · 性能与稳定性

- 星球模式下**关闭**史莱姆动画的每帧更新（看不见它了），但保留其状态（位置/朝向），切回时恢复。
- 关闭贴身雾、关闭从来都看不见的 L0 细节（远处区块用 L1）。
- 相机 `distance` 变化时，球面 LOD 按 `distance / R` 调整（越远越粗）。
- 目标：星球模式下 60fps，帧时间 < 12ms。

### 步骤 7 · 验收

1. 拖拽能绕球转，任意角度都顺（无翻转、无跳变）。
2. 滚轮是"高度"，近距离可俯冲到看见地面细节，远距离能看到整球。
3. 空闲自转，一动就停。
4. 从 `surface` 切到 `planet`，相机自动对准岛心。
5. 从 `planet` 双击已解锁地面，能切回并把史莱姆放过去。
6. 输入互斥正确（WASD 不会让看不见的史莱姆乱走）。
7. 帧时间记录。
8. 六张截图（近地、中距、全球、背面、双击切回前/后）。

## 参数表

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `dist_min` | R×1.05 | | 最近 |
| `dist_max` | R×4.0 | | 最远 |
| `yaw_speed` | 1.0 | 0.3~3 | 拖拽灵敏度系数 |
| `wheel_log` | 0.12 | 0.05~0.3 | 滚轮对数系数 |
| `pitch_limit` | 85° | 60~89 | 防万向锁 |

| `idle_spin` | 0.01 | 0~0.05 | rad/s |
| `idle_trigger_s` | 3 | 1~8 | 空闲多久自转 |
| `surface_restore` | 是 | | 切回恢复史莱姆 |
| `planet_lod_k` | 1.0 | | 距离→LOD 系数 |

---

## 验收标准

1. 绕球顺滑、无万向锁。
2. 滚轮为高度、对数手感。
3. 空闲自转、输入即停。
4. 双向切换空间一致（不偏移）。
5. 输入互斥。
6. 帧时间达标。
7. 六张截图。

## 回退方案

- **转到极点时相机会翻**：pitch 限制已设 ±85°，若仍翻说明用了 `look_at` 的 up 轴不稳定；改用"固定 up = 世界 Y"并手动构造朝向矩阵。
- **切回 surface 位置偏移**：投影反函数与正函数不一致；直接存一份"平面坐标 ↔ 球面点"的查表（只在切换时用）。
- **掉帧**：先把星球模式下关闭所有生物与天气（看不见），再降球面 LOD。
- **用户晕**：把 `idle_spin` 关掉，或降到 0.003；并提供"重置视角"按钮。
