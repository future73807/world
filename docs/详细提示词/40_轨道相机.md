# 40 · 星球观察相机

> **一句话**：在浏览器里用拖拽绕球、滚轮改变观察高度、触屏双指缩放；只观察，不把史莱姆传来传去。

---

## 前置

零件 39（同源球面资源）、34（地表相机状态可封存）完成。

## 提示词正文
> **共同硬约束（独立执行本零件也必须遵守）**
> - 主游玩端是浏览器全屏 Three.js/WebGL；Blender 只负责从零生成、导出和离线检查，禁止把“打开 Blender”作为玩家步骤。
> - 恢复包中的任何文件均不得读取、参考或导入；所有 UI、模型、材质和动画从空白重新设计，禁止迁移、换皮或使用外部游戏/现成模型包资源。
> - 目标是**精致风格化低模**：大/中/小结构、合理拓扑与平面/分组平滑/加权法线、原创程序化材质和近景细节。低面数不等于简陋，禁止方块、体素、像素纹理和粗糙 primitives 通过。
> - 新模型先交剪影、灰模、材质完成图及近/中/远实机证据；美术不合格不能用低面数、帧率或“非 MC”豁免。
> - 新 UI 先交桌面/触屏线框和高保真 HUD/地图/暂停/创建/互动设计稿，使用原创图标、合法字体和统一 token；只参考开放世界游戏的信息层级，不复制具体素材。
> - 默认第三人称跟随。角色具有起步、移动、停止、转向、跳跃预备、上升、顶点、下落和落地；桌面 WASD/指针锁定/空格/Shift/E/M/J/Esc，触屏才显示虚拟控件；松鼠标不强制回正。
> - 禁止三栏/左右常驻面板/常驻日志。CLI 与性能工具默认隐藏，创建、设置、编辑只在高保真非驻留界面。
> - 本零件与上述约束冲突时，上述约束优先；若正文仍存在旧指令，停手报告，不擅自回退产品方向。

你是**实时星球观察相机工程师**。使用另一台 Three.js 相机服务 `planet` 状态，与 34 的地表相机接口分离。旧 Google Earth 式布局或外部软件控件不是 UI 输入；这里只借鉴绕球观察这一抽象手势。

### 步骤 1 · 球坐标与目标

- 相机绕球心，以 `distance / yaw / pitch` 描述；`distance` 默认范围 `R×1.05～R×4`，pitch 限制 ±85°。
- 每帧由球坐标计算位置并稳定构造朝向，避免极区翻转；近裁/远裁随尺度显式调整。
- 初始观察点由当前地表玩家坐标经 39 的同一投影得到，而不是随意转向球背面。
- 地表相机位置、yaw、pitch、dist、弹簧状态与玩家状态在进入前封存，星球相机不覆写它们。

### 步骤 2 · 桌面与触屏手势

- 桌面拖拽旋转，灵敏度随 `distance/R` 调整；滚轮按对数改变距离：`distance *= exp(-wheel × 0.12)`。
- 触屏单指拖动旋转，双指缩放；手势不得同时触发 HUD 按钮或地表虚拟摇杆。
- 可选 WASD 微调观察方向，但不移动隐藏的史莱姆；输入映射由 45 统一仲裁。
- 所有输入经过约 0.1 秒临界阻尼，页面失焦或切换设置时清空持续手势。

### 步骤 3 · 自动旋转与舒适性

- 空闲 3 秒后可以 `0.01 rad/s` 缓慢旋转，任何输入立即暂停。
- `prefers-reduced-motion` 或舒适性设置默认关闭自转、飞行晃动和快速俯冲。
- 提供低干扰“重置观察”操作，只重置星球相机，不影响地表玩家和相机。

### 步骤 4 · 与地表的空间对应

- 39 的正/反投影是唯一换算；同源坐标测试覆盖岛心、块边、已解锁新环与极点保护。
- 双击球面只把该处设为**观察目标/地图目标**，不自动传送史莱姆，也不改地表存档。
- 返回地表时回到进入前的史莱姆位置与跟随相机。若产品以后另设“移动到此处”，必须是独立、可确认的游戏动作，不属于本零件。
- 未解锁区域只能观察轮廓并提示，不通过球面视图绕过迷雾。

### 步骤 5 · HUD 与性能

- 默认只保留轻量返回提示与可选“示意高度”；高度是压缩展示的 UI 标记，不伪造真实公里数。
- 星图、天体详情和编辑在非驻留界面打开，没有右栏或常驻参数面板。
- 不可见地表细节暂停渲染与非必要更新，但玩家/时钟等状态保持；可见性操作幂等且不删除源资源。
- 球面 LOD 随观察距离切换，资源版本一致；返回地表时恢复原流式与碰撞。

### 步骤 6 · 浏览器实机验收

1. 拖拽、滚轮、触屏旋转/缩放顺畅，极区不翻转，输入不穿透到史莱姆。
2. 地表→星球初始方向对应当前玩家附近地形；双击只改观察目标，史莱姆未动。
3. 返回地表后玩家位置、原跟随相机、区块 hash、天气和时钟与进入前一致。
4. 自转可被输入打断，舒适性设置有效；没有常驻编辑器面板。
5. 记录浏览器帧时间与近/中/全球视图截图，保存双向切换和触屏操作录屏；Blender 截图不作证据。

## 参数表

| 参数 | 默认 | 说明 |
|---|---|---|
| `dist_min` | R×1.05 | 最近观察距离 |
| `dist_max` | R×4 | 最远观察距离 |
| `pitch_limit` | ±85° | 极区保护 |
| `wheel_log` | 0.12 | 滚轮对数系数 |
| `damping_s` | 0.1 | 手势阻尼 |
| `idle_spin` | 0.01 rad/s | 可关闭的自转 |
| `idle_trigger_s` | 3 | 空闲触发 |

## 验收标准

1. 相机在 Three.js 内运行，桌面/触屏手势、阻尼、极区和舒适性全部通过。
2. 使用同一投影，切换不传送玩家、不重置地表相机、不改世界 hash/时钟/天气。
3. 无旧三栏和常驻参数 UI，资源 LOD 与版本一致。
4. 双向切换实机证据与浏览器性能数据齐全。

---

## 回退方案

- **极区翻转**：检查 up 轴与朝向矩阵，保持 pitch 限制，不用 Blender 相机替代。
- **返回位置偏移**：修同一投影与封存恢复，不在返回时重新随机出生点。
- **自动旋转令人不适**：默认关闭自转并减少阻尼变化，不强迫用户适应。
- **性能不足**：减少不可见地表工作与球面远景细节，不关闭核心状态或换成静态截图。
