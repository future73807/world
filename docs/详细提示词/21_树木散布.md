# 21 · 树木散布

> **一句话**：在坡度合适、不在水里的地方撒约 200 棵树，成簇分布、路边留空、山顶不种。

---

## 前置

零件 18（地形与着色完成）。

---

## 提示词正文

你是**林业员**。目标：树的位置看起来"像被风吹来的种子长出来的"，不是随机点阵。

### 步骤 1 · 散布算法

不要用纯随机。用"抖动网格"：

1. 把岛面划成边长 `cell`（默认 6 BU）的网格。
2. 每个格子按目标密度决定是否要种：概率 = `spec.trees.density`（目标棵数）÷ 该岛可种格子的总数。**物种与分区密度不在这里决定**——交给零件 21A（它会按区域乘系数、按物种准入过滤）。
3. 要种的格子，位置在格内抖动（±0.42×cell），避免行列感。
4. 用 `derive(seed, "trees")` 的独立随机流，**不许**与地形共用。

再叠一层"成簇"：用低频噪声做一次密度调制，噪声值低的区域（如山谷）树更多，形成小林子。

### 步骤 2 · 过滤条件（从上到下，任一不过则不种）

1. **高度**：`z` 必须落在 `[beach_height + 1.0, snow_line - 1.5]`。
2. **坡度**：坡度 > 0.55 不种（岩壁不种树）。
3. **水边**：距水面 < 1.5 BU 不种（沙滩边缘留空）。
4. **主峰**：距主峰顶 < 4 BU 不种（山顶留白，天际线干净）。
5. **出生点**：距史莱姆出生点 < 3 BU 不种（别把人埋了）。
6. **间距**：与已种树的最近距离 ≥ 1.6 BU（简单 O(n²) 即可，数量小）。

**过滤后如果数量偏差超过 ±30%**，微调 `cell` 或概率，不要硬塞。

### 步骤 3 · 数量控制

spec 的 `trees.density`（0~400）是"目标棵数"。散布后统计，若不足：

- 先降 `min_dist` 到 1.4
- 再降 `cell` 到 5
- 仍不足则在汇报告知"受地形限制实得 N 棵"

若超出：

- 离主峰最远的优先删除，保持岛心有树。

### 步骤 4 · 码放与朝向

- 每棵树随机 yaw（0~360°），不让它们"排队"。
- 缩放 `scale` 在 `1 ± scale_jitter`（spec，0~0.4）内随机，但**不要用非均匀缩放**——低模树非均匀缩放会显丑；用整体等比 + 高度单独微调。
- 轻微下沉 0.1 BU，让"根"埋进地里，避免浮空。

### 步骤 5 · 树型分配

按 spec 的 `trees.weights` 与**该点所属区域的 `tree_mix`**（零件 21A）分配。分型规则：

- 低海拔 + 缓坡 → 圆冠树（A）
- 中海拔 → 锥形针叶树（B）
- 高海拔或奇诡值高 → 奇怪树（C，具体形态零件 22）

每棵树的种类由其位置 + 独立随机流决定，**结果确定**（同 seed 同位置永远同一种）。

### 步骤 6 · 与流式块的配合

树是 `W_PROPS` 下的对象，**不挂在区块集合下**（避免随区块卸载而丢）。但树的生成仍按区块本地坐标求值：只有该块被装载时，才把落在该块的树建出来。

- 每块的树清单由 `derive(seed, "trees", cx, cy)` 本地生成，不需要全局列表。
- 装载块时建树，卸载块时删树。
- 验证：走过去再回来，同位置同树种同大小。

### 步骤 7 · 验收

1. 俯视：树成簇分布、无行列感、密度符合 spec。
2. 贴地：树根埋入地面、无浮空、不在水里。
3. 数一下实际棵数（汇报里必须给数字）。
4. 走过去再回来，树完全复原（截图对比）。
5. 关掉植被滑杆（density=0）时，一棵都不剩。
7. 与 21A 的分工清晰：本零件只做"位置 + 过滤"，21A 做"密度系数 + 物种准入 + 林间空地"。

## 参数表

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `cell` | 6 | 4~10 | 抖动网格边长 |
| `jitter` | 0.42 | 0.2~0.5 | 格内抖动 |
| `min_dist` | 1.6 | 1.2~3 | 最小间距 |
| `clump_noise` | 0.6 | 0~1 | 成簇强度 |
| `slope_max` | 0.55 | 0.4~0.7 | |
| `peak_clear` | 4 | 2~8 | 山顶留空 |
| `spawn_clear` | 3 | 2~6 | 出生点留空 |

---

## 验收标准

1. 实际棵数在 spec 的 ±30% 内（或汇报说明受限原因）。
2. 无树落在水中/沙滩/绝壁上。
3. 成簇、无行列感。
4. 来回走动后树完全复原。
5. 两张截图（俯视密度、贴地树根）。

---

## 回退方案

- **树太多掉帧**：先把 `cell` 提到 8、`slope_max` 降到 0.45，再考虑实例化（零件 35）。
- **树集中成一坨**：`clump_noise` 降到 0.35，或对抖动再做一次"最小间距"重排。
- **与史莱姆出生点冲突**：出生点清空半径必须生效；若用户指定了固定出生点，以它为准。
