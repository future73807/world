# 29 · 迷雾边缘触发器

> **一句话**：走到雾边，它会回头看你；按住 `E` 蓄力，力量条满了，世界就要长大。

---

## 前置

零件 27（史莱姆可控制）、零件 28（雾墙与空气墙）。

---

## 提示词正文

你是**仪式设计师**。这一零件只做"靠近 → 蓄力 → 触发"的体验，真正的生成逻辑在零件 30。

### 步骤 1 · 可拓荒判定

- 史莱姆与当前边界距离 < **6 BU**，且该方向尚未解锁、且当前 `ring < MAX_RINGS`（`MAX_RINGS` 为可解锁到的最高环号） → 进入 `NEAR_EDGE`。
- 进入时：雾在玩家正对的方向"薄一点"（局部透明度 −0.2），形成一个"雾在邀请你"的视觉洞。
- 此刻在史莱姆头顶上方 1.8 BU 出现一个极简提示：**按住 E**（小字，不要弹窗）。

### 步骤 2 · 蓄力

- 按下 `E`：进度环（围绕史莱姆脚下，1.4 BU 半径的细环），1.2 秒填满。
- 蓄力时：
  - 史莱姆微微下压（0.9×Z），眼睛盯着雾。
  - 脚下的环从 `accent` 渐变到亮白。
  - 雾向玩家内涌加速（周期的 0.4 倍），并有风声（若有音频；否则只用视觉）。
  - 相机轻微前推 0.5 BU（"被吸住"）。
- 松开 `E` 未满：进度环 0.2 秒退回，无惩罚，无音效。
- 满蓄力：**0.15 秒的静默**（世界所有雾暂停翻涌），然后爆发。

### 步骤 3 · 触发

满蓄力后，**在 Blender 侧**写一张请求单 `runtime/unlock_request.json`（原子替换，含 `request_id`、`ring_from`、`direction`、`player_pos`、`created_at`），然后等零件 30 的结果单。**不要**在 Blender 里直接入队作业——执行者是网页服务端（见零件 30 步骤 0 的跨进程桥）。

- `direction` 由玩家所在边决定（北/东/南/西；若在角上，取"含更大开阔度"的那一边）。
- 写单后进入"等待中"：雾墙恢复正常翻涌，但**玩家不能再蓄力**（同一时刻只允许一次）。

### 步骤 4 · 不可拓荒的反馈

以下情况按 `E` 时要给明确但轻的反馈，不要静默：

| 情况 | 反馈 |
|---|---|
| 不在边缘 | 无反应（不要打扰） |
| 已到最大环数 | 脚下环变暗 + 一行小字"雾的尽头了" |
| 已有作业在跑 | 提示改为"拓荒进行中…" + 一个小进度点 |
| 该方向已解锁（角上判断错） | 提示"这边已经开了" |

### 步骤 5 · 视觉一致性

- 蓄力环的材质与雾同色系，别用纯 UI 绿。
- 提示文字用世界中立小字（不用 HTML 浮层），贴在史莱姆上方，随相机旋转始终面向相机。
- 所有提示在 1.5 秒无操作后淡出，不长期占屏。

### 步骤 6 · 键盘与手柄

- `E` 为主；也支持手柄的 `X`/`A`（若环境无手柄，跳过）。
- 提示文本按当前输入设备切换（"按住 E" / "按住 X"）。

### 步骤 7 · 验收

1. 靠近边缘：雾局部变薄、出现"按住 E"。
2. 按住：脚下环填充、史莱姆下压、雾内涌加速。
3. 松开未满：环退回、无副作用。
4. 满：静默 → 触发（先只需打印"已请求拓荒"）。
5. 满环数/已有作业/已解锁三种反馈正确。
6. 截图四张（靠近、蓄力中、满蓄力、反馈态）。

## 参数表

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `edge_dist` | 6 | 3~10 | 触发距离 |
| `charge_s` | 1.2 | 0.6~2.0 | |
| `release_s` | 0.2 | 0.1~0.4 | 退回时间 |
| `ring_r` | 1.4 | 1~2.5 | |
| `hint_fade_s` | 1.5 | 0.8~3 | |
| `silence_s` | 0.15 | 0.05~0.4 | 满蓄力静默 |

---

## 验收标准

1. 三种边缘状态（可拓荒/进行中/到底）反馈都正确。
2. 蓄力过程有明确的视觉节奏（不是一根干巴巴的条）。
3. 松手无惩罚。
4. 满蓄力后的"静默"确实存在（这是记忆点）。
5. 不会误触发（不在边缘时完全安静）。
6. 四张截图。

---

## 回退方案

- **提示文字在 3D 里不好做**：改用驾驶舱网页的 HUD（通过事件流下发 `hint` 状态），但保持"不弹窗"。
- **环状指示器被地形遮住**：抬高到地面 +0.06 BU，并关掉深度测试（材质设置）。
- **蓄力时相机前推让人晕**：降到 0.2 BU 或直接去掉。
