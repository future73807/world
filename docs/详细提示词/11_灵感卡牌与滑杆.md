# 11 · 灵感卡牌与滑杆

> **一句话**：没有灵感？在可关闭的创建界面抽三张卡、推八根滑杆，世界的"味道"就出来了；确认后回游戏等待后台生成。

## 提示词正文
> **共同硬约束（独立执行本零件也必须遵守）**
> - 主游玩端是浏览器全屏 Three.js/WebGL；Blender 只负责从零生成、导出和离线检查，禁止把“打开 Blender”作为玩家步骤。
> - 恢复包中的任何文件均不得读取、参考或导入；所有 UI、模型、材质和动画从空白重新设计，禁止迁移、换皮或使用外部游戏/现成模型包资源。
> - 目标是**精致风格化低模**：大/中/小结构、合理拓扑与平面/分组平滑/加权法线、原创程序化材质和近景细节。低面数不等于简陋，禁止方块、体素、像素纹理和粗糙 primitives 通过。
> - 新模型先交剪影、灰模、材质完成图及近/中/远实机证据；美术不合格不能用低面数、帧率或“非 MC”豁免。
> - 新 UI 先交桌面/触屏线框和高保真 HUD/地图/暂停/创建/互动设计稿，使用原创图标、合法字体和统一 token；只参考开放世界游戏的信息层级，不复制具体素材。
> - 默认第三人称跟随。角色具有起步、移动、停止、转向、跳跃预备、上升、顶点、下落和落地；桌面 WASD/指针锁定/空格/Shift/E/M/J/Esc，触屏才显示虚拟控件；松鼠标不强制回正。
> - 禁止三栏/左右常驻面板/常驻日志。CLI 与性能工具默认隐藏，创建、设置、编辑只在高保真非驻留界面。

你是**灵感 DJ**。你的任务是让"想不出要什么世界"变得比"想得出来"更爽。

### 步骤 1 · 卡组结构

三组牌，每组 12 张，共 36 张：

**地形组**：火山口 / 蘑菇林 / 鲸骨滩 / 浮空石 / 苔原 / 咸水湖 / 黑沙滩 / 梯田 / 珊瑚台地 / 溶洞 / 稻田 / 冰裂隙

**材质组**：湿苔藓 / 蜂蜜玻璃 / 旧毛线 / 鲸脂白 / 烧焦木 / 月光银 / 桃子绒 / 雨后石板 / 蜂蜡 / 铁锈红 / 海盐 / 墨绿绒

**情绪组**（也决定天气与时段）：清晨薄雾 / 正午蝉鸣 / 黄昏涨潮 / 雨后彩虹 / 极夜微光 / 大雾迷路 / 夏夜萤火 / 沙尘过境 / 初雪落 / 台风眼 / 日落后的十分钟 / 猫打盹的午后

每张卡有：`id`、`label`（中文 2~6 字）、`weight`（参与生成时的权重 0.5~1.5）、`hint`（给 AI 的一句话意象，20 字内）、`swatch`（一个小色块，纯装饰）。

### 步骤 2 · 创建界面中的抽卡交互

- 卡组只出现在可关闭的 `creating` 世界创建界面，由低干扰入口或暂停菜单打开；默认地表 HUD 没有固定卡位、滑杆或参数表单。
- 创建界面内放三个卡位。点「抽一张」或在对应卡组聚焦时按空格：从对应组随机抽一张，翻转入场（3D 轻微倾斜 + 淡入）。空格只在创建界面捕获抽卡，不同时触发游戏跳跃。
- 三张都抽完，出现「就这样，生成世界」按钮。
- 每张卡右上角小 `×` 可重抽该组。全部清空则回到"待抽"。
- 禁止同一组内重复（抽过的排除，抽满 12 张自动重置）。
- 抽卡有"手感"：按下时轻微下沉 2px，松开回弹；音效默认关，声音开关归入设置界面。
- 创建界面捕获自己的键盘、鼠标与触屏输入；输入自由补充或操作滑杆时 WASD、空格、E、方向键和滚轮不得穿透到角色与相机。
- 取消、Esc 或关闭按钮返回打开前的游戏，恢复原玩家位置、相机姿态、视角模式与 HUD，并清空持续按键；未确认的草稿可保留，但不得自动应用或重建世界。

### 步骤 3 · 八根滑杆

在同一创建界面的卡组下方放八根滑杆，每根有中文标签 + 极值小字提示；界面可滚动或分页，但不把表单拆成常驻左右栏：

| 滑杆 | 左端 | 右端 | 默认 |
|---|---|---|---|
| 起伏 | 平缓 | 陡峭 | 0.45 |
| 水量 | 旱地 | 汪洋 | 0.5 |
| 植被 | 荒芜 | 茂密 | 0.5 |
| 奇诡 | 合理 | 梦境 | 0.3 |
| 暖冷 | 冰蓝 | 炽橙 | 0.5 |
| 拥挤 | 空旷 | 密林 | 0.5 |
| 生机 | 寂静 | 喧闹 | 0.55 |
| 天气 | 总是晴 | 总有雨 | 0.35 |

滑杆移动时，创建界面顶部的"世界摘要"实时变：把滑杆映射成一句预览（"起伏的、水很多的、植被稀疏的、下着雨的…"），并让一个小型等距缩略图（纯 CSS 叠层，不是真 3D）跟着变高变绿。这只是创建界面里的"预演"，不是真渲染，也不得被当成浏览器游戏画面的替代品。

**两根新滑杆怎么翻译**（不要直接把数字丢给模型）：

- **生机** → `creatures` 五类的整体水平；0=只有鱼偶尔经过，1=到处是活物（鸟群加密、萤火虫满草地）。
- **天气** → `weather.kind` 与 `frequency`；0=永远晴，0.5=晴雨交替，1=多雨/多雪且切换频繁。同时影响 `sky.fog_density` 与 `palette` 的灰度倾向。

### 步骤 4 · 组装成请求并返回游戏

点「生成世界」时，把"三张卡的 hint + 八根滑杆数值"组装为零件 10 的输入（不是让 AI 直接读滑杆数字，要把数字翻译成形容词，例如 0.8 植被 → "植被非常茂密，树会挡住视线"）。附上用户可选的"自由补充"输入框内容。

确认后只提交一次后台作业并关闭创建界面，回到原玩家与相机；离线 Blender 生成与 GLB 导出由服务端调度，玩家不接触终端或 Blender。已有世界在新资源完整校验前继续可玩，普通游戏只显示零件 05/07/08 定义的轻量进度和自动消退通知，不在关闭创建后留下卡牌或滑杆面板。

### 步骤 5 · 状态与记忆

- 抽过的卡、滑杆位置存 localStorage，刷新不丢。
- 提供「换一批灵感」按钮：清空三卡与滑杆到默认，但保留自由补充。
- 世界生成成功后，把这一组"输入配方"写进 `runtime/recipes/{timestamp}.json`，方便复现与展示。

### 步骤 6 · 可访问性

键盘可达：在创建界面内，空格抽卡、方向键切换组、Tab 到滑杆、回车生成；滑杆聚焦时方向键优先调整该滑杆，不同时切组。所有卡与滑杆有 `aria-label`，焦点限制在当前可关闭界面，关闭后焦点回游戏画布或原入口。上述快捷键只在 `creating` 生效，不与游戏输入同时消费。

### 步骤 7 · 自检

- 抽满三张，摘要句读起来通顺、不重复用词。
- 滑杆拉到两端，摘要不出现"非常非常"这类叠词。
- 在自由补充输入框键入 WASD、空格与 E，并操作方向键/滚轮，角色不移动、不跳跃、不互动，相机不转动或缩放。
- 取消与 Esc 关闭后回到原玩家位置、相机和 HUD；重新打开可恢复未提交草稿。
- 确认生成只产生一个后台作业，关闭创建后普通游戏无卡牌/滑杆残留，`runtime/recipes/` 有记录且能反推出这次输入。

## 验收标准

1. 三组各 12 张，抽卡不重复，抽满自动重置。
2. 八根滑杆有中文两端提示，摘要实时变化且通顺。
3. 生成后 `runtime/recipes/` 有可读记录，且只触发一个后台作业。
4. 键盘可在非驻留创建界面完成一次生成，所有游戏快捷键均被正确隔离。
5. 默认 HUD 无卡牌、滑杆与自由补充表单；取消、Esc 和确认生成后均回到原玩家与相机，无输入穿透。
6. 四张截图已存，包括关闭创建后的同一游戏画面；不得以固定左右栏或常驻创建表单通过验收。

## 回退方案

- **卡组文案不好**（生成出来怪）：允许直接编辑卡片表（在 `app/lib/cards` 里），但保持三组各 12 张、字段不变；改完在汇报里列出改动。
- **缩略图预演卡顿**：降级为纯色块渐变，不做形变。
