# 36 · 世界预设

> **一句话**：六套"不用 AI 也能演"的世界（覆盖全部六个 biome），随时一键切换——它们是兜底，也是调参的参照系。

---

## 前置

零件 18、23（地形与植被可生成）。建议在 35 之后做，预设要考虑性能预算。

---

## 提示词正文

你是**剧务**。六套手工调好的世界（A~F，覆盖全部六个 `biome`），每套都是一份完整合法的 spec，**不依赖网络**。

### 步骤 1 · 六套预设（A~C 为主，D~F 见步骤 1B）

**A · 苔岛（Moss Island）**
- `biome=island`，`peak_height=14`，`roughness=0.42`，`beach_width=5`
- 色板：天空淡青→奶白、太阳暖白、水青绿、沙米白、草苔绿、岩灰绿
- `sky.time_of_day=0.22`（清晨）、`fog_density=0.42`
- 树：A 型 0.5 / B 型 0.35 / C 型 0.15，密度 200
- 地标：一棵巨树（岛心偏北）
- `mood："潮水退去后，苔藓还湿着"`
- `weirdness=0.2`
- 昼夜：一整天 24 分钟，起始 07:00（清晨）
- 天气：细雨 `rain` / 强度 0.45 / 频率 0.4（会自己转晴）
- 分区：3 区——低地湿地（湿、阔叶）、缓坡草地（中）、北侧石脊（冷、针叶）
- 生物：鸟 0.7 / 鱼 0.6 / 蟹 0.5 / 蝶 0.6 / 萤火虫 0.7

**B · 沙脊（Dune Spine）**
- `biome=desert`，`peak_height=9`，`roughness=0.28`，`beach_width=7`
- 色板：天空粉橙→金、太阳炽白、水极浅青、沙暖米、草（稀疏）灰绿、岩赭
- `sky.time_of_day=0.78`（黄昏）、`fog_density=0.22`
- 树：A 型 0.15 / B 型 0.1 / C 型 0.75（C 为"枯树/仙人掌"变体），密度 60
- 地标：一座灯塔（沙丘顶）
- `mood："风把昨天的脚印抹掉了"`
- `weirdness=0.35`
- 昼夜：一整天 18 分钟，起始 17:24（黄昏，长影）
- 天气：晴 `clear` / 强度 0.2 / 频率 0.25（几乎总晴，偶有沙尘）
- 分区：2 区——沙丘脊（极干、C 型枯树）、背风坳地（稍湿、少量阔叶）
- 生物：鸟 0.3 / 鱼 0.2 / 蟹 0.6 / 蝶 0.15 / 萤火虫 0.1

**C · 霜峰（Frost Peak）**
- `biome=snow`，`peak_height=22`，`roughness=0.62`，`beach_width=3`
- 色板：天空靛→淡紫、太阳冷白、水深青、沙灰白、草（雪线以下）冷绿、岩蓝灰、雪近白
- `sky.time_of_day=0.08`（黎明）、`fog_density=0.55`
- 树：A 型 0.1 / B 型 0.75 / C 型 0.15，密度 140
- 地标：一根骨桥（跨在水上）
- `mood："日出前，雪是蓝色的"`
- `weirdness=0.5`
- 昼夜：一整天 20 分钟，起始 05:36（黎明前）
- 天气：降雪 `snow` / 强度 0.6 / 频率 0.5（会积雪）
- 分区：3 区——山脚林线（针叶）、雪坡（无树）、背风谷（薄雪 + 少量阔叶）
- 生物：鸟 0.4 / 鱼 0.1 / 蟹 0.05 / 蝶 0.05 / 萤火虫 0.2

### 步骤 1B · 三套补齐 biome 的预设（D/E/F）

23B 补上了 `mushroom` / `swamp` / `volcanic`，每套都该有一个能一键演示的预设：

**D · 菌岛（Mushroom Isle）**
- `biome=mushroom`，`peak_height=11`，`roughness=0.38`，`beach_width=4`
- 色板：天空青紫→淡粉、太阳偏冷白、水青绿、沙米灰、草（菌丝地）灰绿偏白、岩灰紫
- `sky.time_of_day=0.86`（暮色）、`fog_density=0.48`
- 树：A 0.2 / B 0.25 / C 0.55，密度 120
- 昼夜 22 分钟，起始 18:30；天气 `mist` 强度 0.5（常起雾）
- 分区：2 区——巨蘑菇林（湿）、菌丝荒原（干、小蘑菇成簇）
- 生物：鸟 0.3 / 鱼 0.2 / 蟹 0.2 / 蝶 0.25 / 萤火虫 **0.9**（孢子与萤火虫双层发光）
- `mood："孢子像雪一样往下飘"`、`weirdness=0.7`

**E · 静水泽（Still Fen）**
- `biome=swamp`，`peak_height=7`，`roughness=0.22`，`beach_width=6`
- 色板：天空灰绿→奶白、太阳弱暖、水灰青、沙深褐、草近黑绿、岩墨
- `sky.time_of_day=0.14`（清晨）、`fog_density=0.6`
- 树：A 0.55 / B 0.1 / C 0.35（垂枝与枯树为主），密度 160
- 昼夜 26 分钟，起始 06:20；天气 `mist` 强度 0.65、频繁度 0.45
- 分区：2 区——浅水湿地（极湿、芦苇睡莲）、枯木高台（稍干、枯树）
- 生物：鸟 0.5 / 鱼 0.7 / 蟹 0.3 / 蝶 0.3 / 萤火虫 0.8
- `mood："水是温的，但没人想下去"`、`weirdness=0.45`

**F · 冷火山（Cold Caldera）**
- `biome=volcanic`，`peak_height=19`，`roughness=0.68`，`beach_width=3`
- 色板：天空灰紫→暗橙、太阳暗红、水灰、沙黑（黑沙滩）、草无、岩玄武黑、雪灰白
- `sky.time_of_day=0.72`（偏晚）、`fog_density=0.4`
- 树：A 0.05 / B 0.15 / C 0.8（焦木），密度 40
- 昼夜 20 分钟，起始 16:40；天气 `storm` 强度 0.35、频繁度 0.55
- 分区：2 区——熔岩台地（热、熔岩池）、玄武岩柱坡（冷、柱群）
- 生物：鸟 0.15 / 鱼 0.1 / 蟹 0.1 / 蝶 0 / 萤火虫 0.15
- `mood："火山睡了，但还温着"`、`weirdness=0.6`

**为什么只用 D/E/F 三套就够**：三套分别把"夜间发光植物"、"湿地与浅水"、"火山与灰烬"三个此前完全缺失的视觉语言各演一遍。加上 A/B/C，六套覆盖了全部六个 `biome`。

### 步骤 2 · 落盘

每套写 `specs/presets/{a_moss,b_dune,c_frost,d_mushroom,e_fen,f_caldera}.json`，字段与契约 F 完全一致（不能少字段，不能多字段）。再写一份 `specs/presets/README.md` 说明三套的调性差异与适用截图场景。

### 步骤 3 · 一键切换

左栏加"预设"下拉：

- 选中后**不立即生成**，先把该 spec 填入"世界设定卡"预览，让用户看一眼。
- 点「生成世界」才真正跑（走零件 05 的作业队列）。
- 已生成的世界切预设：仅当用户确认"会重载整个场景"后才能跑（这是破坏性操作，必须先问）。

### 步骤 4 · 预设也是测试基准

三套必须能稳定通过：

- 零件 37 的 21 条验收中的前 12 条（不含 AI 相关）。
- 作为性能基线：`perf_baseline.md` 里六套各测一次。

### 步骤 5 · 预设的自检

在 Blender 里每套生成一次，各存一张俯瞰 + 一张贴地截图，放 `renders/preset_{a,b,c}_*.png`。三套必须"一眼不同"（不同色系、不同时段、不同树）。

### 步骤 6 · 参数表即调性

在 `specs/presets/README.md` 里给一张对照表：三套在六根滑杆（起伏/水量/植被/奇诡/暖冷/拥挤）上的大致位置，让用户知道"想更冷该往哪走"。再加一张**新维度对照**：起始时刻（清晨 / 黄昏 / 黎明前）、起始天气、区域数、五类生物密度，让用户知道"想更活该往哪走"。

### 步骤 7 · 验收

1. 三份预设 json 通过零件 10 的校验（字段齐、类型对、数值合规）。
2. 六套各生成一次成功，视觉明显不同。
3. 下拉预览不触发生成。
4. 切换已生成世界时有确认。
5. 十二张截图（六套 × 俯视/贴地）。
6. 六套都被纳入性能基线。

## 验收标准

1. 六套 json 合法、可生成（A~F 覆盖全部六个 biome）。
2. 六套视觉明显不同（色系/时段/树型）。
3. 忽略网络也能跑。
4. 六张截图 + 六格滑杆对照表。
5. 纳入性能基线。

---

## 回退方案

- **某套生成失败**：用零件 10 的钳制逻辑排查字段；不要把预设改成"半成品"。
- **预设之间看起来太像**：优先拉开 `sky.time_of_day` 与主色相（差异最大的两个变量），其次才是地形。
- **用户想保存自己的世界为预设**：加"导出当前 spec 为预设"按钮，写入 `specs/presets/custom_{slug}.json`。
