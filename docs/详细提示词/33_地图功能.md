# 33 · 小地图功能

> **一句话**：浏览器全屏游戏左上一张轻量 2D 俯视图，与当前 Three.js 世界共用同一版本的数据——已解锁区域清晰、未解锁区域盖同色雾，玩家是一个会转向的小箭头；连续色块，不画棋盘网格。

---

## 前置

零件 15（区块框架 + 哈希）、零件 30（解锁状态机）、零件 03（左上 `MiniMap` 轻 HUD）。可选：零件 23（地标）。

## 提示词正文
> **共同硬约束（独立执行本零件也必须遵守）**
> - 主游玩端是浏览器全屏 Three.js/WebGL；Blender 只负责从零生成、导出和离线检查，禁止把“打开 Blender”作为玩家步骤。
> - 恢复包中的任何文件均不得读取、参考或导入；所有 UI、模型、材质和动画从空白重新设计，禁止迁移、换皮或使用外部游戏/现成模型包资源。
> - 目标是**精致风格化低模**：大/中/小结构、合理拓扑与平面/分组平滑/加权法线、原创程序化材质和近景细节。低面数不等于简陋，禁止方块、体素、像素纹理和粗糙 primitives 通过。
> - 新模型先交剪影、灰模、材质完成图及近/中/远实机证据；美术不合格不能用低面数、帧率或“非 MC”豁免。
> - 新 UI 先交桌面/触屏线框和高保真 HUD/地图/暂停/创建/互动设计稿，使用原创图标、合法字体和统一 token；只参考开放世界游戏的信息层级，不复制具体素材。
> - 默认第三人称跟随。角色具有起步、移动、停止、转向、跳跃预备、上升、顶点、下落和落地；桌面 WASD/指针锁定/空格/Shift/E/M/J/Esc，触屏才显示虚拟控件；松鼠标不强制回正。
> - 禁止三栏/左右常驻面板/常驻日志。CLI 与性能工具默认隐藏，创建、设置、编辑只在高保真非驻留界面。
> - 本零件与上述约束冲突时，上述约束优先；若正文仍存在旧指令，停手报告，不擅自回退产品方向。

你是**制图师**。小地图是默认轻 HUD 的一部分，不是网页右侧的大地图面板。它帮助玩家辨认方向与边界，必须与脚下 3D 严格一致，同时尽量不遮挡世界、不抢游戏输入。

### 步骤 1 · 数据源与版本（唯一）

`runtime/map_tiles.json` 由 Blender 离线生成器在生成/扩环并导出 GLB 后写出；浏览器实际读取当前 `manifest.json` 的 `map_url` 所指向、与 GLB 同批生成的版本化副本。结构：

**元信息**：`version`、`asset_version`、`ring`、`island_size`、`grid`（每边块数）、`tile_size`（每块世界 BU）、`generated_at`。
**瓦片数组**：每项含 `cx`、`cy`、`kind`（`water`/`shallow`/`sand`/`grass`/`rock`/`snow`/`empty`）、`color`（离线生成器依据同一世界卡、区域与材质分类给出的最终地图色）、`h`（该块中心高度，仅用于可选等高线）、`ring_of`（该块归属环）。
**地标数组**：每项含 `kind`、`x`、`y`、`note`、`ring`。
**边界**：`mist`，含 `bounds`（当前可玩的方形边界）、`color`、`alpha`，与当前 Three.js 迷雾读取同一状态来源。

- 地形分类、世界卡、GLB、manifest 与地图必须来自同一次生成和同一 `asset_version`。浏览器不得用另一套高度阈值重新判断水/沙/草，也不得自行修改 `color` 制造风格。
- 一次扩环只追加新瓦片并更新元信息，不重写旧瓦片；旧瓦片内容哈希与旧区块 GLB 一样必须保持不变。
- 新版本地图和 GLB 完整就绪后随 manifest 原子切换。加载期间小地图继续显示旧版本，禁止新地图配旧地形或反过来。
- 玩家箭头使用浏览器实时玩家坐标与 `yaw`，不用低频服务端快照代替实时位置。

### 步骤 2 · 左上轻 HUD 容器

用 Canvas 2D 绘制小地图（不要另建 WebGL 上下文）：

- 默认位于左上安全区，桌面建议 **160 CSS px** 见方，小视口可缩到 128px；圆形或柔和圆角裁切，透明/轻渐变衬底，不外加固定侧栏、导航卡或大图例。
- 小地图下方最多一行时间/天气由零件 03 决定，本零件不追加任务列表、参数、作业或日志。
- 按 `devicePixelRatio` 设置实际画布分辨率，CSS 尺寸保持不变，保证箭头与边界清晰。
- 默认小地图容器 `pointer-events: none`，不拦截 WASD、鼠标环视、滚轮缩放、跳跃或情境 E。仅一个低干扰展开按钮恢复指针交互；触屏点击区域至少 44px，但视觉仍小巧。
- 地图不支持时隐藏装饰而保留方向所需的最简标记，不弹出常驻错误面板。

### 步骤 3 · 连续色块渲染（无网格）

- 按 `grid × grid` 的数据覆盖范围填色，但**格子只是数据单元，不是视觉描边单元**。相邻瓦片直接共享边，同色区域可合并路径；不得画网格线、深色缝或独立方砖边框。
- 每个瓦片只读取同源 `color` 做纯色填充，使用共享边界坐标与设备像素对齐，避免 Canvas 抗锯齿产生发丝缝。需要重叠覆盖时最多延伸到共享边外侧半个设备像素，且不得形成可见描边。
- **瓦片间缝隙固定为 0**。禁止"留 1px 深色缝以符合低模气质"的旧做法；低模风格由 Three.js 中连续三角网与平面着色承担，不由 2D 棋盘格冒充。
- 不做逐瓦片随机明度抖动。若需要高度层次，只能使用同源数据生成连续、低对比的明暗渐变或极淡等高线，不能让相邻地块像棋盘。
- 等高线提示可选，最多 3 档，不描每块边；减少动态效果或小尺寸模式下直接关闭。

### 步骤 4 · 迷雾遮罩（与 3D 同色）

- 未解锁区域画一层同源 `mist.color` + `mist.alpha` 的覆盖；小地图只做轻量静态/低频纹理，展开地图才使用 2～3 层正弦叠加的缓慢流动噪声，不用图片。
- 可玩边界是一圈无断口的细亮线，颜色取 `mist.color` 提亮，只在玩家靠近时加亮；它不是瓦片网格线。
- 已解锁但尚未探索的区域本期可全部显示；若产品后续需要区分，只加一层 20% 暗罩，不改变地形分类色。
- 扩环时迷雾与 Three.js 的 `REVEALING` 状态同步退去，新区域使用同一新 `asset_version` 的地图与 GLB。

### 步骤 5 · 玩家标记

- 一个小箭头（三角 + 短尾），颜色取史莱姆的 `accent`，柔和外发光不超过 4px；小地图缩小时优先保证位置与朝向可辨。
- 世界坐标 → 地图坐标：`px = (x / island_size + 0.5) * canvas_w`，`py = (0.5 - y / island_size) * canvas_h`（注意 Y 轴翻转）；所有缩放和平移在此基础变换之后统一处理。
- 朝向由浏览器实时 `yaw` 旋转，平滑插值约 0.15s，避免跳帧与跨 ±π 时绕远路。
- 拖尾可选，保留最近 3 秒的位置（每 100ms 采样），画成逐渐变淡的小点；性能不足时先关闭拖尾，不降低箭头更新正确性。

### 步骤 6 · 地标与信息密度

- 每种 `kind` 一个原创 Canvas 路径图标，不引外部游戏素材：
  - `arch` 双竖线 + 弧
  - `giant_tree` 一个三角 + 树干
  - `meteor` 斜线 + 火星
  - `lighthouse` 竖线 + 光锥
  - `bone_bridge` 三段弧
  - `shrine` 小屋顶
- 默认小地图只显示当前区域重要地标，图标约 8～10px；过密时按当前目标、距离与重要性聚合，不能堆成图例面板。
- `note` tooltip、地标列表与"望向那边"只在展开地图中使用。选择地标后关闭展开地图并把它设为游戏内目标，平滑引导相机朝向；不擅自传送玩家。

### 步骤 7 · 高保真展开地图、路径点与输入隔离

默认小地图不直接处理滚轮/拖动，避免与相机争夺输入。M 或原创地图入口打开全屏地图，Esc/M/关闭返回：

- 地图使用 03 的统一字体、图标、透明度、间距和动效 token；世界/地图是主体，标题、关闭和少量操作提示清晰，不变成三栏地理后台。
- 滚轮/双指缩放（0.6×～3×），以指针/手势为中心；拖动平移仅放大后可用，双击或明确按钮回到玩家。
- 单击选中地标并显示可关闭轻详情；选择“设为当前目标”后关闭地图并更新游戏内方向引导，不传送玩家。
- 右键或触屏明确操作设置/取消一个自定义路径点；路径点在地图和游戏内均有原创标记、距离与方向提示，替换前提示，不无限堆积。
- 地标 hover/选中显示 `note`；迷雾边缘显示“可拓荒”与方向解锁状态。
- 图例、筛选和完整列表放入按需底部抽屉，触屏可单手关闭；默认不覆盖主要地图区域。
- 展开界面捕获 WASD、空格、E、滚轮、右键和触摸，输入不穿透；关闭后恢复原玩家、相机、目标、HUD 与持续输入清理状态。后台生成可继续，但不能重置世界或地图版本。

### 步骤 8 · 更新节奏与性能

- 玩家移动时小地图最高 20fps 更新（`requestAnimationFrame` 内节流），不必跟随 Three.js 每帧重绘；箭头插值使用实时输入状态。
- 静止且没有事件时不重绘；收到 `map.updated` 只重绘变化区域（脏矩形），版本切换时才重建整份缓存。
- 扩环开雾持续 1.5 秒，与 Three.js 的 `REVEALING` 对齐；动画只更新遮罩，不重复计算地形色。
- 优先关闭拖尾、流动雾和等高线以省性能，不能通过降低同源一致性或画出网格缝来"优化"。

### 步骤 9 · 实机检查

1. 默认 1280×720 与 1440×900 游戏中，小地图位于左上且轻巧，没有右侧地图栏、固定面板或大地图占据主画面。
2. 挑水、沙、草三个点对照小地图与脚下 Three.js 场景，确认分类、`asset_version`、颜色与坐标一致。
3. 放大检查地图相邻瓦片无 1px 缝、无棋盘描边、无逐块随机抖动；玩家走一圈验证箭头位置、朝向与拖尾。
4. 对比迷雾取色与边界，扩环时小地图和 3D 同步退雾，旧区域不变。
5. 默认小地图不抢滚轮/鼠标；展开后缩放、平移、归位、地标选择、设置/取消路径点可用且输入不穿透，关闭回到原玩家与相机。
6. 对照 03 高保真稿检查地图字体、图标、间距、选中/焦点、底部抽屉和动效，不能用默认 Canvas 调试样式通过。
7. 保存初始轻 HUD、走动中、展开地图选中地标、路径点游戏内引导、扩环前后证据，并附无缝色块近景。

## 验收标准

1. 小地图数据只来自当前 manifest 指向的同版本 `map_tiles.json`，浏览器不按另一套阈值重算地形；三处水/沙/草与 Three.js 对照一致。
2. 默认小地图在左上、约 160px、轻量透明，无右侧地图栏、三栏、固定侧栏或常驻地图参数。
3. 地图为连续同源色块，任意相邻瓦片没有 1px 缝、网格描边或随机棋盘明度；无缝近景截图通过。
4. 玩家箭头位置、实时朝向和可选拖尾正确；迷雾与 3D 同色，扩环同步退去且旧瓦片不变。
5. 六种地标图标与路径点可辨，默认密度受控，高保真详情与完整交互只在可关闭展开地图/底部抽屉中出现。
6. 默认小地图不抢游戏输入；展开地图的缩放、平移、归位、地标选择和路径点可用，游戏内方向引导正确，关闭后原玩家、相机和 HUD 恢复，无输入穿透。
7. 移动时 20fps 内运行且静止不重绘；高保真地图、路径点引导、扩环和无缝近景证据齐全。

## 回退方案

- **`map_tiles.json` 太大**：离线导出器从同一分类结果生成 2×2 降采样地图 LOD；浏览器也可只做显示采样，但不得重新用高度判定 `kind`，地标坐标仍保持精确。
- **Canvas 在低端机掉帧**：把 `fps_cap` 降到 10，静止时不重绘，依次关闭拖尾、流动雾和等高线；不得加入网格线掩盖性能问题。
- **共享边出现抗锯齿发丝缝**：检查 DPR、变换与路径取整，使用共享边路径或最多半设备像素重叠；不得恢复 1px 深色棋盘缝。
- **地图与 3D 不一致**：先核对 `asset_version`、manifest `map_url`、坐标变换与原子切换，再检查 `kind`/`color` 是否直接来自离线生成器的同一材质分类；禁止在网页另造一套地形分类兜底。
