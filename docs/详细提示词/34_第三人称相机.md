# 34 · 开放世界第三人称相机

> **一句话**：玩家能自由环视、平滑跟随、清楚看见角色与前路；相机不抢回、不抽搐、不穿墙，也不靠整岛俯瞰掩盖问题。

---

零件 03（输入与界面状态）、27（玩家运动）完成或可并行按契约联调。

## 提示词正文
> **共同硬约束（独立执行本零件也必须遵守）**
> - 主游玩端是浏览器全屏 Three.js/WebGL；Blender 只负责从零生成、导出和离线检查，禁止把“打开 Blender”作为玩家步骤。
> - 恢复包中的任何文件均不得读取、参考或导入；所有 UI、模型、材质和动画从空白重新设计，禁止迁移、换皮或使用外部游戏/现成模型包资源。
> - 目标是**精致风格化低模**：大/中/小结构、合理拓扑与平面/分组平滑/加权法线、原创程序化材质和近景细节。低面数不等于简陋，禁止方块、体素、像素纹理和粗糙 primitives 通过。
> - 新模型先交剪影、灰模、材质完成图及近/中/远实机证据；美术不合格不能用低面数、帧率或“非 MC”豁免。
> - 新 UI 先交桌面/触屏线框和高保真 HUD/地图/暂停/创建/互动设计稿，使用原创图标、合法字体和统一 token；只参考开放世界游戏的信息层级，不复制具体素材。
> - 默认第三人称跟随。角色具有起步、移动、停止、转向、跳跃预备、上升、顶点、下落和落地；桌面 WASD/指针锁定/空格/Shift/E/M/J/Esc，触屏才显示虚拟控件；松鼠标不强制回正。
> - 禁止三栏/左右常驻面板/常驻日志。CLI 与性能工具默认隐藏，创建、设置、编辑只在高保真非驻留界面。
> - 本零件与上述约束冲突时，上述约束优先；若正文仍存在旧指令，停手报告，不擅自回退产品方向。

你是**开放世界实时相机工程师**。使用 `THREE.PerspectiveCamera`，每帧读取玩家运动根、同源碰撞和统一输入。Blender 相机只用于离线资产检查，不参与正式控制。

### 步骤 1 · 跟随目标与默认构图

- 目标是史莱姆稳定运动根 + 约 1.1 BU 高度偏移，不跟随呼吸/压扁顶点。
- 默认相机在目标后方约 6.5 BU、上方约 2.6 BU，可有很小的肩部偏移以保证角色不挡住中心前路。
- 首屏同时看清角色近景、近处材质和前方路径，不能默认整岛俯瞰。
- 跟随采用弹簧阻尼，水平和垂直可分别调整；垂直方向更稳定，跳跃时不逐帧复制角色高度。
- dt 长帧限步，暂停/失焦/资源切换后不补算一大段弹簧位移。

### 步骤 2 · 指针锁定与自由环视

- 桌面单击游戏后请求 Pointer Lock，鼠标移动直接环视；Esc 释放并打开暂停/设置。
- Pointer Lock 不可用时使用明确的右键/拖动回退，并向玩家说明；文本输入和覆盖界面必须释放。
- 水平 yaw 可连续环绕，pitch 限制在约 -25°～+60°，避免翻转和万向锁。
- **松开鼠标不自动回正。** 玩家视角优先级最高，静止观景时允许长期保持。
- 只有在“正在移动 + 设置允许辅助回正 + 一段时间没有环视输入”时，才温和向移动方向辅助；任何新环视立即取消辅助。
- 触屏右侧滑动环视、双指缩放，摇杆和动作按钮不触发相机手势。

### 步骤 3 · 缩放与视场

- 滚轮/双指调整 `dist` 约 4～14 BU，目标距离和实际距离分别平滑处理。
- 垂直 FOV 默认约 45°，可在 40°～50°评估；广角不能造成角色和树木明显拉伸。
- 近裁约 0.1、远裁约 400，resize 更新宽高比和投影矩阵。
- 景深默认关闭或很轻，不能把低模近景和 UI 模糊；镜头抖动只在重落地时短促且可关闭。
- 蓄力最多轻微前推 0.5 BU，必须经过碰撞检测，不能为演出穿墙。

### 步骤 4 · 碰撞与遮挡处理

- 从目标点向理想相机位置做球体/多点扫掠，命中地形或大型阻挡时把相机放到命中点前约 0.4 BU。
- 地形、洞穴顶和大石必须避障；树冠/细枝可使用简化阻挡或遮挡淡出，避免相机在林里反复弹跳。
- 相机最低高度不低于地面 +0.8 BU，近裁面也需留余量。
- 遇障收近快速可靠，障碍离开后缓慢恢复；不要在障碍间连续切换远近。
- 角色离相机过近或被遮住时，采用轻微淡出/近景隐藏策略，保持角色位置与 UI 可读；不能把角色瞬移走。
- 区块与资源切换时，角色附近旧碰撞保留到新版本就绪，避免一帧穿墙。

### 步骤 5 · 与角色和 UI 解耦

- WASD/摇杆的移动参考只使用相机水平 yaw，不取俯仰。
- 相机只读玩家位置、速度、落地/蓄力事件，不写玩家位置、速度或 AI 目标。
- 地图、暂停、创建和设置打开时释放指针并冻结对应输入；关闭后恢复先前 yaw/pitch/dist 和弹簧状态。
- 服务端快照与 Blender 源相机不得覆盖浏览器实时相机。
- 默认 HUD 的角色安全区与前路安全区由 03 和本零件共同验证，小地图和提示不能遮住落点。

### 步骤 6 · 诊断与电影机位

- 俯瞰只在显式开发/诊断状态使用，文件标 `diagnostic_overview`，不计入默认相机验收。
- 电影位仅用于可选演示，任何有效游戏输入平滑返回跟随，不成为固定启动视角。
- 切换诊断/电影机位时使用约 0.6 秒安全过渡，不能穿地或修改玩家控制。

### 步骤 7 · 实机验收

1. 默认启动、设置返回、地图返回、扩环与 WebGL 恢复后，均回到正确的第三人称跟随。
2. 鼠标环视后停留 5 秒，镜头不自行抢回；移动辅助回正在开启/关闭设置下分别验证。
3. 连续移动、冲刺、急转、跳跃、滚轮/双指缩放稳定，角色和前路清晰，无眩晕式 FOV 变化。
4. 贴山、进林、进洞、贴近角色、越过障碍时不穿地、不贴脸、不高频抽动；遮挡淡出自然。
5. 触屏环视与按钮不冲突，覆盖界面释放/恢复指针正确。
6. 保存默认跟随、贴墙、树林遮挡、跳跃与触屏连续录屏；正式证据全部来自浏览器。

## 验收标准

1. 默认跟随、自由环视、平滑缩放和可选移动辅助符合开放世界手感，松鼠标不抢镜头。
2. 跟随、垂直稳定、碰撞、遮挡淡出和恢复路径可靠，无穿地/抽动/重置。
3. 桌面/触屏与覆盖界面输入隔离正确，相机不写玩家状态。
4. 高保真实机录屏证明角色、材质、前路和 UI 均清晰；俯瞰/Blender 图未冒充。

---

## 回退方案

- **镜头抢回**：关闭默认辅助回正，检查输入时间戳和状态，不用更强制弹簧压住玩家。
- **穿地/贴脸**：修多点扫掠、近裁余量和收近策略，不抬高到整岛俯瞰。
- **树林抽动**：简化阻挡、使用遮挡淡出和恢复阻尼，不提高回正频率。
- **晕动**：关闭自转/抖动/景深，降低缩放突变和 FOV 变化。
- **恢复后跳变**：恢复封存状态再碰撞校正，不重建为默认俯瞰或出生镜头。
