# 24 · 精致史莱姆身体建模（从零设计）

### 步骤 0 · 轮廓、表情与变形设计

1. 在空白工程中制作正/侧/45°剪影和灰模，核心印象为**顶窄底宽、略前倾、安静而好奇的水滴团子**。
2. 同时画出待机、挤压、拉伸和落地四种轮廓，证明拓扑能承受 26 的变形而不塌陷。
3. 眼睛、嘴与高光的位置需要跟随身体曲面，不用贴片随便浮在脸前。
4. 灰模应同时具有清楚的大轮廓、柔和的体积过渡和少量设计过的风格化切面；不能像方块、石头或未经处理的球。
5. 可制作 2～3 个新草案用于选形，最终只保留最符合世界气质的一只进入精修。

### 步骤 1 · 定制身体拓扑

从设计好的环状剖面生成身体，**不是 UV 球压扁**：

| 剖面区域 | 形态要求 | 拓扑作用 |
|---|---|---|
| 稳定底面 | 扁平但不规则，中心与外围有过渡 | 贴地、落地受压时避免尖角 |
| 下腹 | 向外鼓起、前低后高 | 形成果冻重量感与底缘 |
| 主腹 | 最大体积、轻微左右不对称 | 承载主要体积和面部曲面 |
| 肩部 | 自然收窄、前倾 | 形成水滴轮廓与探头感 |
| 顶部 | 小而钝、略偏心 | 提供独特剪影和挤压变形空间 |

- 近景主体以约 24～32 个剖面环、每环 24～32 个设计顶点为起点，调整剖面位置和三角连接，主体约 **1,200～2,000 三角面**。
- 顶点密度集中在面部、底缘和变形区域，背面/不可见区域可更少；不是均匀 UV 经纬球。
- 使用分组平滑、加权法线与局部大切面共同塑形：主腹柔和，肩部和底缘保留少量可读风格化折面。
- 允许对**自己设计的拓扑**使用适度细分、倒角和形态键；不得为了低面数字留下影响轮廓和变形的明显棱角。
- 近景整只（身体、眼、嘴、高光、可选内核）目标 **≤3,000 三角面**；质量未达时先修结构，不以该数字为删减唯一依据。

### 步骤 2 · 精致面部几何

`Slime_Eye_L/R`：

- 使用贴合面部曲率的扁六边/八边体块，具有轻微厚度与柔和边缘，不是圆球或平面贴纸。
- 两眼有极小高度/角度差，保持可爱但不过度随机；眼球嵌入浅表，环绕时不穿出。
- 高光用小菱形与次级弱高光形成层次，使用独立节点供眨眼和视线控制。
- 眼睑/眨眼可通过形态键或局部覆盖几何完成，不靠简单把整只眼藏进身体。

`Slime_Mouth`：

- 用有微小厚度的三段曲线或定制浅槽形成微笑，边缘不生硬，宽度与面部比例协调。
- 睡眠小 `o`、好奇微笑和落地挤压有独立形态键/节点目标。
- 可选红晕采用柔和程序化色块，不是像素圆点，也不遮挡主体材质。

### 步骤 3 · 变形友好与材质分区

- 身体按顶部、主腹、下腹与底缘分配合理拓扑和材质参数，色差柔和，避免三色块直接切成斑马。
- 底缘变形时保持稳定接触，主腹承担主要挤压，顶部提供延迟回弹；不能全身统一缩放造成塑料玩具感。
- 为 `IDLE/WALK/JUMP/LAND/CURIOUS/SLEEP` 预留形态键、骨骼或节点控制；法线在最大压缩/拉伸时仍稳定。
- 身体允许原创程序化色相渐变、细腻粗糙度变化和非像素细节；不用图像贴图掩盖造型。
- 透光、内核、边缘光与眼睛材质由 25 精修，灰模阶段先证明轮廓和体积。

### 步骤 4 · 节点、原点与动画边界

```text
Slime_Root（资产根，局部脚底中心）
└── Slime_Body（定制环状拓扑 + 形态键/局部骨骼）
    ├── Slime_Eye_L / Slime_Eye_R
    ├── Slime_Mouth
    ├── Slime_Core（可选）
    └── Slime_Blush_L / Slime_Blush_R（可选）
```

- 总高约 1.46 BU，局部脚底 Z=0、正面 -Y；浏览器运动根与视觉根分离。
- 不烘焙出生点、相机、世界移动或 AI；glTF 轴向只通过唯一适配层。
- GLB 保留形态键、局部骨骼/节点、面部层级和材质名，供 26 的浏览器动画状态机调用。

### 步骤 5 · 近、中、远 LOD

| 档位 | 目标 | 保留内容 |
|---|---|---|
| L0 近景 | 主体 1,200～2,000 面，整只 ≤3,000 | 完整面部、变形拓扑、法线、材质与表情 |
| L1 中景 | 主体约 400～800 面，整只 ≤1,200 | 水滴轮廓、眼睛、主要形态键与基础透光 |
| L2 远景 | 整只约 300～500 | 独特剪影、面部色点和运动，不要求近景小细节 |

- 玩家角色通常始终使用 L0/L1，不能因距离稍远就变成石块。
- LOD 由同一新源模型生成，材质和形态键对应；切换不改变角色身份、表情与动画状态。

### 步骤 6 · 高保真验收

1. 正/侧/45°剪影、灰模近景和四种变形灰模通过，能指出面部/下腹/顶部结构。
2. 材质完成图具有柔和体积、精致眼睛和细腻色差，不像玻璃、石块、塑料球或方块。
3. 浏览器默认相机近/中/远三距离检查轮廓、法线、面部、透光、阴影和接触点。
4. 最大挤压/拉伸和 360°环绕无塌陷、明显穿插、法线翻面、眼球穿出或透明排序错误。
5. GLB 节点、形态键、材质、LOD 和 manifest 完整；关闭 Blender 后动画与控制可用。
6. 保存 `step_24_concept`、`step_24_clay`、`step_24_deformation`、`step_24_beauty` 和浏览器近/中/远实机证据。

## 验收标准

1. 完全从新设计和新拓扑生成，没有读取恢复包或导入外部模型。
2. 近景轮廓、体积、面部、材质和变形达到精致风格化低模质量，不是方块或粗糙 primitive。
3. 主体约 1,200～2,000 面、整只 ≤3,000 的参考预算与 LOD 正确；未用低面数抵消美观失败。
4. 浏览器近/中/远、变形、材质、阴影、透明排序和控制全部通过。
5. 高保真图、灰模、变形与连续实机证据齐全。

## 回退方案

- **像石块**：增加下腹/面部定制拓扑，调整平滑组和透光，不靠动画单独掩盖。
- **像普通球**：重新设计顶/腹比例、前倾与底缘，不用外部角色替换。
- **像玻璃或硬塑料**：修透光、粗糙度、内核和法线，保持身体体积与柔和边缘。
- **变形塌陷/脸穿出**：调整变形区域拓扑和形态键，不删除表情或降低近景质量。
- **性能不足**：优先减少其他远景成本和透明叠层；玩家近景史莱姆不得退回粗糙模型。
