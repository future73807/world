# 21A · Minecraft 式植被分区

> **一句话**：不是"随机撒 200 棵树"，而是"这片只有针叶、那片只有阔叶、山顶什么都没有"——分区锁物种。

---

## 前置

零件 21（散布算法）、22（三型树）、16A（区域权重场）。

---

## 提示词正文

你是**植被规划师**。零件 21 决定"树在哪"，这一个零件决定"**哪里长什么**"。

### 步骤 1 · 从"全岛一套"改成"分区多套"

零件 21 用的是 spec 全局的 `trees.weights`。本零件改为**逐点查区域权重**：

1. 对候选点取 16A 的 `tree_mix` 加权结果，得到该点的"树种概率"。
2. 三种树按概率抽签（同一随机流，结果确定）。
3. 若抽中的树种在该高程/温度带"不允许"（见下表），则**不种**，而不是换成另一种。

**这一点是 MC 手感的来源**：某些地方就是该空着，而不是"每种树都匀一点"。

### 步骤 2 · 物种准入表

| 树型 | 允许的高程 | 允许的温度 | 允许的湿度 |
|---|---|---|---|
| A 圆冠（阔叶） | 低~中（< 0.55 峰高） | T > 0.35 | M > 0.35 |
| B 锥形（针叶） | 中~高（0.25 ~ 0.85 峰高） | T < 0.6 | 任意 |
| C 奇怪树 | 任意 | 任意 | 任意（但受 `weirdness` 门槛） |

- C 型还要额外过一道 `weirdness > 0.55`（或该区域 `note` 明确写了怪东西）。
- 准入不过就空着——别找替代。

**非树木类植被的准入（23B 补的，统一在这张表里管，不要在 23B 另立一套）**：

| 植被 | 允许的 biome / 条件 |
|---|---|
| 巨型/中型蘑菇 | `biome=mushroom`；巨蘑菇下方 8 BU 内禁树 |
| 小蘑菇簇 | `mushroom`，或（`swamp` 且树荫下），或洞内（16B） |
| 芦苇 | `swamp` 或 moisture > 0.7，且距水 < 3 BU |
| 睡莲 | 必须在水面（湖/湿地浅水），水深 < 0.8 BU |
| 宽叶草 | `swamp` |
| 海草 / 珊瑚 | 必须在水下 0.3~2 BU；珊瑚还要求 `water.tint` 偏清 |
| 河草 | 必须在 17A 的河道内，沿流向倾斜 |
| 熔岩池 / 玄武岩柱 / 焦木 | `biome=volcanic` |

### 步骤 3 · 密度也分区

`trees.density` 是全局目标值，但实际密度按区域调：

- 湿地/茂密区：× 1.3
- 干草区：× 0.45
- 高地岩石区：× 0.15
- 雪线以上：× 0（不种）

再乘 16A 的 `moisture`/`temperature` 得出的"宜林度"。最终密度按区块统计，**并在地图 hover 上显示该块的树数**（可选加分）。

### 步骤 4 · 树群与空地的节奏（MC 的"林间空地"）

- 不要均匀。用两层低频噪声：
  - 第一层（波长 ~26 BU）决定"有没有一片林子"
  - 第二层（波长 ~9 BU）决定"林子里有没有一小块空地"
- 空地阈值：第二层噪声 < `clearing_th` 时，该点不种树（即使准入通过）。
- 目标：走 60 BU 应该经历 **2~4 次"林→空地→林"** 的节奏变化。太少=单调，太多=碎。

### 步骤 5 · 地表小件也分区

同一条准入逻辑复用到零件 23 的小件：

| 小件 | 允许区域 |
|---|---|
| 草簇 | 草地、湿地（密度 ×1.5） |
| 花 | 草地 + T > 0.35 + M > 0.4，成簇 |
| 小石子 | 高地、崖下、沙滩边缘 |
| 贝壳/漂流木 | 只在沙滩带 |
| 蘑菇（若 biome=mushroom） | 湿地、树荫下，成环状小群 |

### 步骤 6 · 与流式装载的一致性

树与小件的选址必须**逐点纯函数**：同坐标 + 同 seed → 同结果。不许"先生成全岛列表再分发"，那样会与零件 15 的按块装载打架。

### 步骤 7 · 性能

- 分区查询不能每棵树都算 5 个区域的权重衰减——缓存"当前块内 4×4 采样网格"的分区结果，块内插值。
- 目标：单块植被选址耗时 < 6ms。

### 步骤 8 · 验收

1. 至少能看出 3 种"植被性格"不同的地带（茂密阔叶 / 稀疏针叶 / 空岩）。
2. 空地节奏：走 60 BU 经历 2~4 次林与空的转换（报次数）。
3. 雪线以上零树、湿地无干草。
4. 同 seed 同坐标永远同树种（抽查 20 点）。
5. 单块选址耗时记录。
6. 三张截图（阔叶林、针叶坡、空岩区）。

## 验收标准

1. 三种以上植被地带可辨。
2. 林→空地节奏 2~4 次 / 60 BU（报数字）。
3. 准入表严格生效（雪线零树、湿地无干草）。
4. 确定性：20 点抽查全一致。
5. 性能达标。
6. 三张截图。

---

## 回退方案

- **地带看不出来**：把 `patch_noise_wl` 降到 6，`clearing_th` 提到 0.5（更多空地，对比更强）。
- **树太碎**（到处单棵）：提 `min_dist` 到 2.2，并降低 `dry_density_mul`。
- **空地太多像荒地**：`clearing_th` 降到 0.32。
- **和 21 的算法重复**：21 只保留"抖动网格 + 过滤"的骨架，所有"密度/物种"决策都搬到这里，避免两处各算一遍。
