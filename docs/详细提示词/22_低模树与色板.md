### 步骤 0 · 先通过剪影与结构评审

- 为 A/B/C 三族分别制作正/侧/45°剪影、灰模近景和第三人称中景。
- 每族都画出大/中/小三层结构：整体树冠轮廓；主干、分叉与主冠层；根部、细枝、边缘、嵌件与色带。
- 禁止从 UV 球、单位立方体、像素树或现成 low-poly tree pack 开始修改。
- 允许对**自己设计的拓扑**做适度细分、分组平滑、加权法线和小倒角；不得为了保留“低模”名义删掉影响轮廓和近景质量的必要结构。
- 灰模不通过时不进入材质。近看像方柱、几个 primitives 或粗糙折纸，均视为不通过。

### 步骤 1 · A 族 · 折伞树（暖低地）

**目标气质**：柔和、舒展、有风向的层次伞盖，近看具有体块和枝叶组织，不是蘑菇或球冠。

**大形**

- 主冠横向展开，左右不对称，顶部有缓慢起伏而非单一尖点。
- 主干具有轻微 S 形弯曲和明显根颈，树高与冠径比例自然。

**中形**

- 主干由 7～9 边收分环状网格构成，根部向外形成 3～5 个低伏支撑根。
- 2～4 个主分叉伸向不同冠层；每个冠层由 5～9 个相互穿插但有秩序的折伞簇组成。
- 每个折伞簇用 2～3 圈设计顶点和偏心脊线构成闭合体块，冠层之间保留少量可见枝干。

**小形与材质**

- 在主分叉和冠层边缘加入少量小枝、切面色带或嫩叶簇，不平均撒三角形。
- 树皮用原创程序化纵向色带/粗糙度变化，不用像素纹理；冠层顶/侧面有柔和色差和接触阴影。
- 大折面可保持清晰，树干和根颈使用分组平滑或加权法线，避免所有面同样生硬。

**近景参考**：800～1,200 三角面；中景 300～500；远景 ≤160。面数只是起点，轮廓和层次不达标就继续调整。

### 步骤 2 · B 族 · 叠羽树（凉坡地）

**目标气质**：修长、疏密有节奏、具有风吹方向的羽状群落，不是对称圆锥圣诞树。

**大形与中形**

- 树干 7～9 边，分 3～4 段形成风向弯曲；主干顶部不机械居中。
- 5～8 层主枝沿不同方位展开，每层包含主羽片、次羽片和少量空隙。
- 羽片为闭合的折脊体块，具有前缘、后缘和侧厚度；长度、倾角、旋转与层间距由设计曲线变化。
- 根部和最低枝形成稳定重心，高处的细枝与羽片逐渐减小，而非等比复制同一模块。

**小形与材质**

- 少量分叉端点、小嫩枝和脊线色带服务近景；远景保留整体节奏，不保留碎小几何。
- 冷青绿具有顶光/背光色差，羽片内侧更暗；材质粗糙度与树干区分。
- 可在大脊线上保留明确折面，在羽片边缘和树干使用合理法线过渡，避免纸片感和全硬边。

**近景参考**：600～1,000 三角面；中景 240～420；远景 ≤140。

### 步骤 3 · C 族 · 灯菌树（高怪度/特殊生态）

**目标气质**：幻想、精致、有生命感，像会发光的小生态灯，而不是简单蘑菇 primitive。

**大形与中形**

- 2～4 段弯曲柄体形成自然重心，使用 8～10 边环状拓扑，柄根有菌丝状小支撑。
- 灯罩具有顶部、肩部、外缘和下部四个高度区，7～12 个主要起伏形成不对称轮廓。
- 灯罩下缘有厚度，内部可简化表现放射状菌褶或下垂小结构；不是单层圆盘。
- 每个世界选择一种主轮廓，但提供至少 3 种真实结构变体，而非只改色相和缩放。

**小形与材质**

- 发光集中于罩下、菌褶或少量嵌件；表面使用柔和色带、透光和细微粗糙度变化。
- 发光不能盖过轮廓，暗面仍能读出柄体与罩缘；不使用外部发光植物贴图。

**近景参考**：900～1,400 三角面；中景 360～600；远景 ≤220。

### 步骤 4 · 共用拓扑、法线与细节规则

- 所有族由新顶点和定制拓扑构成，树干不能是四边方柱，树冠不能是 UV 球/立方体。
- 不全局强制平面法线。按区域选择平面、分组平滑或加权法线，保留风格化切面同时消除不必要的粗糙棱角。
- 允许原创非像素程序化纹理、顶点色、渐变和局部色带；不依赖外部贴图也能读清结构。
- 冠干必须衔接，枝条有合理生长方向；根颈贴地，不能浮空，枝干/冠层穿插不能明显穿帮。
- 每族至少 3 个结构变体，变化包括冠层数量、分枝方向、轮廓比例或边缘结构，不能只换色。

### 步骤 5 · LOD 与性能不牺牲近景

| 档位 | 使用距离 | 保留内容 |
|---|---|---|
| 近景 L0 | 约 0～12 BU，按屏幕占比微调 | 完整根干、主冠层、关键小结构、精致法线与材质 |
| 中景 L1 | 约 12～35 BU | 保留大/中形和主要色带，减少小枝、菌褶和内部面 |
| 远景 L2 | 35 BU 以外 | 保留独特剪影和色板，不增加近景碎面 |

- 近景质量不得因为总面数超限被砍成方柱/大三角。先减少同屏近景数量、提前切换中远景、合批和降低更新频率。
- 各 LOD 来自同一新源模型和确定性简化，不导入另一套廉价树。切换时位置、模板 id、色相和尺度一致。
- 性能报告分别记录单棵源面数、实例数、各档驻留量和实际提交三角面。

### 步骤 6 · 共享 GLB 与原创材质

- 每族/结构变体/色档建立有限共享模板，经唯一出口写入 `shared/` GLB 与 manifest。
- 浏览器使用共享 BufferGeometry + InstancedMesh；不能为每棵树复制一份 GLB 或材质。
- 原创程序化树皮/冠层材质可在 Blender 与 Three.js 中有不同实现，但参数、色板、光照意图和视觉结果必须对应。
- 实例保存位置、旋转、尺度、模板、结构变体和色档；重载后一致。

### 步骤 7 · 美术与实机验收

1. 正/侧/45°剪影、灰模近景、中景和材质完成图齐全；大/中/小三层结构可指出。
2. 三族及各自 3 个结构变体不是换色复制；没有方柱、球冠、圆锥树或纸片树。
3. 近景检查根颈、枝干、冠层厚度、法线、穿插、材质和接触阴影，达到精致风格化低模标准。
4. 浏览器默认跟随中保存近/中/远三距离图，并进行 360°绕树与 LOD 切换录屏。
5. 关闭 Blender 后仍成立；记录源面数、实例、LOD、draw call 和实际渲染量。
6. 美术不过不能通过“面数低”或“帧率高”豁免；先重做结构再继续散布整岛。

## 验收标准

1. 三族有原创轮廓、完整枝冠结构、近景细节和至少 3 个真实结构变体。
2. 近景拓扑、法线、材质、根部衔接和光影精致协调，不像 primitives 拼合或方块。
3. LOD 保留同一身份，近景质量优先；性能统计口径正确。
4. 共享 GLB、材质和实例化正确，所有证据来自新工程与浏览器实机。

---

## 回退方案

- **像蘑菇/球冠**：回到大形和冠层组织，增加横向层次和分枝，不用更多贴图遮盖。
- **像纸片/折纸**：补闭合厚度、次级体块和合理法线，不直接堆更多三角形。
- **像圣诞树**：调整层间节奏、主枝方向与羽片形状，不用对称圆锥。
- **近景很粗糙**：回到结构评审，允许增加定制拓扑/倒角/平滑组；禁止以低模名义通过。
- **性能不足**：提前切中远景、减少同屏近景数量和更新频率，不删除近景根冠结构。
