# 23B · 巨型蘑菇、湿地与水域植被

> **一句话**：补上三个声明了却没实现的 biome（`mushroom` / `swamp` / `volcanic`），并给水边补上 MC 的水生植物。

---

## 前置

零件 21A（植被分区）、23（草花岩石）、17A（河湖，湿地与水域植被要用）。

---

## 提示词正文

你是**生态补齐员**。零件 01 的 `spec.biome` 枚举已经写了六个值，但实际只有三个能生成。这一轮补上缺的三个，并顺带补齐水边植被。

### 步骤 1 · 巨型蘑菇（biome = `mushroom`）

MC 的蘑菇岛最抓人的是"伞盖"。我们不做方块，做**伞盖形低模**：

**三种规格**
- 小蘑菇（1.0~1.8 BU 高）：伞盖是 6~8 边形的圆顶，柄略弯。成簇 5~12 个。
- 中蘑菇（2.5~4 BU）：伞盖双层（上小下大），边缘下垂 0.2 BU，柄有 1~2 处环纹。
- 巨蘑菇（7~12 BU）：伞盖是一个"倒扣的低模球冠"（12~16 面），直径 8~14 BU；伞盖下缘一圈白色菌褶（薄面带）；柄粗 1.2~2 BU，底部有菌丝扩散。

**细节要求（决定可爱还是可怕）**
- 伞盖颜色：`accent` 的柔和版，或红/橙/青三选一（由 `derive` 定）；**菌褶必须偏白**。
- 伞盖上有 2~5 个浅色圆斑（不是完美圆，略微不规则）。
- 伞盖内侧有**发光孢子**（见步骤 2）。
- 巨蘑菇底部的菌丝：地面上一圈放射状白纹（`M_Foam` 变体），半径 3~5 BU。

**密度**：`mushroom` biome 下，巨蘑菇 1~3 棵（是地标级的），中蘑菇 6~12，小蘑菇成簇 40~80 个。
**位置**：越靠近巨蘑菇，小蘑菇越密（伞盖阴影下更适合生长——这条是"生态感"的来源）。
**避让**：树与蘑菇不重叠（间距 1.5 BU）；巨蘑菇下方不种树。

### 步骤 2 · 发光孢子（mushroom biome 的灵魂）

- 在巨蘑菇伞盖内侧与菌褶附近，放 20~40 个小发光点（3 面），颜色青绿或淡紫。
- 缓慢上下漂浮（±0.3 BU，周期 4~8 秒），明灭 0.3~0.8 Hz。
- **只在夜间/洞内更亮**（读 20A 的时刻）；白天弱到几乎看不见。
- 这一条与 23A 的萤火虫是两套东西：孢子跟着蘑菇，萤火虫跟着草地。

### 步骤 3 · 湿地（biome = `swamp`）

- 地形：低洼、湿、`16A` 的 `moisture > 0.72` 区域扩大。
- **浅水**：湿地里有 20~35% 面积是"浅水洼"（z 在 -0.15 ~ 0.25，水面几乎与地面齐平，看起来潮乎乎）。
- 地面材质：深苔绿，局部接近黑绿（`grass` 压暗 35% 并偏青）。
- **雾更重**：该区域 `fog_density` ×1.4（在 16A 的区域参数里体现，不是全局改 20 的雾）。

**湿地植物（这是 MC 湿地最有辨识度的部分）**

| 植物 | 做法 | 数量 |
|---|---|---|
| 芦苇 | 细长（2~4 BU）向上，顶部略弯，成片 30~60 根 | 成片，随风摆 |
| 睡莲 | 平贴水面的 6~8 边薄片，偶尔一朵粉白小花 | 8~20 片 |
| 宽叶草 | 比普通草大 1.6 倍、叶片更宽 | 200~400 |
| 枯树 | 复用 22 的 A 型但无冠、枝干扭曲 | 2~5 棵 |
| 垂枝树 | 冠部垂下 1.5~2.5 BU 的枝（像柳） | 3~8 棵 |

- 芦苇必须有"风动"（顶点动画或整体摆动 ±4°），否则湿地是死的。
- 睡莲的朝向随机偏转（不要全部同一方向）。

### 步骤 4 · 水域植被（河/湖/海里都要）

零件 17A 做了水，但没有水下植物。补三样：

| 植物 | 在哪 | 做法 |
|---|---|---|
| **海草** | 浅水（水下 0.3~2 BU） | 细长带状的 3~5 面，向上摆动 |
| **珊瑚簇** | 只在 `island` biome 的浅水、晴朗较多处 | 3~5 个枝状分叉（每枝 3 面），颜色 `accent` 偏粉/橙 |
| **河草** | 河底 | 更短更密，随水流方向倾斜（读 17A 的流向） |

- 水下植物不投影、不接收阴影（水下光影本来就弱）。
- 珊瑚只在 `water` 的 `tint` 偏清时出现（浑浊的水里长珊瑚不合逻辑）。

### 步骤 5 · 火山变体（biome = `volcanic`）

补齐第三个空 biome。不是做"末日火山"，做"冷却中的火山岛"：

- **熔岩池**：1~3 处，地面上一块橙红自发光斑（不是真流体，起伏 ±0.05 BU 的缓慢呼吸），周围一圈黑曜石色硬壳。
- **火山灰**：地面材质偏灰紫；空气中有缓慢下落的灰烬粒子（10~20 个，慢速，会积在地面短暂停留）。
- **玄武岩柱**：3~6 组，每组 3~5 根六棱柱（高 2~6 BU，顶端不平），这是最"冰岛"的元素。
- **焦木**：复用 22 的 A 型，冠部烧焦（近黑 + 少量余烬红点）。
- **不做**：喷发、熔岩流、伤害。只有视觉。
- 天空：`palette.sky_top` 偏灰紫，太阳更暗（在 spec 里体现）。

### 步骤 6 · 与 21A 的准入表对接

本零件新增的植物要加进 21A 的准入规则（否则会满岛乱长）：

| 植物 | 允许的 biome | 允许的湿度 | 其它 |
|---|---|---|---|
| 巨型蘑菇 | `mushroom` | > 0.5 | 巨蘑菇下方禁树 |
| 芦苇/睡莲 | `swamp` 或 moisture > 0.7 | | 必须近水（< 3 BU） |
| 海草/珊瑚 | 任意，但必须在水中 | | 海草深度 0.3~2 BU |
| 河草 | 任意，必须在河里 | | 沿流向倾斜 |
| 玄武岩柱/焦木 | `volcanic` | | |

**在 21A 步骤 2 的表里补上这些行**（不要在本零件里另立一套判定）。

### 步骤 7 · 性能

- 巨型蘑菇：每棵 ≤ 120 面；中蘑菇 ≤ 40；小蘑菇 ≤ 16。
- 湿地植物与水域植被全部**实例化**（网格数据块：芦苇 1、睡莲 1、宽叶草 1、海草 1、珊瑚 1）。
- 孢子与灰烬是点状，合计 ≤ 80 个 3 面小件。
- 汇报"`mushroom` / `swamp` / `volcanic` 三套各自"的三角面与帧时间。

### 步骤 8 · 验收

1. `mushroom` biome 能量出：巨蘑菇 1~3 棵、有发光孢子（夜间可见）、伞盖有斑点、底部有菌丝。
2. `swamp` biome：浅水洼、芦苇成片会摆、睡莲浮着、雾更重。
3. `volcanic` biome：熔岩池发光、玄武岩柱成组、天空灰紫、有灰烬落下。
4. 水域：海草在浅水摆动；珊瑚成簇（清水里）。
5. 这三个 biome 都能通过零件 36 的方式一键生成（各补一份预设最有说服力）。
6. 准入表更新，没有"沙漠长芦苇"这类错误。
7. 性能数字记录。
8. 六张截图（巨蘑菇/孢子特写/湿地/熔岩池/海草/珊瑚）。

## 验收标准

1. 三个新 biome 都能生成且特征明显。
2. 发光孢子夜间可见、会漂浮。
3. 湿地芦苇会摆、有浅水洼。
4. 水生植被分布正确（只在水里）、珊瑚只在清水。
5. 准入表已更新，无错位植被。
6. 性能达标。
7. 六张截图。

## 回退方案

- **巨蘑菇像雨伞**：伞盖边缘下垂 0.2 BU，并让伞盖不规则（加顶点噪声），不要正圆。
- **孢子看不出**：提高对比——局部压暗周围材质，而不是提高亮度。
- **湿地太像草地**：浅水洼占比提到 0.35，并加深地面色（这是主要区分手段）。
- **玄武岩柱像六角铅笔**：顶端加不平整（每根顶部 Z 抖动 ±0.4），并允许轻微倾斜。
- **火山太"末日"**：熔岩池数量降到 1，灰烬降到 8 个，天空不要全黑。
- **性能掉**：小蘑菇簇降到 30，宽叶草降到 150。
