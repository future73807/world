# 31 · AI 扩写新区域

> **一句话**：新解锁的土地必须是“同一个世界的延续”，不是贴上去的补丁；AI 或离线预设只负责原创环境设定，最终仍要导出 GLB 并在浏览器里实际可玩。

---

## 前置

零件 10（灵感引擎）、零件 30（浏览器请求与服务端扩环作业已就绪）。

---

## 提示词正文
> **共同硬约束（独立执行本零件也必须遵守）**
> - 主游玩端是浏览器全屏 Three.js/WebGL；Blender 只负责从零生成、导出和离线检查，禁止把“打开 Blender”作为玩家步骤。
> - 恢复包中的任何文件均不得读取、参考或导入；所有 UI、模型、材质和动画从空白重新设计，禁止迁移、换皮或使用外部游戏/现成模型包资源。
> - 目标是**精致风格化低模**：大/中/小结构、合理拓扑与平面/分组平滑/加权法线、原创程序化材质和近景细节。低面数不等于简陋，禁止方块、体素、像素纹理和粗糙 primitives 通过。
> - 新模型先交剪影、灰模、材质完成图及近/中/远实机证据；美术不合格不能用低面数、帧率或“非 MC”豁免。
> - 新 UI 先交桌面/触屏线框和高保真 HUD/地图/暂停/创建/互动设计稿，使用原创图标、合法字体和统一 token；只参考开放世界游戏的信息层级，不复制具体素材。
> - 默认第三人称跟随。角色具有起步、移动、停止、转向、跳跃预备、上升、顶点、下落和落地；桌面 WASD/指针锁定/空格/Shift/E/M/J/Esc，触屏才显示虚拟控件；松鼠标不强制回正。
> - 禁止三栏/左右常驻面板/常驻日志。CLI 与性能工具默认隐藏，创建、设置、编辑只在高保真非驻留界面。
> - 本零件与上述约束冲突时，上述约束优先；若正文仍存在旧指令，停手报告，不擅自回退产品方向。

你是**续写者与原创环境守门人**。这一轮只产出一张有效的新环卡 `specs/ring_{n+1}.json` 和对应摘要，不直接操控玩家，也不把 Blender 变成游戏运行时。规则是“渐变”，不是“突变”；无网络、无 Key 或 AI 失败时，本地预设同样能走完资产生成与浏览器游玩。

### 步骤 1 · 输入

扩环作业必须带齐：

- 父环 spec 全文（`specs/ring_{n}.json`）。
- 新环方位（北/东/南/西；角上取开阔度更大的一边）。
- 当前 `ring` 号、`island_size`、父环 seed 与本次请求 id。
- 一句“这个方向的潮流”提示：从父环的 `mood` 与 `landmarks` 推导，例如父环有鲸骨，新环可以是“鲸群搁浅过的滩”。
- 用户可选的一句“我希望这边是……”。心愿只是软输入，不能突破世界连续性、原创边界与 schema。

### 步骤 2 · 参考与原创边界

把以下要求写给模型和后续资产环节：

- 参考图、文字描述与既有世界只用于启发地貌关系、氛围、色板、植被群丛和地标故事，不得直接变成最终模型、贴图或界面素材。
- 新环必须延续本项目的精致原创低模语言：连续地形切面、合理平滑/加权法线、大小结构层次与原创程序化材质；近景不得退回 primitives，也不得复制外部游戏的地形、树木、建筑、道具、图标或布局。
- **不追求 Minecraft/MC 等价或复刻**，不以方块、体素、像素纹理和方树作为“还原度”目标，也不引入原神等游戏的角色、场景或 UI 素材。
- 若参考与原创方向冲突，放弃该参考细节，只保留抽象的气候、地貌节奏或叙事关系。最终 GLB 必须由本项目生成链产出。

### 步骤 3 · 写给模型的连续性约束

用中文写清，用第二人称：

- 输出只一份 JSON，字段与父卡完全一致，不许增删顶层字段。
- `biome` 必须等于父环，或属于相邻集合：`island ↔ swamp/mushroom`、`volcanic ↔ desert`、`snow ↔ island`、`desert ↔ volcanic`。不允许 `island → snow` 这类跳变。
- `palette` 的主色相偏移不超过 ±30°；明度/饱和度整体偏移不超过 ±15%。允许 accent 换色作为“新地方”的信号，但天空与水必须留在同族。
- `terrain.peak_height` 变化不超过父环的 ±30%，`roughness` 变化不超过 ±0.2。
- `sky.time_of_day` 变化不超过 ±0.12，不能“走过一道雾就天黑”；实际全局昼夜仍只采用 ring 0 的时钟。
- `mood` 必须像同一个世界的另一角。好例：“雾散后露出的第二座峰”；坏例：“完全不同的世界”。
- `landmarks` 至多 1 个，`kind` 可与父环重复，表示同一文明留下的东西，但 `note` 要写出与父环的关联。
- `regions` 仍是高程—温湿度生态分区，不是外部游戏 biome 的等价表；`weirdness` 变化不超过 ±0.2。

### 步骤 4 · 方向语法

给每个方向一句地形倾向建议，属于软约束，可违反但要合理：

| 方位 | 倾向 |
|---|---|
| 北 | 更高、更冷、岩石更多 |
| 南 | 更暖、更湿、植被更密 |
| 东 | 更破碎、更多离岛、水更多 |
| 西 | 更平、更开阔、地标更多 |

### 步骤 5 · 五个具体的续写手法

写进提示词供模型使用：

1. **同一条山脊延伸**：让新环的最高点接上父环的次峰高度。
2. **水脉延续**：父环有河口，新环就有下游浅滩/三角洲，但零件 32 不改旧河几何。
3. **文明痕迹**：父环地标在新环有原创的“另一半”，如拱门的另一半、骨桥残骸，而不是复制现成模型。
4. **季节/天气迁移**：不是突变，而是同一时刻云更多/更少；天气仍全局统一。
5. **尺度变化**：树变小、石头变大；世界观同一性来自颜色与形状语言，不是尺寸或外部游戏素材。

### 步骤 6 · 解析与校验

复用零件 10 的宽松解析与严格钳制，另加扩环专用校验：

- 色相偏移用 HSL 计算，跨 0°/360° 时取环形最短路径；超限则向父环插值拉回，不是直接接受。
- `biome` 不合法取父环；缺失字段按零件 01 的契约默认值补齐，不让一张空卡进入生成队列。
- 校验 `regions`、`creatures`、`trees`、`slime` 等字段完整且数值合法，确保离线生成器能实际产出地形、植被、生物与碰撞数据。
- 任何被拉回的字段都记进摘要的“扩环修正”，同时记录输入参考是否被拒绝以及原因。

### 步骤 7 · 摘要文件

`specs/ring_{n+1}.md` 必须包含：

- 一段“这片土地是怎么来的”（80 字内，人话）。
- 与父环的差异表：字段 / 父 / 新 / 是否在约束内。
- 一句“你在雾里能看到什么”，给玩家明确期待。
- 生成来源：AI provider/模型标识，或“本地离线预设”；不得包含 Key。
- 原创检查：使用了哪些抽象启发、拒绝了哪些不适用参考，最终资产仍由本项目生成。

### 步骤 8 · 可玩的离线预设兜底

AI 失败、无网络或无 Key 时，使用内置本地扩环预设与父卡做**确定性微扰**，不是随机，也不是只返回一段文字：

- `peak_height × (0.9 + 0.2×方向系数)`。
- accent 色相旋转 15°，主色族和天空/水保持连续。
- `mood` 从本地 mood 库按方向取一条，地标说明与父环建立关联。
- tree density ×（0.85~1.15），regions/tree_mix/creatures 仍生成完整有效值。
- 同一种子、父卡、方向和预设 id 必须得到同一张新环卡与同一批资源 hash。

离线预设必须继续经过零件 32 的新环 GLB/manifest 导出和零件 30 的版本发布，最终在浏览器里能走进新地形、碰到树木/边界、看到植被与地标。**离线可玩**指完整游戏回路可用，不是展示预设 JSON、概念图或不可进入的静态截图。

### 步骤 9 · 验收

1. 四个方向各扩一次，差异表给出具体数字并全部在连续性约束内。
2. 新旧区域经正式 GLB/manifest 链路在浏览器第三人称下同屏检查：色系同族、地形连续、植被和地标为原创低模。
3. 检查参考使用记录，没有外部游戏模型、贴图、图标、标志性布局或 MC 等价目标混入最终资源。
4. 断开网络并移除 Key，用离线预设完成一次“请求 → 生成 → 发布 → 开雾 → 进入新环”，不是只验证卡片解析。
5. 同一离线输入重复导出关键 hash 一致；`specs/ring_{n+1}.json` 与 `.md` 成对存在，spec 中无 Key。
6. 保存 `renders/step_31_browser_*.png/webm`、差异表、离线生成与实机记录。

## 验收标准

1. 四方向扩写满足 schema 与连续性约束，修正记录和摘要数字真实。
2. 参考只提供抽象启发，最终新环是原创低模，不追求或复制 MC/其他游戏素材与等价外观。
3. 新旧区域通过浏览器正式资源版本实际加载，视觉同族、接缝自然、可以进入和碰撞。
4. 离线预设在无网络/无 Key 时也能生成完整 GLB/manifest 并支持真实游玩，同输入可复现。
5. 极端心愿“我想要完全相反的地方”会被约束并注明，不破坏世界身份，不生成另一套游戏风格。
6. spec、摘要、原创检查、离线记录和浏览器实机证据齐全。

## 回退方案

- **AI 总想跳变**：降低采样温度，压缩可选 biome 与色板范围，仍失败就用本地预设，不重复无上限请求。
- **参考把风格带向外部游戏**：删除该参考细节，仅保留地貌/气候抽象关系，并重新做原创检查。
- **色相偏移校验误判**：HSL 差值取环形最短路径，超限向父环插值。
- **新环接缝断崖**：由零件 32 在新环一侧做高度融合；本零件保证 spec 合法，不改旧区块。
- **离线兜底像复制旧环**：在保持色板连续的前提下调整山脊走向、群丛位置和一个关联地标，仍由确定性种子生成实际新几何。
