# 45 · 视角状态机（地表 / 星球 / 宇宙）

> **一句话**：三个视角不是三个场景，是一个世界的三种"观看距离"。切换必须连贯，且任何时刻只有一个真相。

---

## 前置

零件 34（第三人称）、40（轨道相机）、41（宇宙视图）、39（星球化）。

---

## 提示词正文

你是**导演**。你决定"现在用哪台相机、显示哪些对象、锁定哪些输入"。

### 步骤 1 · 三个视角

| 视角 | 相机 | 可见 | 隐藏 | 玩家输入 |
|---|---|---|---|---|
| **`surface`** | 第三人称（34） | 区块、水、植被、生物、史莱姆、迷雾 | 星球本体、大气、轨道、星空 | WASD / 空格 / E |
| **`planet`** | 轨道相机（40） | 星球本体、大气、云壳、星球上的"小点" | 区块（隐藏）、史莱姆、迷雾（改为大气） | 鼠标拖拽/滚轮 |
| **`cosmos`** | 自由飞行（41） | 多星球、轨道、恒星、星空 | 单颗星球的细节、史莱姆 | WASD + QE + 右键 |

**同一个时刻只有一个视角。** 不要做"小窗预览"（会增加一层复杂度，收益极低）。

### 步骤 2 · 状态机与过渡

```
SURFACE ──(M 键 / 抬起视角)──► PLANET ──(拉远)──► COSMOS
   ▲                              │                 │
   └────(双击地面 / 空格)──────────┘                 │
   ▲                                                │
   └────────────(点击行星 → 先到 PLANET 再到 SURFACE)─┘
```

过渡规则（每段都有动画，不许瞬切）：

| 过渡 | 时长 | 做法 |
|---|---|---|
| `surface → planet` | 1.2s | 相机升起 + 地形顶点从平面插值到球面（零件 39） |
| `planet → cosmos` | 0.9s | 相机拉远 + 天体淡入 + 星球缩为"宇宙尺度" |
| `cosmos → planet` | 0.9s | 相机飞向目标行星 + 星球放大到本体尺度 |
| `planet → surface` | 1.2s | 反向球面化 + 相机回到史莱姆身后 |

- 过渡期间：**锁定全部输入**（否则会插值错乱），但显示一个极简的"过渡中"提示。
- 过渡可以被打断（按 Esc）：打断时立即置为源状态，不留在中间。
- 过渡的每一帧都要写当前进度到 `world_state.json` 的 `view` 字段（供网页显示）。

### 步骤 2B · 当前星球（`current_planet`）

三个视角都要知道"我在哪颗星球上"：

- `surface` / `planet`：`current_planet` = 你所在的那颗。
- `cosmos`：`current_planet` = **最后停留的那颗**（不是"选中"的；选中是另一层 UI 状态）。
- 从 `cosmos` 点 `born` 星球降落 → 先跑 43 步骤 6 的现场生成 → 再切 `surface`。
- **`world_state.json` 永远只描述 `current_planet` 的那份数据**。切换星球时，先把当前那份存回 `runtime/planets/{id}/`，再载入目标那份。

这条让零件 01~38 完全不需要知道"多星球"这回事——它们只操作"当前世界"。

### 步骤 3 · 唯一真相与视角无关的数据

**关键设计**：切换视角**不改世界状态**，只改观察方式。

| 数据 | 是否随视角变 |
|---|---|
| `ring`、`island_size`、`seeds`、`unlocked_chunks` | ❌ 不变（世界本体没变） |
| 史莱姆的位置与朝向 | ❌ 不变（`planet`/`cosmos` 模式下它仍在原处，只是看不见） |
| 昼夜时钟 `clock` | ❌ 不变（**三个视角共享一个时钟**） |
| 天气 | ❌ 不变（在 `planet` 模式下表现为"云更多/更少"） |
| `view` 字段 | ✅ 只有它变 |
| `current_planet` 字段 | ✅ 只有它变（切换星球时） |

**这一条要写在代码注释最显眼的位置**：视角是相机，不是世界。

### 步骤 4 · 各视角下的"信息降级"

为了 60fps，每个视角都要主动关掉看不见的东西：

| 视角 | 关闭 | 理由 |
|---|---|---|
| `planet` | 生物行为更新、天气粒子、草花、迷雾墙 | 看不见且开销大 |
| `cosmos` | 上述全部 + 星球本体细节（用 LOD 版） | 同上 |
| `surface` | 星球本体、大气、轨道、星空 | 同上 |

- 关闭用"**隐藏**"，不是"删除"（切回来要能秒恢复）。
- 每类对象的隐藏/显示走同一个控制器，且**幂等**（重复调用不出错）。

### 步骤 5 · 存档与恢复

- `world_state.json` 的 `view` 字段记录当前视角（含过渡进度）。
- 重新打开工程时：恢复到上次的视角（若上次停在过渡中，恢复到源状态）。
- **不要**恢复相机精确位置（容易出怪视角）——只恢复视角类型，相机用该视角的默认位置。

### 步骤 6 · 输入冲突表（必须做对）

| 按键 | surface | planet | cosmos |
|---|---|---|---|
| WASD | 移动史莱姆 | 微调视角朝向 | 平移飞行 |
| 空格 | 跳 | 回到 surface | — |
| `M` | 去 planet | 去 cosmos（再按） | — |
| Esc | 菜单 | 回到 surface | 回到 planet |
| 鼠标左键拖 | 环视（34） | 绕球旋转（40） | 转向（41） |
| 滚轮 | 缩放跟随距离 | 高度 | 速度/拉近 |

写一张对照表放进汇报，并**逐格测一遍**。

### 步骤 7 · 验收

1. 四段过渡都平滑（各录一段）。
2. 过渡中锁定输入，Esc 能打断且回源状态。
3. 切换后世界状态零变化（`ring`、哈希、史莱姆位置都不变）。
4. 三个视角各自 60fps（报帧时间）。
5. 每类对象在对应视角下确实被隐藏（不是删除），切回来秒恢复。
6. 重启后恢复到上次视角。
7. 输入对照表逐格通过（24 格）。
8. 六张截图 + 四段过渡录屏。

## 回退方案

- **过渡后相机位置诡异**：不要恢复精确位置，只按视角默认位；并把"上次相机位置"从状态文件里删掉。
- **切回来时对象没恢复**：隐藏控制器不是幂等的；加一个"按视角强制同步一次"的保险调用。
- **过渡掉帧**：过渡期间先切到 L1 精度，结束后再升 L0。
- **玩家不知道自己在哪**：三个视角各给一个极简的角落标签（`地表 · 第 2 环`、`行星`、`星系`），并让它在 1.5 秒后淡出。
