# 23 · 精致草花、岩石与地标（从零设计）

> **一句话**：用有曲线、有厚度、有材质层次的草花、岩石、海岸小件和原创地标补足世界近景，而不是撒几何碎片。

你是**近景道具与生态细节设计师**。小件也必须有大形、结构、材质和合理接地。近景质量优先，远景通过 LOD 与实例化控制成本。

### 步骤 1 · 草簇

- 每簇由 5～9 片弯曲叶片组成，叶片有根部、主弯和尖端，不是 2～3 个三角形的直片。
- 近景叶片可为 2～3 段窄条闭合体，单簇约 24～72 三角面；中景减少段数，远景用简化有厚度的草形。
- 至少 3 种草簇结构：直立短草、外展宽叶、风吹长草；每簇的叶片长度、朝向和弯曲有协调变化。
- 顶端色稍亮，根部与地表有色彩/阴影接触；可使用原创程序化渐变，不用像素贴图。
- 分布服务视线和路径，不能均匀铺满，也不能穿树根、地标和角色出生点。

### 步骤 2 · 花

- 花茎有 1～2 段自然弯曲，至少一片小叶；花头由 5～8 片有轻微弧度的花瓣围绕中心构成。
- 近景单朵约 60～120 三角面，中景保留花瓣轮廓，远景用简化多角色点，不是 5 边圆片。
- 至少 3 种花型：小钟形、展开星形、低伏簇花；同簇有高低与朝向变化，不全朝正上方。
- 花色由 accent 派生，花瓣中心、边缘和花心有轻微色差；风动很轻，不能像机械旋转。
- 3～7 朵成簇并与空地、路径形成构图，不随机撒满全岛。

### 步骤 3 · 岩石

- 从定制多环/多面拓扑形成不对称轮廓，具有主切面、次级断面、接触面和少量边缘倒角。
- 小石约 40～80 面，中石 100～240 面，大石/岸石 300～800 面；远景再简化，不能统一用 8～20 面多面体。
- 至少 4 种轮廓家族：扁层岩、圆钝岸石、尖脊碎岩、风蚀巨岩。不是同一 mesh 非均匀缩放。
- 材质包含岩层色带、粗糙度、接触阴影和少量地层变化；大石在近景不能只是一块灰三角。
- 埋地比例按底部形状调整，不只统一埋 30%；重点检查接地稳定、碰撞和相机构图。

### 步骤 4 · 漂流木与贝壳

- 漂流木使用 6～8 边弯曲干体，包含断枝、裂口端面和少量年轮/纵向色带，约 80～220 面；不是细长棱柱。
- 贝壳为带弧度与扇形肋纹的薄壳，边缘有轻微缺口，约 40～100 面；不是半圆薄片。
- 姿态顺沙面、潮线和风向布置，有轻微埋沙与接触阴影；不能立着、悬浮或等距排队。

### 步骤 5 · 原创地标

地标必须先有独立剪影和结构草图，近景参考 300～2,000 面/处，按屏幕重要性分配：

| kind | 原创结构要求 |
|---|---|
| `arch` | 非对称石拱，具有支撑脚、错位拱块、风蚀边与爬生色带，不是两方柱加弧 |
| `giant_tree` | 使用 22 的高品质根干结构并重新设计巨化比例、根廊与冠层，不只放大 6 倍 |
| `meteor` | 斜插晶岩体、破裂外壳、周围冲积土与少量冷色内芯，焦痕融入地表而非黑圆环 |
| `lighthouse` | 原创风标塔，具有收分塔身、平台、支撑、灯室和光路，不是圆柱加亮点 |
| `bone_bridge` | 多节自然弧形骨状结构、连接支撑与磨损面，能解释跨越关系，不是三段弧 |
| `shrine` | 低矮台地、偏心立石、刻槽色带与小供台，轮廓安静独特，不做通用庙宇拼装 |

- 地标服务导航与近景探索，位置可站立、可绕行、不挡出生点；互动入口与相机视野需预留。
- 近景无穿插、悬浮和粗糙拼合，远景仍能靠剪影识别。

### 步骤 6 · LOD、实例与构图预算

- 草花、贝壳和小石按 0～8/8～25/25 BU 以上设置近/中/远表现；大石和地标按屏幕占比切换。
- 近景细节不被全局面数预算优先砍掉；先减少远处实例、合批和更新频率。
- 共享模板按结构变体建立，实例化后仍保持位置、旋转、接地和材质一致。
- 密度只是上限，按视线留白和路线构图安排；近景不要同时把所有小件挤在镜头里。

### 步骤 7 · 高保真验收

1. 草叶弯曲、花瓣层次、岩石断面、漂流木端面和贝壳肋纹在近景清晰可辨。
2. 所有小件接地自然，无漂浮、明显穿插、纸片感或同一模型机械复制。
3. 地标有独立剪影和完整结构，能绕行探索，不是 primitives 拼合。
4. 浏览器保存草地、海岸、岩石、地标近景与对应中景图，附 360°近景录屏。
5. 记录源面数、LOD、实例和实际渲染量；美术不合格不能用“小件不重要”豁免。

---

## 验收标准

1. 草、花、岩石、漂流木、贝壳与地标均为从零设计的精致低模，具有真实结构差异。
2. 近景拓扑、法线、材质和接地质量通过；没有圆片花、三角草、灰块石和棱柱木。
3. 实例与 LOD 控制成本但不牺牲近景，资源版本与散布确定。
4. 高保真实机图、绕看录屏和性能数据完整。

---

## 回退方案

- **细节变噪点**：减少小件数量，扩大近景主形和留白，不靠加面解决构图。
- **像廉价素材包**：回到轮廓与结构变体，调整材质统一性和接地，禁止换现成包。
- **地标像积木**：重做支撑、比例和边缘结构，不用更多小方块装饰。
- **性能不足**：减少远景实例和更新频率，不删除近景花瓣、断面和根干细节。
