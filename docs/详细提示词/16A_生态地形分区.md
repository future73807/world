# 16A · 生态地形分区

> **一句话**：用高程、温度、湿度与地层让岛的不同区域有自己的生态身份，而不是铺满同一种绿色或复制外部游戏。

---

## 前置

零件 16（高度函数）、17（岛屿轮廓与海岸）通过；世界设定卡中有合法 `regions`。浏览器和 Blender 已能调用同一套分区定义。

### 步骤 1 · 本项目自己的区域语言

区域由四类可感知信息组成：

1. **高程带**：低地、丘陵、山地拥有不同地表色、植被与通行节奏。
2. **湿度**：干燥区偏暖黄，适中区偏草绿，湿润区偏青绿。
3. **温度**：暖区多阔叶，冷区多针叶，极冷高处显露雪与裸岩。
4. **地层断面**：陡坡可以看到有节制的土层和岩层变化，但不做等距棋盘横纹。

这些只使用本项目 spec、seed 和原创色板，不能映射成 MC 群系名称、材质或标志性造型。

### 步骤 2 · 连续区域权重场

spec 的 `regions` 有 1～5 个区域。为每区赋予由 `derive(seed, "region")` 决定的中心和影响范围：

- 中心在岛内，彼此尽量相隔至少 `island_radius * 0.45`，避免全挤在一起。
- 权重使用平滑钟形衰减并归一化，所有采样点权重和为 1。
- 边界采用 8～12 BU 的过渡带，不画行政区划般的硬线。
- 权重函数只依赖世界坐标、seed 与 spec，同坐标在 Blender、浏览器和地图中结果一致。

逐点计算：

| 属性 | 规则 |
|---|---|
| 附加高程 | 各区 `elevation` 权重 × `elevation_boost`，叠加且不破坏海岸约束 |
| 地表材质 | 加权 `moisture` / `temperature` / 高度查统一判定表 |
| 树种倾向 | 各区 `tree_mix` 加权，交给 21A |
| 色彩微调 | 各区 `palette_shift` 加权，幅度受全局色板约束 |

Python 与 TypeScript 必须共享可测试的输入/输出样例；不得各自调一套阈值，导致地图和脚下不同。

### 步骤 3 · 材质判定

按以下顺序命中第一项：

| 条件 | 地表表现 | 色板来源 |
|---|---|---|
| T < 0.25 且高于雪线 | 雪与少量露岩 | `snow` + `rock` |
| T < 0.35 | 冷色针叶林地 | `grass` 压暗约 20% |
| M > 0.72 且位于低地 | 湿地青绿与浅水苔 | `grass` 偏青约 15% |
| M < 0.28 | 干草与暖沙土 | `sand` 偏黄 |
| 高度 > 0.7×峰高 | 裸岩切面 | `rock` |
| 其余 | 低模草坡 | `grass` |

- 每种材质内部允许受 seed 驱动的少量面色差，但禁止像素纹理、方格描边和噪点贴图。
- 相邻三角面的明度差不能掩盖大轮廓，不能在玩家脚下制造密集闪烁。

### 步骤 4 · 崖壁地层

对坡度大于 `strata_slope` 的面按世界 Z 划分 3～4 个色带：

- 低处偏土色，中间为岩色，高处偏冷灰或雪色。
- 层厚允许 ±15% 低频扰动，宽度随山体尺度变化，避免整座岛都是平行尺纹。
- 同层使用纯色和硬边，但明度差保持克制；地形仍以三角切面为主，而非条纹贴图。
- 地层颜色在 GLB 中以材质或顶点属性导出，浏览器不能另造一套分类。

### 步骤 5 · 与地形、植被和地图分工

- 16A 决定“这里是什么生态与材质”；18 负责“低模材质如何着色与导出”。
- 16A 不直接摆树；21A 统一决定树种、群丛和空地。
- 不用暗色实心椭球假装可进入洞穴；真实洞口、洞内 GLB 与浏览器碰撞由 16B 负责。
- `map_tiles.json` 的区域分类与颜色直接来自本零件同一判定结果。
- 小地图默认只显示必要轮廓与区域色；`note` 在展开地图或查看区域时出现，不形成游戏侧栏。

### 步骤 6 · 实机验收

1. 默认第三人称走 60 BU，至少能辨认 3 个区域，过渡自然。
2. 近看草坡与崖壁仍是连续低模三角形，没有方砖、网格线或像素表面。
3. 雪线上无草地，湿地无干草；判定顺序符合契约。
4. 随机 100 个采样点权重归一化误差 <0.01，并报最大值。
5. Python 与 TypeScript 对固定测试点输出相同分类；至少覆盖 3 种区域与边界点。
6. 浏览器区域、小地图与 GLB 三者颜色一致；俯瞰图只作诊断附件。

## 参数表

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `region_count` | 3 | 1~5 | 实际区域数 |
| `region_min_dist` | 0.45R | 0.3~0.6 | 区域中心最小距离 |
| `region_blend_bu` | 10 | 4~20 | 区域过渡带宽 |
| `elevation_boost` | 4 | 0~10 | 区域附加高程上限 |
| `strata_layers` | 4 | 2~5 | 崖壁色带层数 |
| `strata_slope` | 0.55 | 0.4~0.7 | 地层判定坡度 |
| `strata_jitter` | 0.15 | 0~0.3 | 层厚扰动 |
| `snow_temp_th` | 0.25 | 0.15~0.4 | 雪线温度阈值 |

## 验收标准

1. 三种区域在默认实机镜头中可辨，不靠俯瞰才能看出。
2. 地层有低模切面感，不存在方块化或整岛统一平行条纹。
3. 权重、材质判定和跨运行时测试全部通过。
4. 小地图与脚下分类一致，浏览器中可直接走近所有区域。
5. 证据含默认跟随截图、崖壁近景、区域过渡录屏和测试数字。

---

## 回退方案

- **区域看不出差异**：先调整植被与色板层次，不增加方块或网格线。
- **边界像圆圈**：缩短高梯度段并加入低频扰动，保持权重归一化。
- **地图与 GLB 颜色不同**：停止分别计算，统一判定样例和导出数据。
- **地层太花**：减少一层并降低相邻明度差，恢复山体大轮廓。
