# 00 · 索引与执行顺序

> 58 份文件：本索引 + 57 个零件（46 个地表件 + 8 个字母后缀件 + 11 个星球/宇宙件 39~49）。
> 相关设计依据（**新增元素前必读**）：
> - `docs/MC元素对照表.md` — MC 五大分类 2,095 条目逐类对照
> - `docs/宇宙模拟软件对照表.md` — SpaceEngine / Universe Sandbox 功能对照

## 怎么用

**单零件**：打开对应 `.md`，从「提示词正文」开始整段发给 ZCode。

**整套**：对 ZCode 说：

> 读 `docs/详细提示词/00_索引.md`，从零件 02 开始按顺序施工。
> 每做完一个零件：自检、三机位截图、存 `world/step_NN.blend`、三行汇报。
> 破坏性操作前先问。

**跳做**：允许，但必须满足该零件的「前置」。前置没完成的，先补前置。

## 三条施工路线（时间不够时怎么砍）

**A · 只看效果（半天）**
01 → 02 → 14 → 15 → 16 → 17 → 17A → 18 → 19 → 20 → 20A → 21 → 22 → 23B → 24 → 25 → 26 → 34 → 37（部分）
砍掉：所有网页、AI、迷雾、地图。产出一座能截图的海岛 + 一只会呼吸的史莱姆。

**B · 要"走到哪生成哪" + 迷雾（一天）**
A 的全部 + 16A → 17A → 21A → 23A → 23B → 16B → 20B → 28 → 29 → 35 → 37（部分）
砍掉：API Key 和网页驾驶舱，解锁用固定预设推进。产出开放世界手感 + 拓荒爽感。

**C · 完整版（两到三天）**
全顺序。G1~G6 全过。

**D · 星球与宇宙（在 B 之后加半天）**
B 的全部 + 39 → 40 → 41 → 42 → 43 → 44 → 45 → 46 → 48 → 49。
砍掉：AI 生成宇宙（用 43 的本地模板造 4 颗）、47 的深度编辑器（只留基础编辑）。产出「从太空看自己走过的岛」「多星球星系」「改重力就跳不动」。
