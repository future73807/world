# 17 · 岛屿轮廓与海岸线

> **一句话**：给高度场套一个"岛的蒙版"，让边缘自然沉入海里；再铺一条连续沙滩和一段水下缓坡。

---

## 前置

零件 16（高度函数可用）。

---

## 提示词正文

你是**海岸线设计师**。目标：岛的轮廓不圆、沙滩连续、入水处平缓，走近海边有"能下脚"的感觉。

### 步骤 1 · 岛屿蒙版

定义"岛屿半径"随角度变化的函数：

半径随角度变化的语义（文字化描述，不是代码）：以 `base_radius` 为基准，叠加三条不同频率的正弦扰动——三阶（振幅 18%）、五阶（10%）、九阶（6%），每条各带一个由种子决定的相位。

- 相位 `p1..p3` 由 `derive(seed, "coast")` 决定。
- `base_radius` 默认 48（出生岛边长 100，半径约一半稍减）。
- 再叠加一小段双频噪声扰动（振幅 2~4 BU），避免"波浪形圆"。

**蒙版的应用**：把高度乘以一个随"距中心归一化距离"衰减的因子。关键在手感：**从岛心到边缘，先是平的、再快速下降、最后在水下缓平**。用平滑阶跃曲线，不要线性。

### 步骤 2 · 沙滩带

沙滩 = 高度落在 `[ -0.3, beach_height ]` 的过渡带，`beach_height` 默认 1.2 BU。

- 沙滩必须**连续**：绕岛一圈，不允许断成几段（除非用户 spec 明确要多岛）。
- 沙滩宽度由 `beach_width`（spec，2~8 BU）控制，映射到蒙版的斜率上：宽度越大，过渡越缓。
- 沙滩表面略微压平（把该带内高度向 0.5 拉 30%），脚感更稳。

### 步骤 3 · 水下坡

沙滩往外继续下降，形成浅滩与深水：

- 0 ~ -2 BU：浅水缓坡（斜率约 0.15）
- -2 ~ -8 BU：陡一点（斜率约 0.45）
- -8 以下：平底

这部分在零件 19 会被水遮住，但玩家从水上能看见颜色变化（浅水偏青、深水偏深蓝），所以几何要连续。

### 步骤 4 · 多个小岛（可选）

若 spec 的 `island_bias` > 0.6，在 R(θ) 之外再造 1~2 个小离岛：

- 半径 6~12 BU
- 高度峰值 2~6 BU
- 与主岛最近距离 > 10 BU（留出水道）
- 位置由 `derive(seed, "islet")` 决定

不要做 5 个以上——低模世界里"多"会变成"乱"。

### 步骤 5 · 与区块的配合

蒙版是**全局函数**，接入方式与零件 16 完全一致：`h_final(x,y) = h_raw(x,y) * mask(x,y) + underwater_profile(x,y)`。所有块独立求值，不共享状态。

落在岛外的块：仍要生成水下地形（不能是空洞），否则从岸边看过去是一个天坑。

### 步骤 6 · 验收

1. 正俯视截图：轮廓不圆，海岸线自然。
2. 贴地截图（站在沙滩上向海）：沙滩带连续，水下坡不陡崖。
3. 绕岛走一圈（可瞬移采样 16 个方位），每一步都有沙滩或浅水，无"直接断进深水"的地方。
4. 打印绕岛 16 个方位的最外沙滩点半径，标准差不要过大（> 40% 说明轮廓太怪，回调）。

## 参数表

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `base_radius` | 48 | 36~64 | |
| `coast_wave_amp` | 0.18 | 0.1~0.3 | 三阶轮廓 |
| `coast_noise_amp` | 3.0 | 1~6 | 轮廓噪声 |
| `beach_height` | 1.2 | 0.6~2.0 | |
| `beach_width` | 4 | 2~8 | 来自 spec |
| `shore_slope` | 0.15 | 0.08~0.3 | 浅滩坡度 |
| `deep_slope` | 0.45 | 0.3~0.8 | |
| `islet_bias` | 0.6 | | 触发多岛的门槛 |

---

## 验收标准

1. 俯视轮廓不圆、不出现"锯齿圆"。
2. 沙滩绕岛一周连续，`beach_width` 可感知地改变宽度。
3. 站位在沙滩看海，水下坡无断崖。
4. 16 方位采样半径合理（汇报标准差）。
5. 多岛开关打开后，离岛不与主岛粘连。
6. 三张截图（俯视、沙滩、水下坡侧面）。

---

## 回退方案

- **沙滩断开**：多半是蒙版噪声过强导致某些角度"直接进了深水"；把 `coast_noise_amp` 降到 2，或对蒙版做一次平滑。
- **蒙版让山也塌了**：蒙版应只作用于"径向衰减"，不要乘到主峰体上；检查叠加顺序。
- **多岛像碎渣**：把离岛半径下限提到 8，数量降到 1。
