## 提示词正文
> **共同硬约束（独立执行本零件也必须遵守）**
> - 主游玩端是浏览器全屏 Three.js/WebGL；Blender 只负责从零生成、导出和离线检查，禁止把“打开 Blender”作为玩家步骤。
> - 恢复包中的任何文件均不得读取、参考或导入；所有 UI、模型、材质和动画从空白重新设计，禁止迁移、换皮或使用外部游戏/现成模型包资源。
> - 目标是**精致风格化低模**：大/中/小结构、合理拓扑与平面/分组平滑/加权法线、原创程序化材质和近景细节。低面数不等于简陋，禁止方块、体素、像素纹理和粗糙 primitives 通过。
> - 新模型先交剪影、灰模、材质完成图及近/中/远实机证据；美术不合格不能用低面数、帧率或“非 MC”豁免。
> - 新 UI 先交桌面/触屏线框和高保真 HUD/地图/暂停/创建/互动设计稿，使用原创图标、合法字体和统一 token；只参考开放世界游戏的信息层级，不复制具体素材。
> - 默认第三人称跟随。角色具有起步、移动、停止、转向、跳跃预备、上升、顶点、下落和落地；桌面 WASD/指针锁定/空格/Shift/E/M/J/Esc，触屏才显示虚拟控件；松鼠标不强制回正。
> - 禁止三栏/左右常驻面板/常驻日志。CLI 与性能工具默认隐藏，创建、设置、编辑只在高保真非驻留界面。
> - 本零件与上述约束冲突时，上述约束优先；若正文仍存在旧指令，停手报告，不擅自回退产品方向。

你是**游戏美术、交互与技术总验收工程师**。所有正式视觉与操作证据来自本次从零工程和浏览器实机。不得读取恢复包，不得用外部游戏/现成模型包/通用网页皮肤替代原创设计。

### 步骤 1 · 封存可验收版本

1. 汇总当前新源资产、GLB、地图、材质、动画、UI 和状态，生成不可变 `asset_version`。
2. 清单的 seed、ring、资源 hash、LOD、spec 与地图一致，所有文件完成后才发布。
3. 保存 `world/final.blend` 作为新源工程，玩家只从浏览器进入。
4. 记录独立源面数、驻留 LOD、实例源面数、实际渲染三角面、draw call 与帧时间，禁止混为一个数字。
5. 输出 `runtime/acceptance.json`，逐项记录通过/失败/未做、实测值和证据路径，不写“应该可以”。

### 步骤 2 · 一票否决

任一项出现即整体不通过：

- 读取、参考或导入任何恢复包实现，或使用外部游戏/现成模型包资源。
- 模型虽非方块，但明显是 primitives 拼合、圆片花、球冠树/菌、三角鱼、压扁球云或少量大三角的粗糙演示。
- 用“低模”作为全平面法线、极低面数、缺少大/中/小结构和近景细节的借口。
- UI 只有线框/默认组件皮肤，或仍是三栏、驾驶舱、通用网页表单；没有高保真统一视觉。
- 操作只是按键有反应，存在明显滑步、速度突变、机械切换、镜头强制抢回或互动提示闪烁。
- 必须打开 Blender才能游玩，或用静态图/视频/iframe 冒充实时游戏。
- 通过强 Bloom、滤镜、景深、特殊角度或降低近景质量掩盖美术问题。

### 步骤 3 · A 组 · 精致模型与材质

逐项验收并附高保真证据：

1. 所有关键模型有本次原创剪影、结构说明、灰模和材质完成图，来源可追踪。
2. 角色、树木、岩石、道具和地标具有大/中/小三层结构，近景不是 primitives 拼合。
3. 史莱姆为定制水滴拓扑，主体参考 1,200～2,000 面、整只近景 ≤3,000；面部、形态键和 LOD 完整。
4. 折伞树、叠羽树、灯菌树具有根颈、主枝、冠层厚度、合理法线和至少 3 个真实结构变体。
5. 草有弯曲叶片、花有茎叶花瓣、岩石有主/次断面、漂流木有端面、贝壳有弧度和肋纹。
6. 菌群具有伞盖厚度、弯柄、菌褶与菌丝；生物具有完整身体与翅/鳍/钳；云有闭合体块与层次。
7. 地形是连续共享顶点三角网，没有独立方砖、体素、像素纹理、网格描边和方块海岸。
8. 法线按区域选择平面/分组平滑/加权法线，不全局过硬或过滑；近景没有明显穿插和翻面。
9. 草、沙、岩、雪、树皮、水和果冻在近景通过粗糙度、透光、色带、接触阴影等可辨，不是同种塑料换色。
10. 原创程序化纹理和非像素细节使用合理，无外部贴图；强 Bloom/滤镜未掩盖材质缺陷。
11. 近、中、远三距离均有实机图，LOD 保持身份，切换不突然变成粗糙模型或产生明显闪烁。
12. 基础地形为 100 块×200=20,000 面；默认实际渲染出生岛目标 ≤250k，满环目标 ≤570k，统计口径正确。

### 步骤 4 · B 组 · 动画与开放世界操作

13. 浏览器具有待机、起步、移动、停止、转向、跳跃预备、上升、顶点、下落和轻/重落地的完整状态。
14. 起步/停止/转向与真实速度、加速度和角速度同步，没有明显滑步、瞬间满速或瞬间翻面。
15. 坡面、台阶边缘、块缝、空中与落地碰撞稳定，资源切换不改变脚下高度或重置玩家。
16. 动画局部滞后、眼神和落地反馈自然，最大挤压/拉伸时面部、法线和透明层不穿帮。
17. 鼠标自由环视后镜头不强制抢回；移动辅助回正可配置，任何新输入优先。
18. 跟随、缩放、避障和遮挡淡出自然；贴山、进林、进洞和角色过近时不穿墙、不贴脸、不抽动。
19. 当前最佳互动目标按距离/方向/可达性选择且有去抖，E 提示、蓄力、取消、完成和失败清楚。
20. 桌面与触屏输入、提示图标和布局随最近输入正确切换，无双跳、粘键和输入穿透。
21. 30/60fps 与模拟长帧下运动响应一致；关闭 Blender 后全部成立。

### 步骤 5 · C 组 · 高保真 UI 与地图

22. 有桌面/触屏线框、高保真 HUD/地图/暂停/创建/互动效果图、视觉 token 和交互分镜。
23. 默认 HUD 与确认稿一致：字体、原创图标、间距、透明度、色彩、层级和动效协调，世界占主体。
24. 小地图、当前目标、必要状态和情境提示清晰，不遮挡角色与前路；无三栏/固定侧栏/常驻日志。
25. 全屏地图可缩放、拖动、回到玩家、选择地标、设置/取消路径点，游戏内方向引导正确且不传送。
26. 地图图例/筛选在按需抽屉，地图与 GLB/迷雾/资源版本一致，无棋盘格和调试样式。
27. 暂停/设置/世界创建具有完整游戏视觉，关闭后精确恢复玩家、相机、目标和时钟。
28. 默认/hover/focus/pressed/disabled/selected/loading/error 状态完整，键盘焦点、对比度与触屏点击区可用。
29. 字体来源与 license 合法，图标为原创；没有复制原神或其他游戏的素材与默认网页皮肤。
30. CLI、日志、性能工具默认隐藏；普通玩家不需要接触开发者功能。

### 步骤 6 · D 组 · 世界、拓荒与稳定性

31. 走远与返回后区块、树种、结构变体、材质和 hash 一致，近景质量不下降。
32. 水面、岸、雾、天空、昼夜和天气表现稳定，近景水体/云/粒子具有设计过的细节而非简单面片。
33. 小地图与脚下同源，玩家朝向、地标、路径点、迷雾边界一致，扩环同步。
34. 迷雾有碰撞与情境 E；连点只产生一个作业，失败保持旧版本，成功不中断玩家操作。
35. 扩环只追加新资源，旧 hash 100% 不变；玩家、相机、天气、时钟不重置，接缝无 >0.5 BU 异常阶跃。
36. 新环保持原创精致模型与统一世界气质，不是旧块矩阵复制或低成本 primitives 填充。
37. 同 seed 可复现；断网/无 Key 可从本地预设进入完整游戏，不停在设置页。
38. 缺 GLB、hash 错误、WebGL 丢失和断线均有恢复/明确提示，不用静态图掩盖。
39. 默认实际渲染和满环压力测试记录 fps、中位/p95、draw call、实际三角面；不得用 Blender 帧率替代。

### 步骤 7 · 可选宇宙

未做则整组标“未做”，不阻塞核心版。若做：所有观察与编辑仍在 Three.js，切视角不传送/重置地表玩家；编辑器非驻留且高保真；尺度标“示意”；天体和 UI 同为原创精致风格，不变成另一个后台。

### 步骤 8 · 高保真演示

`renders/DEMO.md` 的核心流程：

1. 默认跟随展示史莱姆与近景材质，起步、移动、停止、急转、跳跃和落地。
2. 走近折伞树/岩石/花草，环绕检查细节，再拉远验证 LOD。
3. 自由环视停留，证明镜头不抢回；进入树林验证遮挡处理。
4. 打开全屏地图，选择地标并设置路径点，返回后沿引导前进。
5. 打开暂停/设置再关闭，验证状态与视觉恢复。
6. 到迷雾按 E 蓄力、取消一次，再完成拓荒；新环进入后旧区域与近景质量不变。
7. 展示黄昏/天气和角色材质，回到默认游戏镜头结束。

不先展示 CLI，不切 Blender，不用整岛俯瞰替代上述过程。

## 验收标准

1. 一票否决为零，核心 39 项逐项有真实结论与证据。
2. **精致模型、高保真 UI、开放世界操作和浏览器可玩四方面同时通过**，任何一方面不能由其他方面抵消。
3. 近景美术、完整运动、自由相机、地图路径点和高保真界面均有连续实机证据。
4. 所有统计、版本、hash、帧率与资源来源真实，可选功能未做则如实标记。
5. 用户能通过演示直接复核，不需要开发者临时补操作或解释“低模就应该粗糙”。

## 回退方案

- **模型粗糙**：回到剪影/灰模/结构评审，允许增加定制拓扑、合理法线和原创材质，不继续堆功能。
- **UI 像网页**：回到高保真设计包，重做视觉层级与状态，不换另一个组件库皮肤。
- **操作像技术演示**：回 27/34 修控制器和相机，不用动画/粒子掩盖。
- **性能不足**：先调远景实例、LOD、更新频率和后处理，不把近景主角与模型退回方块/简陋几何。
- **浏览器无法运行**：明确不通过，不提供仅 Blender 演示的退路。
