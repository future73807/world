# 37 · 总装与验收

> **一句话**：把散件装成一套能演示的东西，然后逐条过 21 条验收——用截图和数字说话。

---

## 前置

全部零件（至少 01~36；37 可以跳过 25 的精细材质，但不能跳过 30/32）。

---

## 提示词正文

你是**总装工程师**。这一轮不再新增功能，只做四件事：接好、清干净、跑一遍、留证据。

### 步骤 1 · 总装

1. 从当前最新的 `step_NN.blend` 或 `ring_N.blend` 起，合成 `world/final.blend`：
   - 出生岛 + 所有已解锁环的对象**合并到一个场景**（不保留多场景）。
   - 所有区块按当前史莱姆位置装载（L0 半径 3 块），其余为 L1/L2。
   - 雾墙移动到当前边界。
   - 水面、天空、太阳、云按当前环的 spec。
   - 史莱姆在出生点，相机在跟随位。
2. `final.blend` 打开即完整可用：**不需要再跑任何脚本**。
3. 把 `world/scripts/` 里能复用的生成器留下，把一次性实验脚本移到 `world/scripts/_archive/`（不要删，便于回溯）。

### 步骤 2 · 清理

- 删除参考网格、调试用占位小球、临时相机、测试空物体。
- 删除未被引用的材质、网格、集合。
- 确认没有对象在 Scene Collection 根下。
- 确认没有对象命名违契（前缀检查）。
- 把最终状态写进 `runtime/world_state.json`（ring、island_size、seeds、player、fsm=idle）。

### 步骤 3 · 验收清单（A~E 共 21 主项 + 9 地表子项 + 11 宇宙子项）

逐条执行、逐条记录"通过/不通过 + 证据（截图名或数字）"：

**A. 交付与启动**
1. `world/final.blend` 打开即完整出生岛，无需脚本。
2. 浏览器 `npm run dev` 起得来，三栏都有内容，无控制台报错。
3. 内置 CLI 能跑 `blender --version`，危险命令被拦。

**B. 世界与流式**
4. 史莱姆从出生点向任意方向走 60 BU，全程地形连续、无空洞、无浮空。
5. 走远后回来，地貌完全一致（区块哈希一致，报数字）。
6. 远端区块以 LOD 形态存在，靠近后变细，无明显接缝错位。
7. 水面有波浪、岸边有浪花线、水下地形隐约可见。

**C. 角色**
8. 史莱姆能走（WASD）、能跳（空格）、落地压扁、待机呼吸、会眨眼。
9. 松开输入 2 秒后，AI 接管且行为自然（不是抽搐）。
10. 史莱姆不会走进水里、不会卡在树上。

**C2. 预制元素（地形/植物/动物/天气/昼夜）**
10a. 地形至少 3 个可辨区域 + 崖壁 3~4 层硬边横纹（零件 16A）。
10b. 植被分区：至少 3 种"植被性格"地带，林→空地节奏 2~4 次 / 60 BU（零件 21A）。
10c. 五种生物可见，且夜间萤火虫出现、能被史莱姆追到（零件 23A）。
10d. 时间真的在走：加速 ×60 走完一整天，阴影方向随之变化（零件 20A）。
10e. 五种天气各能触发：雨有涟漪、雪会积、风暴更浪且有闪电（零件 20B）。
10f. 岛内有河（水面低于两岸）与湖；至少 1 条河能流到海或成湖（零件 17A）。
10g. 至少能走进 1 个洞，洞内有第二出口或天窗（零件 16B）。
10h. `mushroom` / `swamp` / `volcanic` 三个 biome 都能生成且特征明显（零件 23B）。

**D. 迷雾与拓荒（核心）**
11. 走到边缘撞不进迷雾；能贴墙滑；有"陷进去再被推回"的手感。
12. 边缘出现"按住 E"；蓄力环填充；满蓄力有静默；松手无惩罚。
13. 满蓄力后：后台作业启动，CLI 面板滚日志，进度条前进。
14. 作业成功后：页面弹「世界有新的变化，快去看看」，雾退 1.5 秒，新环显影。
15. 扩环后旧区块哈希 100% 不变（报数字）；接缝 5 BU 内无 > 0.5 BU 的阶跃。
16. 新环的 `biome` / 色相 / 地形与旧环同族（报色相偏移数值）。
17. 地图遮罩同步退一圈，地图尺寸与 3D 一致。

**D2. 星球与宇宙（若做了阶段 5，否则整组标"未做"）**
11a. 按 `M` 能从地表升到星球：看到自己走过的那座岛卷成球（零件 39）。
11b. 轨道相机绕球顺滑、滚轮是高度、空闲自转（40）。
11c. 拉远到宇宙：多颗行星在椭圆轨道上公转，有明暗交界线（41）。
11d. 改恒星质量，所有周期明显变快（42，报倍率）。
11e. 3~7 颗星球的宇宙卡合法，星球间至少三处不同（43）。
11f. 星球边缘辉光只在亮侧、云壳自转更快（44）。
11g. 地表↔星球↔宇宙四段过渡平滑，**世界状态零变化**（45，哈希验证）。
11h. 星图上的行星公转与 3D 一致，点星能飞过去（46）。
11i. 星球编辑器七组十四段字段全可改；改配色后太空中那颗球颜色也变（47）。
11j. 十种天体至少见到六种；彗尾背离恒星；行星环与自转轴对齐（48）。
11k. 改某行星质量到 2.0，地表跳跃明显变低、落地压得更扁；挪到内圈雪消失（49 的两条因果链）。

**E. 韧性与预算**
18. 断网 / Key 无效时，仍能生成六套预设之一，摘要徽章正确。
19. 七家 provider 面板都能配置；至少四家实测连通（OpenAI / Claude / Gemini + 任一中转）；主家失败自动换家成功。
19b. 生物 / 天气 / 昼夜推进 / 雾 / 草花 五个开关各关一次，世界都能跑（零件 35 开关矩阵）。
20. 连点两次拓荒只有一次生效；作业失败能回滚到扩环前状态。
21. 环数上限时帧时间达标（或已按零件 35 顺序降级并汇报最终数字）。

### 步骤 4 · 演示剧本（3 分钟）

写成 `renders/DEMO.md`，按这个节奏：

1. **0:00-0:20** 打开网页：抽三张卡（苔藓/鲸骨/黄昏），滑杆推到"奇诡"。
2. **0:20-0:40** 点生成 → 内置 CLI 开始滚日志 → 进度条走过地形/水/树/史莱姆。
3. **0:40-0:55** 弹通知"世界有新的变化" → 点「打开 Blender」→ 俯瞰机位展示整岛（可切六套预设对比）。
4. **0:55-1:30** 切跟随位，带史莱姆走一圈：过沙滩、进水边的浪花、绕过树、跳一下（落地压扁）。
5. **1:30-1:55** 走向迷雾边缘 → 雾变薄 → 按住 E → 蓄力环满 → 静默 → 触发。
6. **1:55-2:20** 切俯瞰：雾退一圈、新土地显影、地图外扩。
7. **2:20-2:40** 地图 hover 边缘"可拓荒" → 走进新土地 → 看到新地标。
8. **2:40-2:50** 切到黄昏（时间跳到 18:10）+ 触发一场雨：雨落、水面起涟漪、史莱姆更透。
9. **2:50-2:56** 沿河走一段（水面低于两岸、纹理在流），抬头看见瀑布。
10. **2:56-3:00** 切电影位收尾：日落、雨、雾、史莱姆剪影；镜头外萤火虫慢慢亮起。

## 验收标准

1. 41 条逐条有结论 + 证据（未做阶段 5 时，D2 整组标"未做"）。
2. `final.blend` 打开即用。
3. `DEMO.md` 剧本可照做。
4. 六类截图齐。
5. `HANDOVER.md` 三节齐全。
6. 场景无违契命名、无根下游离对象、无未引用数据块。

## 回退方案

- **某条不过但不影响演示**：如实标记"未通过"，写清原因与影响面，不要含糊。
- **总装后帧率崩**：把 L2 半径缩小，或先把最外环整圈设为 L1 静态呈现。
- **网页起不来**：用 `renders/DEMO.md` 里备用的"仅 Blender 演示"路线，并在交底里写明。
