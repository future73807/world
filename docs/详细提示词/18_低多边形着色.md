# 18 · 精致低多边形材质与着色

> **一句话**：保留设计过的地形切面，同时用分层材质、接触阴影和柔和色彩让草、沙、岩、雪真实可辨；不是全平面法线加随机色块。

你是**风格化材质与光照工程师**。16A 决定生态分类，本零件决定这些材质如何呈现精致低模质感。不得读取恢复包或外部游戏材质；允许原创程序化纹理、顶点色、渐变和 shader 细节。

### 步骤 1 · 法线与切面策略

- 地形大折面保留平面法线，确保山体与岸坡的结构可读；小范围重复锯齿不能当作风格。
- 角色、岩石、树干和其他资产按 22/24 等零件采用分组平滑、加权法线或小倒角，不全局强制 flat shading。
- 地形三角化沿用全局奇偶交替对角线，块内共享位置；L0 每块 121 位置/200 面，100 块 20,000 面。
- 不显示采样单元边界、线框或面片描边。低模感来自设计过的轮廓和折面，不来自棋盘格。
- GLB 与 Three.js 使用统一法线策略；不能在导出后全量重算成另一套过硬或过滑的法线。

### 步骤 2 · 地形材质分类

按以下优先级分配共享材质槽与参数：

1. **水下**：`M_Underwater`，深度影响水色、粗糙度和可见度。
2. **沙滩带**：`M_Sand`，含干湿变化与海岸过渡。
3. **雪线**：`M_Terrain_Snow`，只在生态条件成立时出现。
4. **陡坡**：`M_Rock`，按坡度、朝向与地层形成差异。
5. **其余地表**：`M_Terrain`，草地或当前生态对应材质。

- 分类由最终三角面中心高度、坡度和 16A 权重共同决定，源侧、GLB 与浏览器一致。
- 分类边界可采用小幅确定性过渡，避免每块三角形随机跳色；不能为了“过渡自然”把所有地貌打成同样模糊的绿。

### 步骤 3 · 每类材质的精致细节

| 材质 | 必须可辨的表现 |
|---|---|
| 草地 | 低频色相/明度变化、柔和粗糙度、少量贴地色带；近看不是一整片纯色塑料 |
| 沙岸 | 较细颗粒感或程序化微粒、干湿色带、较低但清晰的粗糙度差异；不使用像素砂点 |
| 岩石 | 折面法线、地层色带、裂面粗糙度和接触阴影；不是随机灰三角 |
| 雪 | 柔和边缘、轻透光/散射感、与岩石接触处的遮蔽；不是纯白无层次 |
| 水下 | 深度色、岸线湿润过渡、克制的可见度变化；不是一块蓝色平面 |

- 可使用原创程序化噪声、顶点色和 shader 增加近景细节；不下载或临摹外部材质。
- 色相扰动控制在低频、连续且小幅度，禁止逐三角形随机彩斑。

### 步骤 4 · 光影与接触感

- 统一太阳、环境光、色调映射、曝光和颜色空间，避免 Blender 与浏览器各做一轮 sRGB 转换。
- 使用合理的环境光遮蔽/接触阴影强化树根、岩石、角色与地表接触，不画黑色贴片冒充阴影。
- 材质高光服务种类区分：果冻、雪、沙、岩石和树皮不能共享同一塑料高光。
- Bloom、景深和描边只能克制辅助，不能遮盖法线、穿插或低质量轮廓。
- 近景不能因全局平面着色出现过硬阴影锯齿；阴影过滤与分辨率需实测。

### 步骤 5 · 跨运行时与扩环一致性

- 色板、分类、法线策略、材质参数与 LOD 规则随 GLB/manifest 版本导出，浏览器通过唯一适配层使用。
- Blender 与 Three.js 的显示特性可以不同，但输入参数、分类和视觉目标必须一致，正式美观以浏览器为准。
- 扩环旧块保持原 spec、材质身份和 hash；新环可延展色板，但交界处不能重写旧材质。
- 材质 shader 可以按 LOD 减少高频细节，不能在中近距离突然变成无层次纯色。

### 步骤 6 · 近、中、远实机验收

1. 近景检查草、沙、岩、雪（当前 biome 适用者）在纹理/粗糙度/法线/接触阴影上的区别。
2. 中景检查山体切面、海岸和生态过渡，确认低模轮廓清楚且无棋盘彩斑。
3. 远景检查材质层次不会闪烁、噪点化或突然糊成同一颜色。
4. 角色走过不同地面时，接触阴影、脚点、湿度和材质反馈正确，无漂浮感。
5. 同机位换色板比较，颜色管理正确；跨块/LOD/扩环不重新随机材质。
6. 保存高保真实机图和连续录屏，不以 Blender 材质球或线框图代替。

## 验收标准

1. 地形切面清楚，法线按资产类型合理选择，没有“全局全平面”造成的粗糙感。
2. 草、沙、岩、雪和水下材质在近景可区分，具有精致且克制的程序化细节与接触光影。
3. 颜色、分类、材质、LOD 和跨运行时来源一致，无随机彩斑、闪烁和 Z-fighting。
4. 近/中/远高保真实机证据齐全；不靠 Bloom、滤镜或角度遮盖问题。

---

## 回退方案

- **像随机彩三角**：降低逐面色差，改为世界坐标低频变化和分类内细节。
- **像塑料**：按材质调整粗糙度、接触阴影与微观层次，不只降低饱和度。
- **法线太硬/太滑**：按区域修平面/平滑/加权法线，不全局切换一种模式。
- **跨运行时不一致**：冻结发布，检查颜色空间、法线、分类和 shader 参数来源。
- **性能不足**：降低远处程序化细节、阴影和后处理，不删除近景材质区分。
