# 18 · 低多边形着色

> **一句话**：把地形变成"每面一个纯色"的低模长相——水面线索、沙滩、草地、岩、雪，全靠高度与坡度上色，配色来自 spec。

---

## 前置

零件 17（轮廓与沙滩可用）。

---

## 提示词正文

你是**上色师**。目标：不用贴图、不用 UV，只靠几何 + 顶点色/材质槽，做出"一眼低模"的观感。

**分工**："某处该是什么材质"由零件 16A 的区域判定表决定；本零件只负责"这个材质怎么画"（平面着色、明度抖动、折纸感）。若 16A 尚未做，先用本零件的简单高度/坡度判定顶着，做完 16A 后必须回来对齐。

### 步骤 1 · 平面着色

- 所有地形网格设置为平直着色（每个三角面一个法线）。
- 三角化方式：**对角线交替**（棋盘式交错），避免所有块呈同一个方向的斜纹。
- 禁用平滑着色、禁用加权法线。

### 步骤 2 · 上色策略

采用"每块一个网格 + 多材质槽按面上色"的方式（或顶点色 + 一个材质，二选一，选你更稳的；汇报里说明）。规则按优先级从高到低：

1. **水下**（z < -0.4）：`M_Underwater`，颜色由 `palette.water_deep` 与 `water_shallow` 按深度插值。
2. **沙滩带**（-0.4 ≤ z < beach_height+0.6）：`M_Sand`。
3. **雪线**（z > snow_line 且坡度 < 0.6）：`M_Terrain` 的雪色变体（用同一材质，颜色参数切换，或建 `M_Terrain_Snow` 若更简单）。
4. **陡坡**（坡度 > slope_rock）：`M_Rock`。
5. **其余**：`M_Terrain`（草地）。

`snow_line` 默认 `peak_height * 0.72`，但只有当 biome 属于 `snow` 或 `volcanic` 才启用；`island` 默认不积雪（除非 `peak_height > 20` 且 `sky.time_of_day` 偏冷）。

### 步骤 3 · 颜色扰动

同一类地形的相邻面之间要有**微妙色差**，否则一片死平：

- 用面中心坐标做低频噪声，色相 ±4°、明度 ±5%。
- 岩石面额外加一点随机明度抖动（±8%），让它"碎"。

**不要**五彩斑斓——低模的高级感来自"少而准"的颜色。

### 步骤 4 · 色板接线

所有颜色从 `specs/ring_{n}.json` 的 `palette` 读，映射关系：

| 地形 | 色板字段 |
|---|---|
| 草地 | `grass` |
| 沙滩 | `sand` |
| 岩石 | `rock` |
| 雪 | `snow` |
| 深水/浅水 | `water_deep` / `water_shallow` |
| 强调色（花、地标点缀） | `accent` |

若某字段缺失，用最近色相的默认值，不抛错。

### 步骤 5 · 线稿感（可选增强）

给地形材质加一个非常轻的"边缘加深"：用几何法线与视线夹角在小范围内加深颜色（这是着色器层面的，不是描边）。目的：低模面片之间更有"折纸感"。开启与否由 `weirdness` 或用户开关控制。

### 步骤 6 · 变更兼容

着色逻辑必须能被零件 32（扩环）复用：只按坐标求值、不依赖"当前已有哪些块"。新增区域的配色由新 spec 提供，但**旧块的色也必须保持不变**（旧块读旧 spec 的颜色）。

### 步骤 7 · 验收

1. 俯视图：五种地形色块清晰、边界沿等高线自然。
2. 贴地：草面有微妙色差、岩面有碎裂感。
3. 放大看单块：所有面是平面着色，无平滑渐变。
4. 换一个 spec 的 palette（换 `accent` 与 `grass`），整岛气质立刻变化（两张对比图）。

## 参数表

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `snow_line_ratio` | 0.72 | 0.5~0.9 | 相对 peak_height |
| `slope_rock` | 0.62 | 0.4~0.8 | 坡度阈值（0~1） |
| `color_jitter_hue` | 4° | 0~10 | |
| `color_jitter_val` | 5% | 0~12 | |
| `rock_jitter` | 8% | 0~15 | |
| `tri_alt_diagonal` | 是 | | 棋盘三角化 |
| `edge_shade` | 0.15 | 0~0.4 | 折纸感强度 |

---

## 验收标准

1. 五种地形色齐、边界自然。
2. 平面着色生效（近看无平滑渐变）。
3. 相邻面有微妙色差，不是死平。
4. 换 palette 后整体气质明显变化。
5. 无贴图依赖、无 UV 依赖。
6. 三张截图（俯视、贴地、单块特写）+ 一张换色对比。

---

## 回退方案

- **多材质槽导致 draw call 爆**：改用"顶点色 + 单一材质"，颜色写入顶点色属性；视觉几乎一致。
- **颜色发灰**（色彩管理问题）：检查是否用了 AgX 的强压缩，或把材质改成自发光混合一点，提亮中间调。
- **雪线乱跳**（高度噪声导致斑驳雪）：对 `z - snow_line` 做软阈值（smoothstep 带宽 0.8 BU）。
