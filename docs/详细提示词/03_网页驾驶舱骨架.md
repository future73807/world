# 03 · 网页驾驶舱骨架

> **一句话**：把一个全新项目 `app/` 立起来，左边灵感、中间视口、右边地图与日志，深色玻璃感，一眼知道自己在开飞船。

---

## 前置

零件 02 通过（Node 可用；MCP 不要求，本轮不碰 Blender）。

---

## 提示词正文

你是**驾驶舱结构工程师**。只搭骨架与样式，不接任何真实数据；所有地方先放"假数据"，但要放在以后能替换的位置。

### 步骤 1 · 建工程

在 `app/` 下新建一个现代前端工程（Next.js App Router 或 Vite + React 都行，选你更稳的那个，选完在汇报里说明）。要求：

- TypeScript。
- 路由至少两条：`/`（驾驶舱）与 `/api/*`（服务端路由预留）。
- 能在 3000 端口跑起来，`npm run dev` 一条命令启动。
- 目录分三层：`app/components`（纯展示组件）、`app/lib`（数据与状态）、`app/server`（服务端路由与进程管理）。

### 步骤 2 · 三栏布局

桌面端三栏，比例 `280px / 自适应 / 380px`：

**左栏「灵感舱」**
- 顶部：世界名占位 + 一个「世界设定卡」摘要区（先放假字段：biome / mood / weirdness）。
- 中部：灵感卡牌抽卡区（先放 3 个空卡位，写了"待抽"）。
- 底部：「生成世界」主按钮（大、圆角、有呼吸光效）、「重置」次按钮。

**中栏「世界视口」**
- 一块 16:9 区域，先放一张占位渐变图 + 居中文案"等待世界"。
- 下方细长条：阶段进度（分期：地形 / 海岸 / 着色 / 水 / 天空 / 树木 / 史莱姆 / 迷雾），每一步一个可点亮的小圆点。
- 视口右上角悬浮小徽章：`ring 0 · 100×100`。

**右栏「地图与日志」**（上下分，6:4）
- 上部：地图容器（占位圆角方块，带"未生成"遮罩）。
- 下部：日志预览（最近 8 行，等宽小字，带颜色）。

### 步骤 3 · 底部终端抽屉

页面最底部一条高 36px 的条，写着 `⌘ CLI · 就绪`。点击或按 `Ctrl+J` 向上展开一个 320px 高的终端面板（此零件只需"能展开/收起"，内容留给零件 04）。

### 步骤 4 · 通知挂点

右上角预留通知堆叠区（`toast host`），先让它在开发模式下能手动触发一条假通知，验证位置与动效。文案服从契约：`notify` 事件里的 `body` 含"去看看"时要高亮对应按钮。

### 步骤 5 · 视觉基调

- 深色底（近黑偏蓝），玻璃拟态卡片（背景模糊 + 1px 半透明描边 + 内发光）。
- 圆角统一 14px，栅格 8px。
- 主色由一个 CSS 变量 `--accent` 驱动，后续会由世界色板覆盖；本轮默认青绿。
- 字体：正文用系统无衬线，数字与日志用等宽。
- 动效克制：按钮 hover 亮度 +6%，卡片入场 160ms 上浮，不要花哨。

### 步骤 6 · 状态占位

在 `app/lib` 建一个"世界状态"的占位模块：定义好前端需要的类型（与契约 F/G 对齐），数据来源先返回假对象。**不要**此时接文件系统。

### 步骤 7 · 自检与截图

用浏览器打开 `http://localhost:3000`，截三张图：整页、终端抽屉展开、通知弹出。放进 `renders/app_step03_*.png`。检查 1280 宽下不横向滚动、1440 宽下三栏不挤。

## 参数表

## 验收标准

1. `npm run dev` 能起，浏览器打开无报错（控制台干净）。
2. 三栏 + 底部终端条 + 右上通知区四件齐。
3. `Ctrl+J` 能开合终端抽屉，动效顺。
4. 假通知能弹出，含"去看看"时按钮高亮逻辑存在。
5. 进度条八个小圆点可编程点亮（假数据验证一次）。
6. 三种截图已存 `renders/`。
7. 代码分层清楚：`components` 里无 Node API 调用。

---

## 回退方案

- **Next.js 装不上**（网络/镜像问题）：退回 Vite + React，路由用简单文件式或单页 + 手写 hash 路由，把结论写进汇报。
- **端口被占**：换 3100，并在 README 的启动命令里改成新端口。
- **玻璃拟态在低端机掉帧**：把 backdrop-blur 降为 6px，或提供一个"性能模式"开关（关闭模糊，改半透明纯色）。
