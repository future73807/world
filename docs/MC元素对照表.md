# MC 元素对照表 · 只比较设计问题，不搬运实现

> 本表用于说明“参考什么设计问题、迷雾群岛怎样给出不同答案、哪些内容明确不做”。
>
> 它不是美术参考、模型清单、系统复刻任务或覆盖率目标。禁止根据本表下载、导入、改名、重着色或重建 MC 的标志性内容。

---

## 1. 使用规则

一次合格的参考必须走完以下路径：

```text
观察到一个设计问题
→ 抛开对方的模型、名词、UI 和具体机制
→ 说明迷雾群岛的玩家需求
→ 用原创低模几何、角色、命名与交互重新回答
→ 在浏览器中检查二者是否有明显差异
```

禁止停在“把它也做一个”“差不多还原”“换低模材质继续用”。不要求条目数量、系统等价、相似度或某种外部游戏手感。

---

## 2. 可以比较的设计问题与本项目答案

| 设计问题 | 迷雾群岛的原创回答 | 明确不能搬什么 |
|---|---|---|
| 大世界怎样避免到处一样？ | 用高程、温度、湿度与 seed 形成连续生态权重，配合原创色板和不同步行节奏 | 群系名称映射、方格边界、标志性材质、现成世界生成规则复刻 |
| 地形材料怎样一眼可辨？ | 连续三角网 + 有限面色 + 不规则地层切面；草坡、沙岸和裸岩靠几何与色块区分 | 草方块、沙方块、矿石贴图、像素表面、单位立方体 |
| 林地为什么有探索节奏？ | 折伞树、叠羽树、灯菌树三族原创植物，配合群丛、空地和通行走廊 | 方树、像素树叶、现成树种模板、等距矩阵种植 |
| 环境怎样显得有生命？ | 鸟群、浅鱼、沙蟹、小蝶与夜光虫只承担视线引导和氛围，行为围绕史莱姆的好奇心 | 标志性敌对生物、驯养/繁殖/掉落循环、现成角色造型 |
| 散步时有什么远处目标？ | 偏心拱、风标塔、漂木桥、古树立石等从剪影重新设计的地标 | 村庄、要塞、神庙等结构复刻，战利品箱与副本流程 |
| 时间如何改变世界？ | 光照、天空色、雾层、活动生物与水面反馈共同变化，保持夜间轮廓可读 | 只复制时间数值，或照搬外部 UI/天空素材 |
| 天气如何被感知？ | 雨点涟漪、薄雪覆盖、风改变植被和雾，天气影响观察而非生存惩罚 | 像素粒子、状态图标包装、外部灾害机制复刻 |
| 玩家怎样理解世界边界？ | 雾墙、角色附近 E 蓄力、扩环开雾和新地标，形成原创拓荒仪式 | 基岩墙、地图边界外观、传送门或其他标志性边界设计 |
| 玩家怎样查找方向？ | 左上小地图、世界内地标、可关闭的展开地图；默认不打开管理面板 | 物品式地图、像素图标、外部 HUD 布局与坐标界面 |

这里的“原创回答”只是设计约束，具体模型仍需从剪影、灰模和新顶点生成，不能反过来查参考图临摹。

## 3. 明确不引入的系统

| 类别 | 不做的原因 | 替代体验 |
|---|---|---|
| 战斗、武器、敌对生物、Boss | 会破坏轻松探索与可爱调性 | 观察生物、追光、发现地标、拓荒 |
| 背包、装备、附魔、药水、属性成长 | 与无负担散步目标不符 | 角色情绪、世界变化、环境记录 |
| 采集、合成、熔炼、耕作、交易 | 会把探索变成资源清单 | 雾边蓄力、生态观察、地标故事 |
| 红石/电路与自动化机器 | 不属于本项目的核心动词 | 后台世界生成仅作开发管道，不变成游戏装置 |
| 饥饿、生命值、死亡惩罚 | 不需要生存压力 | 深水/迷雾的温和阻挡与回退 |
| 多维度与标志性传送门 | 会稀释浮岛与迷雾身份 | 可选的同一世界星球观察，不改变地表玩法 |
| 外部游戏的物品数量与图鉴完成率 | 数量目标会诱导照搬 | 只验收可感知的空间、操作和氛围质量 |

## 4. 模型与 UI 的独立来源检查

新版资源必须能回答：

1. 轮廓设计稿在哪里？
2. 新顶点/新 SVG/新 Canvas 路径是怎样生成的？
3. 是否打开过恢复包、外部模型包或参考游戏资源作为制作输入？若是，立即停止使用并报告。
4. 不看颜色时，剪影是否仍与参考对象明显不同？
5. 移除 UI 文案后，布局是否仍像外部游戏或旧驾驶舱？若是，重新设计。

对象名、schema 字段和 seed 等技术接口可以保持稳定；几何、材质、视觉图标、动画姿态、布局和交互表现必须重新设计。

## 5. 验收时怎样使用本表

本表不提供“已完成多少 MC 内容”的分数，只用于反向排查：

- 是否因为这里提到某类自然物，就制作了对方的标志性造型？
- 是否为了凑功能，加入了战斗、背包、合成等明确不做的系统？
- 是否把参考对象的截图像素、配色、模型或 UI 当作验收图？
- 是否用“低模化”“去像素化”“改名”掩盖直接复刻？
- 新模型是否有独立轮廓稿和灰模，新 UI 是否有独立线框和实机状态证明？

任何一项存在，回到设计阶段重做。最终仍以 `详细提示词/37_总装与验收.md` 的浏览器实机与原创性检查为准。
