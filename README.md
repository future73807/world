# 迷雾群岛 · 精致低模开放世界

> 一套用于从零制作**浏览器全屏、精致风格化低多边形探索游戏**的提示词包。
>
> 目标是精致模型、类似原神这类开放世界游戏的直观操作与高保真游戏 UI。不是 MC、不是驾驶舱，也不是低面数技术演示。

---

## 1. 最终体验

打开浏览器，直接进入一座细节完整的原创浮岛。玩家用第三人称控制一只柔和透光的切面水滴史莱姆，在具有根冠层次的树木、弯曲花草、断层岩石和水面间自由探索。

角色能够自然地起步、移动、停止、转身、跳跃和落地；相机不抢回、不穿墙；地图可以选地标和设置路径点；迷雾边缘通过 E 蓄力拓荒。

**低多边形是一种有意的风格，不是方块、粗糙 primitives 或面数越少越好。**

## 3. 精致模型标准

### 3.1 大、中、小三层结构

- **大形**：独特剪影，远处可辨。
- **中形**：主枝、冠层、岩层、角色体积与支撑关系。
- **小形**：近景边缘、端面、菌褶、花瓣、色带、嵌件与合理程序化细节。

允许合理细分、分组平滑、加权法线、小倒角、形态键和原创非像素纹理。禁止单位立方体拼接、体素、像素纹理、方树和外部游戏资源。

### 3.2 关键资产

| 资产 | 质量要求 |
|---|---|
| 史莱姆 | 定制水滴拓扑，主体约 1,200～2,000 面、整只近景 ≤3,000；面部、变形、材质与 LOD 完整 |
| 折伞树 | 根颈、主枝、多个折伞冠层、闭合厚度与近景材质，近景约 800～1,200 面 |
| 叠羽树 | 风向弯干、主枝、闭合羽片与疏密节奏，近景约 600～1,000 面 |
| 灯菌树 | 弯曲柄体、伞盖厚度、菌褶、局部透光和结构变体，近景约 900～1,400 面 |
| 草花 | 弯曲叶片、花茎、花瓣与柔和色差，不用三角草和圆片花 |
| 岩石 | 主/次断面、边缘倒角、地层色带和接地关系，不是灰多面体 |
| 生物 | 完整身体与翅/鳍/钳等结构，不用三角鱼、两片翼鸟和十面螃蟹 |
| 菌群与云 | 闭合体块、厚度、内部层次和合理法线，不用球冠/压扁球拼装 |
| 地标 | 独立剪影、支撑结构和近景细节，不是柱、弧和薄片的组合 |

所有关键模型先交剪影、灰模和材质完成图，再交浏览器近/中/远实机证据。美术不合格不能靠低面数或帧率豁免。

## 4. 高保真开放世界 UI

参考原神等游戏的世界优先、操作直接、信息随情境出现和界面完成度，不复制具体素材。

### 默认 HUD

- 左上精致小地图、区域名与时间/天气。
- 少量当前目标，可用 J 展开。
- 右上少量原创地图/目标/暂停入口。
- 底部必要角色状态。
- 对象附近的输入图标、互动动作与蓄力反馈。
- 自动消退的区域发现和通知。

### 独立游戏界面

- **全屏地图**：缩放、拖动、回到玩家、地标详情、路径点与世界内方向引导。
- **暂停/设置**：统一视觉、完整状态、关闭后精确恢复。
- **世界创建**：幻想世界气质，不做后台表单。
- **触屏布局**：左下摇杆、右下动作、地图与菜单适配安全区。
- **开发工具**：CLI、日志和性能面板默认隐藏。

施工前必须有桌面/触屏线框、高保真 HUD/地图/暂停/创建/互动效果图、字体与图标规范、视觉 token 和交互分镜。不能直接用组件库默认皮肤通过。

## 5. 开放世界操作与镜头

| 输入 | 行为 |
|---|---|
| WASD / 方向键 | 相对相机移动，具有起步、停止和转向反馈 |
| 鼠标 | 单击后锁定指针环视；Esc 释放并暂停 |
| 滚轮 | 平滑调整跟随距离 |
| 空格 | 跳跃，包含预备、上升、顶点、下落与落地 |
| Shift | 快速移动/短冲刺 |
| E | 当前最佳对象互动 / 迷雾蓄力 |
| M | 打开/关闭全屏地图 |
| J | 展开/收起目标详情 |
| Esc | 取消、关闭顶层界面或暂停 |

角色运动包含待机、起步、移动、停止、转向、跳跃预备、上升、顶点、下落和轻/重落地；速度与动画匹配，不滑步。

相机支持自由环视、平滑跟随、缩放、避障与遮挡淡出。**松开鼠标不强制回正**，只有设置允许的移动辅助回正。

## 6. 浏览器与 Blender 分工

| 部分 | 职责 |
|---|---|
| `app/` | Three.js 实时渲染、输入、运动、相机、碰撞、动画、地图与高保真 UI |
| `world/` | 从零制作 Blender 源模型、材质、动画、分块 GLB 和离线检查 |
| `app/server/` | spec、seed、作业、资源校验与原子发布 |
| 可选 AI | 生成世界参数；断网时使用本地预设 |

玩家不需要打开 Blender 或命令行。后台扩环只生成新增资源，浏览器预载后切换，不重置玩家和相机。

## 7. 资源预算与质量底线

- 区块 10 BU，出生岛 100 块；L0 地形每块 11×11 个位置、200 三角面，共 20,000 面。
- 地形采样密度不是可见方格，也不限制角色和近景植被细节。
- 出生岛默认实际渲染目标 ≤250,000 三角面；每环新增目标 ≤80,000，满环目标 ≤570,000。
- 分别统计独立源资产、驻留 LOD、实例源面数和实际渲染量，不能重复累计共享几何。
- 浏览器同屏 draw call 目标 ≤600，1080p 验收硬件目标 ≥45fps。
- 性能不足先减少远景实例、更新频率和后处理，**不得把主角和近景模型退回粗糙 primitives**。

## 8. 先通过 G0 精致可玩切片

1. 一小块完整地形的精致度样板：地形、树、岩石、史莱姆、材质与光影。
2. 高保真 UI 设计包和桌面/触屏交互分镜。
3. 浏览器真实资产、完整角色运动、自由相机、地图路径点和迷雾互动。
4. 高保真实机截图、连续录屏和性能数据。
5. 用户确认后才扩展 AI、后台、生态和宇宙。

不得以完成 CLI、API、宇宙编辑器或大量地形代替 G0 美术与操作验收。

## 10. 当前状态

提示词包已完成统一修订与静态校验；环境自检报告见 `runtime/env_report.md`（Blender 4.3.2 / Node 22 / RTX 4060 可用）。

G0 的**原创 UI 设计包**已交付于 `design/`：统一 token、桌面与触屏线框，以及默认 HUD、全屏地图、暂停设置、世界创建、迷雾互动的高保真稿和渲染截图（桌面 1920×1080，触屏 844×390）。设计稿背景为原创 SVG 示意，不是实机画面。

**尚未生成** Three.js 实机应用、可运行 UI、史莱姆与树木的剪影/灰模。历史恢复包位于仓库外，但不允许作为任何制作输入。

下一步应是：确认 `design/` 的视觉方向后，实现 03 实机底座与输入状态机，并制作原创模型剪影与灰模，再合成 G0 浏览器精致可玩切片，而不是直接重建整个世界。
