# 迷雾群岛 · 精致低模开放世界

> 一套用于从零制作**浏览器全屏、精致风格化低多边形探索游戏**的提示词包。
>
> 目标是精致模型、类似原神这类开放世界游戏的直观操作与高保真游戏 UI。不是 MC、不是驾驶舱，也不是低面数技术演示。

---

## 1. 最终体验

打开浏览器，直接进入一座细节完整的原创浮岛。玩家用第三人称控制一只柔和透光的切面水滴史莱姆，在具有根冠层次的树木、弯曲花草、断层岩石和水面间自由探索。

角色能够自然地起步、移动、停止、转身、跳跃和落地；相机不抢回、不穿墙；地图可以选地标和设置路径点；迷雾边缘通过 E 蓄力拓荒。

**低多边形是一种有意的风格，不是方块、粗糙 primitives 或面数越少越好。**

恢复包只作为与生产隔离的历史存放，不是资源库、设计参考或回退实现。

## 3. 精致模型标准

### 3.1 大、中、小三层结构

- **大形**：独特剪影，远处可辨。
- **中形**：主枝、冠层、岩层、角色体积与支撑关系。
- **小形**：近景边缘、端面、菌褶、花瓣、色带、嵌件与合理程序化细节。

允许合理细分、分组平滑、加权法线、小倒角、形态键和原创非像素纹理。禁止单位立方体拼接、体素、像素纹理、方树和外部游戏资源。

### 3.2 关键资产

| 资产 | 质量要求 |
|---|---|
| 史莱姆 | 定制水滴拓扑，主体约 1,200～2,000 面、整只近景 ≤3,000；面部、变形、材质与 LOD 完整 |
| 折伞树 | 根颈、主枝、多个折伞冠层、闭合厚度与近景材质，近景约 800～1,200 面 |
| 叠羽树 | 风向弯干、主枝、闭合羽片与疏密节奏，近景约 600～1,000 面 |
| 灯菌树 | 弯曲柄体、伞盖厚度、菌褶、局部透光和结构变体，近景约 900～1,400 面 |
| 草花 | 弯曲叶片、花茎、花瓣与柔和色差，不用三角草和圆片花 |
| 岩石 | 主/次断面、边缘倒角、地层色带和接地关系，不是灰多面体 |
| 生物 | 完整身体与翅/鳍/钳等结构，不用三角鱼、两片翼鸟和十面螃蟹 |
| 菌群与云 | 闭合体块、厚度、内部层次和合理法线，不用球冠/压扁球拼装 |
| 地标 | 独立剪影、支撑结构和近景细节，不是柱、弧和薄片的组合 |

所有关键模型先交剪影、灰模和材质完成图，再交浏览器近/中/远实机证据。美术不合格不能靠低面数或帧率豁免。

## 4. 高保真开放世界 UI

参考原神等游戏的世界优先、操作直接、信息随情境出现和界面完成度，不复制具体素材。

### 默认 HUD

- 左上精致小地图、区域名与时间/天气。
- 少量当前目标，可用 J 展开。
- 右上少量原创地图/目标/暂停入口。
- 底部必要角色状态。
- 对象附近的输入图标、互动动作与蓄力反馈。
- 自动消退的区域发现和通知。

### 独立游戏界面

- **全屏地图**：缩放、拖动、回到玩家、地标详情、路径点与世界内方向引导。
- **暂停/设置**：统一视觉、完整状态、关闭后精确恢复。
- **世界创建**：幻想世界气质，不做后台表单。
- **触屏布局**：左下摇杆、右下动作、地图与菜单适配安全区。
- **开发工具**：CLI、日志和性能面板默认隐藏。

施工前必须有桌面/触屏线框、高保真 HUD/地图/暂停/创建/互动效果图、字体与图标规范、视觉 token 和交互分镜。不能直接用组件库默认皮肤通过。

## 5. 开放世界操作与镜头

| 输入 | 行为 |
|---|---|
| WASD / 方向键 | 相对相机移动，具有起步、停止和转向反馈 |
| 鼠标 | 单击后锁定指针环视；Esc 释放并暂停 |
| 滚轮 | 平滑调整跟随距离 |
| 空格 | 跳跃，包含预备、上升、顶点、下落与落地 |
| Shift | 快速移动/短冲刺 |
| E | 当前最佳对象互动 / 迷雾蓄力 |
| M | 打开/关闭全屏地图 |
| J | 展开/收起目标详情 |
| Esc | 取消、关闭顶层界面或暂停 |

角色运动包含待机、起步、移动、停止、转向、跳跃预备、上升、顶点、下落和轻/重落地；速度与动画匹配，不滑步。

相机支持自由环视、平滑跟随、缩放、避障与遮挡淡出。**松开鼠标不强制回正**，只有设置允许的移动辅助回正。

## 6. 浏览器与 Blender 分工

| 部分 | 职责 |
|---|---|
| `app/` | Three.js 实时渲染、输入、运动、相机、碰撞、动画、地图与高保真 UI |
| `world/` | 从零制作 Blender 源模型、材质、动画、分块 GLB 和离线检查 |
| `app/server/` | spec、seed、作业、资源校验与原子发布 |
| 可选 AI | 生成世界参数；断网时使用本地预设 |

玩家不需要打开 Blender 或命令行。后台扩环只生成新增资源，浏览器预载后切换，不重置玩家和相机。

## 7. 资源预算与质量底线

- 区块 10 BU，出生岛 100 块；L0 地形每块 11×11 个位置、200 三角面，共 20,000 面。
- 地形采样密度不是可见方格，也不限制角色和近景植被细节。
- 出生岛默认实际渲染目标 ≤250,000 三角面；每环新增目标 ≤80,000，满环目标 ≤570,000。
- 分别统计独立源资产、驻留 LOD、实例源面数和实际渲染量，不能重复累计共享几何。
- 浏览器同屏 draw call 目标 ≤600，1080p 验收硬件目标 ≥45fps。
- 性能不足先减少远景实例、更新频率和后处理，**不得把主角和近景模型退回粗糙 primitives**。

## 10. 当前状态

提示词包已完成统一修订与静态校验。运行环境：Blender 4.3.2 / Node 22 / RTX 4060，均已验证可用（原 `runtime/env_report.md` 已随 `runtime/` 目录一并移除，环境结论记录在此）。

**G0 可玩切片已实装**（`app/`，Three.js + React + TypeScript）：

- 100 BU 确定性浮岛：连续三角地形、斜切海岸与断崖地层带、海面波浪、CSS 天空渐变、远景漂浮岛群。
- 三族原创低模植被各 3 个结构变体 + 岩石 + 草花，全部程序化生成；近/远双 LOD。
- 史莱姆：共享顶点环状拓扑、上小下大半圆穹体、上下渐变、外壳内置角、挤压/拉伸弹簧、底盘贴合地形；起跳后裙边完全离地并留接触阴影。
- 第三人称相机（水平环视、缩放、地形避障、逐实例遮挡虚化）与移动/跳跃/冲刺状态机；点击体力条可冲刺一小段。
- 白色 HUD（lucide 图标包，图标槽位等高对齐）、全屏地图（无锚点、真实位置箭头）、白色单页设置、书本帮助、迷雾粒子前沿与区域生成。
- 加载完成时云团散开转场。
- 实测（1440×900）：165 fps，提交三角面约 699k，0 个 NaN 地形采样。

**本轮（第 11／12 轮）修掉的根因**，均已浏览器实测：

1. **地形 NaN**：`world.ts` 对可能为负的 fbm 值取 `Math.pow(v, 1.2)` → 39% 采样点为 NaN，地面整片消失。改为先映射到 0..1 再取幂。峰值由 6.9 升至 11.5 BU，高地生物群系可达；`ridgedFbm` 已删除。
2. **地形横向折痕**：剖面 key 逐段用 smoothstep 插值，每段交界处曲率突变，42 环网格上表现为一圈圈横向褶皱。改为 Catmull-Rom 全段连续。
3. **地图迷雾整岛透出**：Chromium 的 `source-atop` 保留目标 alpha，纯白填充不会提高不透明度。迷雾遮罩底色 0.84 → 0.985。
4. **遮挡虚化整族透明、且实际无效**：改为逐实例 `aFade` instanced attribute；并且必须把 alpha 写在 `diffuseColor` 上（替换 `<opaque_fragment>`），因为 three r18x + WebGL2 下在 `<dithering_fragment>` 之后写 `gl_FragColor` 是空操作——这正是"树挡住镜头却没虚化"的真正原因。
5. **新岛过不去 / 穿模**：`player.ts` 硬编码 `maxR = 47.5` 改为随迷雾前沿扩张的 `boundaryRadius`；`buildRegionVegetation` 补注册 collider。
6. **史莱姆的角像纸片**：角原本是独立球壳贴在穹顶外。改为对穹顶顶点做 2D 高斯位移（角度 × 高度），角成为同一张网格的连续表面，跟随挤压形变且无接缝；顶点色同步加深。
7. **地图拖动卡顿**：拖动过程中每帧重排 1536² 的地形烘焙。改为拖动期间完全不烘焙，松手后延迟 120ms 烘焙一次，并把 tile 降到 1024²。
8. **地图雾外露出地形 / 接缝**：雾遮罩只有 300 BU，方框外直接画地形。改为方框外用同色云填充。
9. **冲刺没有速度感**：速度提升 2.2 倍但镜头毫无变化。加入 FOV 52→63 与跟随距离 +0.9 的冲刺推镜。
10. **帮助书本像 PPT**：增加封皮厚度、书页堆、书脊凹槽与整体投影。

**第 13 轮（本轮 UI 与接壤）**，同样逐项在浏览器实测：

1. **跳跃时与地面严丝合缝**：`Slime.update` 每帧把底盘顶点拉回地形，与高度无关。改为按离地高度释放贴合，并新增接触阴影球（离地时才有）。
2. **犄角长在两侧**：环角度约定是 `x=cos(a), z=sin(a)`，脸在本地 -Z 即 `a=-π/2`，原代码按 `π` 计算，角因此落在左右。修正为眼睛正上方。
3. **接壤处是一坐一坐小岛 / 穿模**：三处叠加——接壤锚点把玩家半径算了两遍（锚点落到海里约 21 BU）、已存在区块从未重建（旧网格留着旧表面＝一堵穿模墙）、每个区域各自生成崖壁裙边（裙边横穿它并入的岛）。现在锚点直接用 `玩家 + 朝向×岸距`，区块强制重建，整岛只保留一张合并裙边，并新增宽度≈0.86 半径的填平堤道。沿轴线实测高度 2.8→8.4 单调，无水沟。
4. **新区域方向与大小**：改为在玩家朝向的射线上找岸，半径 46–56 BU，并把圆顶中心推到接壤锚点之外，避免把树和玩家一起吞掉。
5. **迷雾没有覆盖地图**：雾遮罩是有限方块，方块外直接绘制地形。新增无缝云贴图 + even-odd 填充遮罩外区域，并把遮罩边缘羽化，方块边界不再可见。
6. **E 键到处都能用**：改为按视线前方 13 BU 内是否有海判定。岛内按 E 不产生任何效果，站到岸边才出现提示。
7. **草丛像垃圾**：4200 个均匀散点改为 620 个种子簇（每簇 3–6 丛），并禁止在沙滩生成；实测 606 个采样实例中 0 个落在沙滩。树干下沉量随坡度加大并沿法线倾斜，坡地上根盘不再悬空。
8. **UI 不是全白、图标大小不一**：设置页与所有页面改为白色半透明页 + 深墨字；选项与说明改为左右同一行；滚动条改为 12px 圆角半透明白（白底加描边以保证可见）；HUD 图标统一到 44px 槽位并逐个做光学缩放，实测三槽 top=24／高=44／同基线，下方 M·I·C 均 13px。
9. **叉号不好看、帮助书的叉会消失**：全部换成图标包的 X；帮助书的叉提升到 z-index 400 常驻。
10. **告知位置**：toast 改为页面顶部居中，文案"新区域「X」已生成"。
11. **帮助书与加载转场**：书本按参考稿重做为奶油色书页、四角细线、页码、标题横线、书脊丝带、封面双线框；加载完成改为蓝天背景下云团膨胀上升消散。
